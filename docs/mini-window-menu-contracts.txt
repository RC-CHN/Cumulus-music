当前入口与复用关系
- MiniApp头部菜单按钮、头部右键、ContextMenu/Shift+F10打开同一个MiniWindowMenu。
- 置顶复用useMiniPin，实际窗口属性/保存偏好分开，未知时只读重查，偏离时仅重应用。
- 完整模式复用mini_leave；保留同一个MusicClient/队列/音频实例和原播放位置。
- 播放模式复用useMiniModes及Rust原有普通/心动/FM/一起听状态机，不建立第二套队列。
  普通四项，可心动时加心动；心动中保留心动选中及退出选择；一起听三项；FM两项。
  FM两项和一起听三项是沿用本客户端已有领域规则的社区适配，不能称为M622原样。
- 桌面歌词开关、重试、设置损坏修复、锁定/解锁调用下述专用IPC。设置/样式/几何
  仍由原主窗口设置页维护；小窗不获得通用设置IPC。
- 退出使用mini_exit，经已有生命周期/保存/播放器收尾流程退出；不是销毁WebView
  后留下后台进程。主窗口有未决关闭流程时拒绝，不自动重放退出。

窄IPC与可信状态
desktop/src/mini/menu.rs、desktop/src/desktop_lyrics/mini_menu.rs：
- mini_lyric_menu_read(generation, ticket) -> {ticket, enabled, visible, opening,
  locked, damaged, error}。首个ticket是已有小窗媒体上下文，返回ticket是原生持有的
  歌词状态快照引用；前端不传偏好revision、窗口label或任意设置字段。
- mini_lyric_menu_action(generation, menuTicket, action) -> void；action只允许
  toggle/retry/repair/lock/unlock。接受后一次性消费ticket，并撤销更早的在途读取。
- mini_exit(generation) -> void，仅当前登记的小窗代次可调用。
- 三个命令只开放给小窗能力，主窗和歌词窗口不能借此获得新的调用权限。
- 歌词快照包含账号epoch、偏好revision、窗口serial/generation、显示/启动/锁定和
  错误状态。执行前重新校验；已退役窗口、旧账号、被其他窗口修改过的上下文拒绝。
- 相同快照的纯读取保留同一ticket。先发出的读不能撤销已经接受的动作；读失败或
  确认丢失不自动重新提交开关、修复、锁定或退出。
- 只持有桌面歌词自己的operation锁。真实歌词窗口启动等待不占小窗transport锁，
  暂停/定位等原有控制仍能执行。偏好读写使用已有Rust持久化/CAS及账号所有者校验。
- 返回值不含Cookie、设备标识、凭据、原生句柄、完整授权URL或任意文件路径。

状态与失败恢复
- 菜单打开时读一次，此后每750ms完成一次后再安排下一次只读更新；短暂transport
  busy只推迟，恢复后继续读。菜单关闭/组件卸载/账号变化停止计时并丢弃旧结果。
- enabled是持久化意图，visible/opening是原生窗口状态，不能互相替代。保存成功但
  启动失败时保留enabled，显示明确错误及“重试打开”，重试不反向开关/改revision。
- 保存失败保持实际窗口与偏好原样，保留错误。下一次显式打开菜单重新读取后才能
  决定新动作；不会假装已关闭，也不会以业务错误触发图形后端自动重启。
- 损坏设置提供明确修复；仍存在的已锁窗口保留解锁入口。锁定前确认主窗、托盘或
  当前可用小窗中至少有可恢复入口；可用小窗存在时不额外弹出主窗。
- 锁定/解锁复用同一原生set_ignore_cursor_events及ledger，未创建模拟锁定标志。
- 切歌、账号/队列/模式族变化关闭旧菜单；仅同账号且菜单持有焦点时归还原入口。
  账号切换后歌词窗口可保留用户全局可见偏好，但不展示旧账号媒体内容。

菜单交互和视觉边界
- ActionMenu/MenuSubmenu使用共享配色、图标、MenuTransition、焦点样式和减少动态
  效果策略；只用transform/opacity过渡。420×206内两个190px菜单横向错开，滚动
  有界，子菜单必要时向左展开。C++原始菜单几何未恢复，此尺寸为社区适配。
- 上下/Home/End选择父项，右方向键进入子菜单，左方向/Escape先回到父项，再按
  Escape关闭整组，Tab离开。父菜单滚动或移动到别项会关闭旧子菜单。
- 打开子菜单后等待布局可见再聚焦选中项。离场节点立即inert；select还核对当前
  open状态、连接状态、节点归属及当前可用项，拒绝迟到回调，不只依赖CSS挡点击。
- 普通/心动/FM/一起听选择互相排斥，菜单选中标志来自播放器回读；pending不是
  成功态。桌面歌词操作有自己的进行提示，不将其等待映射为播放器不可操作。
