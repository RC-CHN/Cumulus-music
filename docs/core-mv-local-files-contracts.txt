本地 MV 与完成文件/目录操作的联动
2026-10-26；独立 Rust core，用真实解码器文件占用约束保护操作。

产品行为
正在播放或暂停的已下载 MV 可以重命名、移动和迁移目录。
提交文件意图后暂时释放视频，保存原生实际播放位置；操作完成后重新核验下载任务、离线
完整性及本账号权限，从新路径恢复原位置、音量、速度和播放/暂停意图。
操作未结束时显示“正在处理本地视频文件”，可跳转下载管理继续或撤销；暂停按钮仍可
改变完成后的播放意图。停止、切换视频、切换账号都会撤销旧视频的自动恢复。
删除实体或仅移除下载记录后停止该本地 MV，保留续播位置；不自动转向在线音源。
从下载卡片重试/重新播放继续核验原任务；从其他在线入口重新选择 MV 或显式切换清晰度，才按对应入口重新选源。
歌曲的Forget仍沿用保留队列/本地来源的既有契约；不把歌曲语义强行套到MV账号离线任务上。
播放引擎尚在打开本地文件时发生操作也会取消旧加载，不允许迟到解码器自行播放。

模块边界与调用顺序
download/playback.rs：当前账号任务状态查询、同owner/task的便携文件锁；无Tauri依赖。
mv/playback/resolve.rs：选择完成任务，先持有租约，再核验未迁移、任务路径/摘要/状态
未改变；执行完整离线校验，打开原生解码器。持有租约的HeldEngine按声明顺序销毁原生
设备，再释放锁，覆盖迟到帧引用、尚在加载和被取消的阻塞线程。
mv/playback/local.rs：观察持久化task.file_operation和下载目录active批次；保存检查点，
取消旧加载、清空帧槽、等待原生stop/销毁。新playId只在重新加载时分配。
download/completed/execute.rs：resume在既有文件/任务/本地库/传输锁内等待播放租约，
然后才复制/链接/提交元数据/删除原文件。准备意图不等租约，避免双方互等。
FileEvent::WaitingForPlayback提供停止/取消检查点；等候最多30秒，每10ms检查一次。
等候时不持有SQLite或账号mutex；账号过期、宿主停止、等候超时返回错误，意图仍存在，
可显式继续或取消。不会强行删除仍被占用的文件。
目录子操作复用相同租约；即使某个子任务已完成、file_operation已清空，只要整批active
仍存在，视频继续等待，避免重新打开随后可能回滚的中间路径。
frontend的VideoView新增file_operation状态，复用现有video_snapshot与下载命令，未增加
远端HTTP写入或IPC命令。生产界面的帧和状态仍由core给出。

HTTP、账号与恢复
文件重命名/移动/删除和目录迁移本身没有远端接口。
恢复本地MV沿用/api/mlog/detail/v1 {id,type:"2"}读取最新详情；网络失败只使用同账号已有
MV缓存及经过完整核验的本地文件。不会为本地恢复请求play/mv/url或download/mv/url。
每一步绑定原SessionToken；源任务、文件锁和持久化记录按owner隔离。
跨进程文件锁在进程退出后由操作系统释放；文件意图、实际路径和续播点在SQLite中保留。
重启后不自动猜测未决文件路径：先继续/撤销文件操作，再显式播放恢复续播点。
检查点写入失败仍释放原生设备，展示错误；不把已释放视频伪装成继续播放。
取消发生在Prepared时恢复原路径；Cleanup不能撤销，需完成已提交的新路径清理。
整批目录撤销按既有日志逆序搬回，直到批次最终Cancelled后才允许恢复。

验证
core/tests/mv_local_files.rs共8项，使用真实文件/SQLite/跨连接重开与可控解码器：
1. 持有stop确认期间，改名不能提交路径或删除原文件；恢复位置/音量/速度。
2. 跨盘复制算法在MetadataCommitted中断，重开日志完成清理并恢复暂停状态。
3. 暂存复制后取消，原路径恢复，等候期间的暂停意图生效。
4. 播放中Delete/Forget均停止且不转网络，分别删除/保留实体。
5. 目录子任务完成后保持等待，整批提交/逆序回滚后从最终路径恢复。
6. 等候时Stop、选择其他视频和切换账号均撤销旧恢复。
7. 文件意图取消尚在加载的解码器；媒体焦点交接后恢复为暂停。
8. 检查点存储失败仍释放设备；新session/actor重开日志，未恢复操作前拒绝显式本地播放，

边界
copy_only验证实际复制/校验/发布代码，不冒称在当前环境物理跨盘或Windows/macOS实测。
原生MV播放占用协调不代表所有其他媒体库入口都已使用相同租约。
文件操作通过本core持久化契约进行；外部程序任意修改文件不是该协议的一部分。
此项补完MV文件联动，不代表剩余MV业务或整个桌面目标完成。
