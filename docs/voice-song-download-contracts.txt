Cumulus 本批只实现有明确普通下载权限、已经喜欢的单曲前置，不接 IPC 或 UI。
- prepare 只接 epoch/playId/卡片回执/行号；仅解析原生保存的普通歌曲行。
  同时校验签名卡片、账号资料、喜欢读取和下载授权接口使用同一唯一 MUSIC_U、
  设备及凭据版本。只读本机喜欢快照、单曲任务及有效的同账号本地文件映射；
  无喜欢快照或操作仍待核对返回 membership_unknown，不默认为未喜欢。明确
  未喜欢返回 playlist_required，不能调用 start 继续。已有下载/任务不重复创建。
- start 接同一卡片范围与现有 DownloadOptions，重新检查本地匹配、喜欢快照和
  当前权限。普通任务在持有下载目录操作锁时最后一次核对；准备中失效会移除
  私有暂存目录而不保存任务。提交后由现有 DownloadScheduler 执行普通歌曲权限
  和传输；不会借用播放试听、当前节目授权或从行权利推断下载 URL。
- 后续接入点：同一行回执派生「下载到歌单」选择；将用户显式选择的目标交给
  受同一 SongCard 范围保护的现有歌单写入日志，而不是用任意 renderer songId。
  Directory/options 可复用 DownloadDialog，确认时调用该受保护的原生入口；
  不能直接降为普通 start 歌曲列表。当前未喜欢、已购专用音质、云盘、付费提示
  及该入口的桌面布局/平台交互仍待各自接入。不得自动支付或改已有真实歌单。

验证：合成签名 EAPI 夹具检查未喜欢/未知/不可用无写、确切普通歌曲授权参数和
任务去重、权限拒绝保留下载管理记录、旧卡片及节目停止后的拒绝；独立本地测试
在准备目录后使许可失效，检查无持久任务、无暂存目录。没有使用真实账户或服务。
