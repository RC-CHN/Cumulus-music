Cumulus 实现有明确普通下载权限的已喜欢分支，以及未喜欢时选择已有或创建自建歌单的
原生分支与主窗口 IPC。页面入口和实际桌面流程尚未接入。
- prepare 只接 epoch/playId/卡片回执/行号；仅解析原生保存的普通歌曲行。
  同时校验签名卡片、账号资料、喜欢读取和下载授权接口使用同一唯一 MUSIC_U、
  设备及凭据版本。只读本机喜欢快照、单曲任务及有效的同账号本地文件映射；
  无喜欢快照或操作仍待核对返回 membership_unknown，不默认为未喜欢。明确
  未喜欢返回 playlist_required，不能调用直接 start 继续。已有下载/任务不重复创建。
- start 接同一卡片范围与现有 DownloadOptions，重新检查本地匹配、喜欢快照和
  当前权限。普通任务在持有下载目录操作锁时最后一次核对；准备中失效会移除
  私有暂存目录而不保存任务。提交后由现有 DownloadScheduler 执行普通歌曲权限
  和传输；不会借用播放试听、当前节目授权或从行权利推断下载 URL。
- choose_playlist 只接受卡片行和用户显式选择的歌单 ID；通过同账户签名凭据
  读 `/api/v6/playlist/detail`，必须是当前账号拥有的普通可编辑歌单。沿用既有
  独占写锁和日志，发一次 `/api/v1/playlist/manipulate/tracks`，仅原生解析的
  单曲 `trackIds`、选中 `pid`、`op=add`；M/3160 fav→M/232:662–693→M/15:2099
  不传普通编辑流程的 `imme`。M/3085:779–783、M/21:362 的收藏 `subp` 门控
  不放行真值非正的歌曲；已喜欢直接下载不取用该收藏权限。发送前复核
  卡片和 Cookie 范围。已经存在时按现有 Unchanged 处理，不再发 add。
- picker_status 默认只读原生绑定的操作；显式核对只回读详情，不能重放 add。
  已确认、无变化或已发出且服务明确拒绝并完成回读，才给独立的一次性继续凭据。
  最后一种保留原版已有歌单回调 false 也继续的行为，仍显示收藏失败；未发出、
  过期、身份变化或结果不明无法绕过。旧卡片失效不影响既有独立歌单日志核对。
  `phase` 是日志的回读状态，`addFailed` 是原生有证据的写入失败；二者可能不同。
  例如另一个客户端已加歌导致回读确认成员关系，也不能把这次明确失败写入
  说成成功。界面只在 `continuation` 非空时才开放下一步。
- start_from_playlist 以同账号、同卡片/播放/行及同一已完成操作的一次性凭据启动；
  确实持久保存任务时消耗凭据，媒体授权和传输仍由原下载调度处理。弹窗未选择
  目标时不触发写。目录和选项可复用 DownloadDialog，仍须走此原生入口。
- create_playlist 必须显式提交名称与隐私，不接受默认自动提交。用独立的创建和加歌
  两条日志。原生确认返回的 ID 属于本账号、是创建前没有的匹配歌单，且创建实际
  收到成功响应时才串联首次加歌。含糊的创建结果可以显式只读回读；确认以后，只有
  另一次显式 add_created_playlist 才能发出尚未建立日志的首次加歌。任何已有 add
  日志都只回读，不会重新创建或重发写请求。新建目标必须有确认的加歌；已有歌单
  的 add=false 继续例外不适用于新建。播放/卡片失效时保留已发送动作的独立日志，
  不从新卡片恢复旧写，也不自动删除已创建歌单。已购专用音质、云盘、付费提示及
  实际桌面流程仍待独立接入。

主窗口服务对象为 `{target:{epoch,playId,receipt,index}}`，不接歌曲、节目或任务 ID。
已有目标另传用户选择的 `playlistId`；新建另传 `name` 和明确的 `private`。状态
查询只在显式点击核对时传 `reconcile=true`；创建回读后未写加歌的情况下须另调用
`player_voice_song_download_add_created_playlist`。共享下载选项确认时，根据来源
调用 `player_voice_song_download_start` 或 `player_voice_song_download_start_from_playlist`
并传入原生继续凭据。通用 `start{song_ids}` 不能作为此入口的降级行为。

任务去重、权限拒绝保留下载管理记录、旧卡片及节目停止后的拒绝；独立本地测试
在准备目录后使许可失效，检查无持久任务、无暂存目录。已有歌单用例覆盖回调
成功/明确失败/已存在、外部歌单、挂起详情或写入之前换节目、丢失响应后只回读、
错行/重复凭据及下载媒体仍独立授权。新建用例覆盖显式私密与公开、确认创建再加歌、
新建加歌拒绝、创建响应丢失后只读确认再显式继续、创建已发送后换节目不能加歌。
