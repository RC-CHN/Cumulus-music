Cumulus

- Rust 只为普通队列中具备一致在线歌曲 ID 的目录条目或目录歌曲下载投影 `likeSongId`。
  主窗口命令 `player_queue_like` 接受账号代次、显示队列版本、条目 ID 和明确
  目标布尔值；Rust 重新读取同一队列快照，拒绝过期、隐藏、非歌曲或非普通
  队列条目，然后用原生解析出的歌曲 ID 进入账号的通用喜欢用例。
- 打开队列或显示图标不会写入。明确点按后，账号用例读取 `/api/song/like/get`，
  记录原状态和目标；有变化时只发送一次写入。确认回读成功才更新心形状态。
  丢失回复留在原账号的本机日志；队列提供原有「核对喜欢状态」窗口，核对只读，
  不重放写入。窗口关闭后优先把键盘焦点还给原来那首歌；若该行不再可见则回到
  队列关闭按钮。喜欢操作不选择播放行、不重开解码器、不移动或删除队列项。
- 目录歌曲下载使用原歌曲 ID，前提是确认原生任务不是声音或云盘下载、且展示资料
  的 ID 与原生歌曲 ID 一致；不会把下载任务 ID 当歌曲 ID。官方的本地喜欢、云盘
  匹配、声音、私人 FM、房间和迷你播放器属于各自分支。
