下载行菜单、确认与文件操作（2026-10-31）

官方证据
- DownloadedTrack.tsx / DownloadedVoice.tsx 将分类、关键词、排序与 Scene.download
  交给对应 Viewer。DownloadingTrackViewer.tsx 同时提供暂停/开始、删除下载、更多。
- 官方 hybrid/app.chunk.1482700000000.js 中资源菜单的有序定义为：播放、下一首
  播放、查看评论、分隔、收藏、下载、分享、歌手/专辑/来源/主播、复制链接、
  上传网盘、打开文件所在目录、分隔、删除下载及其他场景的移除动作。每项有
  scene/resourceType/下载状态检查，不能把整个定义当成每种资源都显示的菜单。
  已下载资源的下载项会隐藏；艺人/专辑等主要针对播放列表/迷你栏，上传项针对本地。
- 官方 24.chunk.1482700000000.js 中未完成任务 cancel 会确认“确定将该资源从列表中
  删除？”，下载文件移除也有“确定删除下载文件？”分支。当前保留社区客户端的
  明确文件说明；不自动调用任何支付、公开分享或邀请。
- 没有使用 YesPlayMusic。重命名、移动、仅移出列表及文件管理入口是既有 Rust
  文件业务在 Cumulus 菜单里的附加动作，不冒充已证明的官方菜单项/尺寸。

实现与入口
- downloadMenu.ts 定义可用动作与顺序，DownloadRowMenu.vue 显示同一 ActionMenu；
  DownloadTrackTitle 只发入口事件；DownloadTable/DownloadPage 分发领域动作。
  普通行右键、行/更多按钮 Shift+F10、更多按钮都打开相同菜单，不直接进入管理页。
- 已完成歌曲/云盘原文件：播放、下一首、评论、分隔、收藏、分享、复制链接、
  打开文件所在目录、分隔、删除下载；附加区为重命名、移动、仅移出列表、文件管理。
  不对已完成文件重复显示下载。公开歌曲链接不包含授权参数。
- 声音按程序资源处理，不能把音频 songId 当 voiceId，也不提供歌曲收藏/分享/复制。
  有 voiceId 才显示声音评论，走已有 voice 评论入口。声音收藏/分享的完整官方资源
  菜单仍需另行恢复与对齐，当前没有用歌曲接口冒充。
- 未完成任务显示暂停或继续、删除下载。行内暂停/继续仍可直接执行；行内删除和
  菜单删除均先打开同一个单任务确认。没有把“删除任务”变成删除已完成文件。

业务调用及状态
- 播放继续使用完整筛选 downloads PlaySelection，从对应任务开始，不能只播放
  当前渲染节点。下一首走 playerAction(queue_downloads, task_ids=[任务ID],
  expected_queue_revision)，保留离线任务身份、当前 entryId/playId 和暂停状态；
  不通过在线 songId 请求流地址。原生空队列行为与边界沿用下载批量队列实现。
- 评论走既有 trackComments：有 voiceId 用 voice，否则 track。收藏打开既有
  PlaylistCollectDialog，分享打开既有公开链接分享窗口；不会直接发布内容。
  复制使用既有 copyText IPC；失败保留重试入口，等待期间保留按钮并阻止重复请求。
- 打开目录用 openDownloadDirectory(epoch, taskId)。这次新增入口调用绑定；本轮
  菜单专项不自动打开本机文件管理器，不宣称该 OS 外部窗口已新做实机验收。
- 重命名、移动、删除、仅移出分别进入 file 窗口的具体确认阶段；输入获得焦点，
  空文件名/空目录不能提交。按钮和标题说明当前动作，返回可看完整管理入口。
  调用 rename、move_to_directory、file/delete、file/forget 等既有 Rust 命令；
  完成依靠原生日志/后台 worker，不用前端改路径模拟。冲突保留原文件并显示错误。
- 文件窗口从最新可用视图解析同一个任务；缺失、状态改变、路径改变、已在整理、
  已知读取失败时禁用提交。账号 epoch 改变不能让旧窗口使用新账号记录。
  原生核心仍负责当前任务、实际文件身份、账号与并发校验；前端检查不替代它。
- ActionMenu 关闭时若原行的更多按钮已因失焦隐藏，先聚焦父行再聚焦按钮，以便
  后续 ModalTransition 能记录真实入口。菜单外滚动时焦点交给原行/列表；虚拟
  回收或记录删除后不聚焦已脱离 DOM 的按钮。读取失败时菜单动作保持禁用。
- 控制或文件写入等待时确认按钮和关闭按钮禁用，重复点击不会再提交。失败/取消
  不伪造完成；结果提示和 DownloadOperations 保留原有恢复入口。

验证与剩余边界
- 单元策略覆盖歌曲动作顺序、声音 ID 分流、清理中/取消中/读取失败/FM 等可用性；
  UI/文件证据按层记录在 ui-ux-validation.txt，不把测试数当作官方一致性比例。
- 当前菜单不包含官方评论数量、原生热键提示、社交分享渠道、完整声音收藏等尚未
  恢复或核对的分支；文件附加项属于社区适配。Windows 实机外观、真实封面和
  当前真实账号的远端写入未由这批合成验证证明。下载的多层历史已由 download-navigation-ui-contracts.txt 后续专项实现，其他资源页继续审计。
