Cumulus 外观与交互验收（2026-10-28）

范围
本轮检查编辑入口、歌单卡片、主题、弹窗、键盘焦点、窄窗口、空态与读取失败状态。
使用实际 Tauri + WebKitGTK 窗口、正式生产前端与 IPC；合成账号隔离业务数据库和 WebView 存储。
这不是在线歌单写入/会员业务重验，也不替代其他业务验收文档。

官方依据与差异
- references/ui-recovery/sources/packages/pc/src/pages/playlist/views/Common.jsx：
  官方歌单标题旁的 button-edit；本实现将有权限的编辑入口放在标题旁，收藏歌单不显示编辑。
- 同目录 pages/decoration/views/SkinPage/components/Official.tsx、components/Header/index.jsx：
  官方浅/深皮肤与顶栏外观入口。新增顶栏调色盘，提供跟随系统、浅色、深色。
- 本轮未使用 YesPlayMusic。没有完整官方皮肤 token 的恢复证据，因此语义配色为重建，
  不宣称像素级复刻；歌单卡片右上角菜单是本产品的布局调整，沿用已实现的编辑/排序用例。

实现
1. frontend/src/styles/tokens.css 为界面、表格、侧栏、播放器、菜单、表单及弹窗提供语义颜色。
   保留图片、二维码黑白模块、会员卡片金色及媒体内容本身的颜色，不做整体反色。
   原生表单 color-scheme 与有效主题一致；灰色文案、歌词逐词高亮和错误状态同步适配。
2. 本地键 cumulus.appearance.v1 仅存 system/light/dark，不涉及账号凭据。
   public/appearance.js 在首屏样式前应用偏好；Vue 订阅系统配色与跨窗口 storage 变化。
   无效偏好回到系统；存储异常不阻断界面，选项仍可即时应用并显示未保存提示。
3. 主题切换使用现有应用层的短透明度动画，减少动态效果时直接切换，不重新挂载播放器。
   本机 WebKitGTK 2.52.6 在 startViewTransition 调用后出现 UI 进程 SIGSEGV；隔离同一窗口、
   同一操作移除该调用后可继续。最终实现不用该 API，避免把运行中的崩溃交给启动回退处理。
   这是一条本机复现证据，不是对所有 WebKit 版本的结论。
4. 歌单卡片移除常驻“编辑/上移/下移”整排按钮，改为右上角菜单，支持右键打开。
   菜单 Teleport 至 body，定位限制在窗口内，不受列表滚动裁切；滚动/缩放/点击外部关闭。
   上下键、Home/End、Escape/Tab、禁用项跳过和焦点返回均处理；仅打开时注册全局监听。
   面板可见性提交后再设置焦点，修复对隐藏面板 focus 无效的问题。
5. 编辑弹窗自动聚焦名称；中文加权字数、超限/非法名称反馈与保存禁用保持核心约束。
   封面缩至侧边，窄窗口进一步缩小，保存区保持可达。封面子弹窗与均衡器加入进出动画。
   原生 dialog 离场后再恢复焦点，嵌套封面关闭后回到父弹窗，父弹窗关闭后回到页面入口。
   小窗口均衡器压缩滑杆并设置最大高度，避免底部操作越界。
6. 云盘初次读取失败显示重试页及未知计数，不显示“空云盘”的上传引导；下载读取失败
   也不会被当作“还没有下载歌曲”。已有缓存内容仍可保留并提示刷新失败。
