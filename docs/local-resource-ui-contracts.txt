实际发现与修复
1. 离开后返回本地页，原查询仍筛选列表，搜索框却重新变成空值。搜索草稿现在从
   同一 LocalQuery 初始化，离开页面前同步提交尚未到 10ms 的完整输入。旧页面
   的计时器只属于原 visit；隐藏、重新进入或销毁后不能覆盖新页面输入。
2. 发出新查询后，旧行仍可播放，导致新查询配旧行/revision。本地快照现在绑定
   keyword/sort/descending/group/groupKey/includeMissing/offset/limit；revision
   仅作为索引前置条件，不作为显示条件。新条件没有成功结果时不显示旧行。
   loading、读取错误或写操作进行中，播放处理函数和按钮都拒绝旧行播放。
3. 读取失败曾与命令失败共用错误；正常后台轮询会清掉扫描失败提示。现在
   readError 与 command error 分开，读成功只清读取错误。扫描失败带具体动作，
   必须由用户再次执行该动作，不以“重读列表”冒充重试扫描。
4. 登录后本地/CUE 曲目进入队列，native_like_selection 曾直接按线上歌曲映射
   解析，导致 mini_snapshot 报非正整数 ID。现在复用主播放器资源投影，未关联
   的本地/CUE 无线上喜欢目标；已下载歌曲保留真正的线上 song/voice ID。
   迷你窗口、系统媒体与快捷键继续共享原播放器、账号及队列控制边界。
5. 原生重新扫描执行期间按钮会禁用，WebKit 因此把焦点移到 body，结束后不会
   自动恢复。现在选择目录、重新扫描、暂停/恢复扫描完成后，若仍属于同一次
   本地页访问且焦点没有移到其他控件，返回原可用按钮；离开页面后不抢回焦点。

搜索与错误交互
- 普通输入 10ms 后发起实际 typed local_page；保留用户输入中的空格。Rust 查询
  仍按原契约处理 trim/casefold，不能用结果文本反向改写输入框。
- 中文输入法组合中不发送中间拼音，compositionend 提交完整文字。这是为避免
  不完整输入干扰结果而添加的社区交互约束；原 FlexSearchInput 的组合分支并非
  完全相同，不能称为逐行复刻。切换分组同时取消待发输入/组合并清空关键词。
- 清空按钮保留搜索框焦点；歌曲/歌手/专辑/文件夹共用权威查询。分类键变化会
  重建输入控件；不从旧类别的延迟回执恢复文字。
- 首次或新条件读失败显示“本地音乐暂时无法读取”及“重试读取”，不显示空库
  引导。确实无匹配显示“没有匹配的本地音乐”，与失败、尚未扫描明确区分。
- 同一查询后台读失败保留已有行并禁用依赖它们的动作；1500ms 可见页轮询仍为
  只读。显式重试成功后，如果原重试按钮移除且焦点落到 body，返回搜索框。
  新焦点已由用户移动时不抢回；失败仍保留可见的读取重试入口。
- 扫描失败不销毁索引，不自动重放命令；后续正常轮询不隐藏命令失败。显式
  重新扫描成功清除该提示。已有 native snapshot_changed 回第一页规则保留。

跨页产品约束
云盘删除仍使用冻结的确认计划及单独的本地文件选项；本批不增加 HTTP 接口。
选择删除本地下载文件：真实文件、完成下载记录、离线登记、本地索引以及队列
中的该文件条目一致移除。返回下载页仍保留原搜索值，不能显示旧完成行；返回
本地库重新读取；原队列中其他条目、CUE 身份及暂停状态继续有效。
不勾选本地删除：云盘记录删除后，已完成文件和下载任务保留，下载页可继续
从已验证的离线资源播放，不因云盘删除重新申请在线音源。
CUE 对应整文件保护沿用组合删除预检，不允许误删共用音源。

本地歌曲所在目录
官方恢复 hybrid_app.chunk.1482700000000.js/556.js:779–805 在 Scene.local 资源
菜单提供「打开文件所在目录」。本地行右键、Shift+F10 或更多按钮进入同一个菜单。
关闭菜单后返回原按钮；旧查询或行记录已变化时撤下动作。无法打开保留独立错误提示，
不会重试播放或自动扫描。更多按钮和焦点处理是 Cumulus 的键盘适配。
typed IPC open_local_track_directory(id,revision) 仅主窗口可调用：前端只交还
当前索引的 ID 及版本，不提供目录路径；设备本地库不依赖账号联网。Rust 重新查询
记录并核对文件、CUE 及其音源指纹，再从已索引的规范路径计算父目录。CUE 打开
物理音频目录，NCM 打开原文件目录；不会触发解密或打开缓存。不新增业务 HTTP。
Linux 合成桌面用例通过系统启动入口的受控替身核对完整单参数路径，不打开文件管理器
窗口；Windows 用例只核对拒绝过期引用和 UI 调度，不视作 Windows Explorer 验证。

从本地列表删除
官方恢复 M/556:939–942 把「从列表中删除」与 :977–993 的磁盘删除分开；
async_localList.removeItem（M/2304，动作转录 :747–798）调用原生 deleteItemList，
以 removebyid 标记目标，并在仅列表删除时保持 removefile=false。本实现只接通
非物理删除：现有 local_command 新增 hide_track{id,revision}，仅主窗口可调用。
Rust 以索引锁内的实际 ID 和版本核对，原子写入设备本地的隐藏版本记录；旧引用
报 snapshot_changed。文件、同 CUE 的其他分段、原队列已持有的资源与下载记录
保留，不触发线上 API。列表和匹配查询省略该版本；文件管理继续检查完整索引。
定时监视及重启不撤销隐藏记录；检测到新的文件版本可重新出现，用户显式「重新扫描」
会恢复原隐藏版本。这是 Cumulus 在持续监视下的可逆处理；不宣称还原官方原生
重扫策略。本批不实现「从本地磁盘删除」。

本地分组宽度
官方 LocalMusicCategory.tsx 在分组模式支持调整左栏；恢复 M/461 的边界为左栏
155px、曲目区 460px。Cumulus 用实测容器宽度扣除曲目区与 20px 分隔区，限制
鼠标拖动和键盘方向键/Home/End；拖动预览按帧合并，Escape 或失焦取消。可用
空间不足时退回 120px 左栏并隐藏分隔控件，不将临时收窄覆盖设备的宽栏偏好。
宽度仅作为 WebView 界面偏好保存，不改变目录、搜索、选中分组或播放资源。
Linux WebView 合成回归 30 项通过，另保存 30 张截图；窄窗焦点回到已选分组，
拉宽恢复拖动后记录的宽度。Windows WebView2 仍由跨平台 CI 分开验证。

  官方 XTableViewer/Row.tsx handleHotKey 在本地歌曲行把 Delete/Backspace
  交给 removeFromLocalList，并过滤长按重复。Cumulus 接到同一个版本校验与列表

  屏蔽长按重复；待查询、失败或行已替换时不能执行。行消失后仍遵守既有焦点回退。

本地单曲菜单的播放和下一首

本地列表排序反馈
官方 LocalMusic.tsx 将 TableViewer 的列名和 forward/reverse 状态传给播放全部与
列表动作。Cumulus 的标题、歌手、专辑、格式和时长列统一显示当前升降序，并通过
aria-sort 只标记实际选中的列；沿用 Rust 本地查询和同一队列选择条件。
排序读回重建表格时，仅在焦点随旧表头丢失且查询未变的情况下恢复原列焦点。
合成桌面探针使用 WAV、CUE 和 NCM 文件确认时长升降序、方向提示及焦点，
并接续原有本地队列和原生播放验证。
若用户在输入防抖期间立即点列标题，关键词和排序合成一次原生列表读取，
不以旧查询覆盖输入。IME 未提交文字不参与排序请求；提交时沿用新排序。

歌手、专辑分组顺序
官方 ArtistOrAlbumList.tsx:185–194 按拼音排序，再将未命名组显示为「其他」
并放在末尾。Cumulus 使用 WebView 的中文拼音排序展示，不改变 Rust 分组键、
计数、队列或目录树顺序。用实际索引的 CUE、NCM、WAV 核对「北京、上海、
其他」顺序，以及按组点击仍读取正确的本地曲目。

分组切换焦点
歌手、专辑、文件夹及「全部」共用查询绑定的焦点恢复。只有当前读取重建列表、
旧焦点落回页面时，才定位到新表中的同一分组；切换查询或用户已经移走焦点时
不抢焦点。桌面回归通过原生分组查询验证具体歌手、专辑、目录及返回全部。
选分组或切换「显示不可用文件」也会把仍在防抖中的关键词合入同一次读取，
避免先用旧关键词查询。切换歌曲／歌手／专辑／文件夹分类仍按原交互清空搜索。

文件夹树键盘导航
方向键左右展开、折叠或在父子目录间移动，上下及 Home/End 移动可见行焦点；
Enter 或空格仍通过原按钮选择目录。导航不会查询或修改原生选中目录。
这是恢复官方树状目录后补齐的桌面键盘交互，保留独立展开按钮和 Shift+F10 菜单。
