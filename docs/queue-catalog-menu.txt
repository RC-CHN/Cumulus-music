播放队列普通歌曲菜单

官方依据：网易云音乐桌面 3.1.42.205594。恢复的
`PlayingTrackTitleCell.tsx:804–826` 和 M/3113:443–459 在「更多」上派发
`Action.menu`、`Scene.playingList` 和该行包装对象。右键由 M/405:225–247
和 M/392:49–68 取得同一父场景。M/106:206–223 负责点击选择，M/352:742–753
仅在多项保留时交给菜单多选上下文。

- M/556:83–195：普通条目为播放，当前播放的同一条目为暂停；播放列表场景不显示
  下一首播放。评论数从 `/api/resource/commentInfo/list` 读取，普通歌曲
  `resourceType=4`，`resourceIds` 为原始字符串 ID 数组的 JSON 文本；失败时保留
  无数字入口。选中多项时隐藏评论、分享和复制链接。
- M/556:362–377,664–686,834–856：完成下载的歌曲不再显示下载，按本机下载
  记录提供打开所在目录。歌手和专辑取歌曲资料；「来自」独立取入队时保存的
  文本和去向。搜索来源只有文字，不提供链接。
- M/3085:350–376,768–774,2822–2848,3734：播放仍作用于被点的条目，
  收藏、下载和移除可使用当时的选择；移除是本机播放队列操作，不删任何歌单。

Cumulus

- Rust 从账号代次、队列版本和条目 ID 取得当前普通歌曲，处理评论计数和本机
  下载状态后再次核对同一快照。计数两秒未返回时保留入口，旧快照不出菜单。
  文件路径留在 Rust；目录项现可绑定唯一可核对的完成下载或账号已匹配文件，
  详见 queue-catalog-file-reveal.txt。
- 队列面板共享弹层定位、键盘和焦点逻辑。悬停／聚焦「更多」或右键可开菜单；
  点击其他未选行时选中该行，右键已选行保留组。显示的多选顺序来自当时的选择，
  操作前再次核对队列和选择。播放、暂停、移除走现有原生队列控制，收藏／下载
  使用现有目标选择或下载确认。右键／更多的「收藏」和行内按钮共用只读
  `player_queue_collect_rows`：传入当时的有序队列条目 ID，由 Rust 重新核对账号、
  版本和目录资格，再打开选择目标的弹窗。取消后恢复入口焦点，不写目标歌单。
  分享只打开本机对话框，复制的是普通公开链接。
- 已核对的专辑、艺人、歌单显示入队时保存的来源名；无显示名仍用来源类别显示，
  不从歌曲资料补造来源名。菜单继续独立保留来源路由；搜索仅显示文字。
  恢复的 MockMenu 只给出 180px 最小宽度，未确认原生窗口的长文字上限。
  Cumulus 限制来源文字的显示宽度并保留完整的可访问名称，避免长专辑名撑宽整列。
  本菜单仅接普通目录歌曲；含非目录歌曲的选组不提交部分操作。普通在线声音走独立
  的 `queue-voice-menu.txt` 契约。本地、下载资源行、云盘、FM、房间和减少推荐
  实验菜单需独立验收。未模仿原版分享埋点或未证实的操作。

验证入口：`scripts/ci/catalog_smoke.py --album-duration-sort` 覆盖实际
Tauri WebView 的「更多」和右键、其他歌曲计数、计数失败、来源与专辑区分、旧
队列拒绝、多选动作和移除，以及当前歌曲从菜单续播和暂停复用同一解码实例。
本机 Linux 合成回归通过 28 阶段并留有截图：
`.build/ui-proof/post-rc-queue-compact-menu-r1/report.json`。多选收藏通过同一
原生入口取到两首，实际列出合成目标歌单；取消未写入，保留原队列、选择顺序、
暂停位置和解码实例，焦点回到入口。完成下载时目录项的显示规则另由前端测试验证；
该夹具不调用真实服务，也不打开实体文件管理器。
