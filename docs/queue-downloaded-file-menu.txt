Cumulus
- 普通主窗口队列中，具有已发布音频下载任务、固定媒体 ID 和原生路径形状的
  单曲/声音投影 downloadMenu: song/voice。More、右键和 Shift+F10 共享菜单、
  选组、播放/暂停及焦点归还。单曲保留既有的版本绑定收藏，歌手/专辑只有
  本条目的有效原生元数据 ID 才导航。声音没有歌曲、歌手、专辑或主播动作。
  「来自」在已证实由下载页面入队时跳对应的已完成分类；不在历史条目上猜来源，
  同一已完成分类不重新入页。物理下载文件不会被队列移除动作删除。
- 定位 IPC 只接 epoch、queue revision、entryId，仅主窗口。原生取出同一可见
  普通队列条目的任务 ID、媒体/节目绑定和已记录路径，再核对同一账号内的
  Complete 任务、发布目标、原生离线账本、文件形状及完整内容哈希。检测到
  路径迁移时在打开文件字节前拒绝旧路径。分离歌与声音类型验证，不能把声音的
  主音频 ID 当成歌的下载。不会给渲染器发送队列任务 ID、文件路径或授权 URL。
- 系统交接前核对同一已验证文件和队列身份；失败不扫描同 ID 的替代任务、不换
  目录/缓存文件、不续会员或另取音源。文件路径交接仍存在操作系统外部进程在
  交接后替换文件的边界。Linux 只在明确不支持选择时用既有的受检父目录回退。
  云盘下载、MV、FM、心动、一起听、线上歌曲/声音自己的下载关联入口和迷你队列
  不复用本菜单。缺少旧版发布证据的条目显示文件不可用。
- M556:174–213,437–457,738–761 的已下载评论、分享和官方复制链接属于独立的
  资源与权限分支；本批不以普通在线菜单伪造它们，也不从 NCM 后缀猜付费提示。
  桌面自带下载页自身的菜单和顶部「打开下载目录」不改变。
