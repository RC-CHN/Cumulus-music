Cumulus 的本次范围
- 普通主窗口队列里，只为带本地索引 ID 和资源版本的条目提供这个菜单。游客可定位；
  登录用户使用当前自己的播放队列。FM、心动、一起听房间、线上目录、下载资源、
  云盘、声音和仅由系统打开的文件保留各自边界，迷你队列不投影新入口。
- 「更多」、右键和 Shift+F10 共用菜单、同一焦点回归及选组。顺序为播放/暂停、
  收藏、歌手、专辑、来源、原文件定位、移出队列。当前暂停时仍标「播放」，
  复用已加载的 CUE/音频实例；对非当前项使用原生选曲。收藏使用同一捕获选组，
  未登录打开登录窗，已登录只支持 Rust 已验证的线上关联/目标歌单，不代填本地
  占位、不上传文件。未关联时说明不能收藏，不改已有歌单。原本的 local 收藏、
  文件和标签状态均不因显示菜单变化。
- 本地文件标签不含可靠的歌手/专辑目标 ID，所以只显示这两条文字，不按同名猜
  路由。有明确 local 来源才提供跳回本地音乐；历史入队的本地音频可以定位，但
  不从文件标签猜历史去向。条件式的已匹配评论、在线分享及官方复制链接不是本批
  分支；没有借普通目录歌曲菜单补造目标、权益或 commentThreadId。下载资源包装
  的文件定位是独立分支；原研究的加密付费提示不能由 NCM 扩展名推断。
- player_queue 仅新增 localMenu 布尔能力。定位 IPC 只接当前 epoch、队列 revision
  与 entryId，仅主窗口。Core 从普通队列的可见条目提取同一 local_id 与原生
  LocalRevision，在索引核对可用文件、物理路径及版本。CUE 检查原音频和 cue sheet
  的规范路径和指纹、定位音频；NCM 定位原始容器，不开缓存。该本地指纹包含文件
  大小、mtime 和平台身份，沿用本地索引契约；不声称是完整文件内容哈希。
- 文件与账号/队列状态在系统调用前复核。队列变更、账号代次切换、路径替换、
  索引或源文件变化拒绝，不改定位目标或回退到另一个文件。Linux 只在系统明确
  不支持选择时用既有受检的原文件父目录回退；Windows 用原生 Shell 选择项目。
  系统接口按路径/URI 定位，不能原子防止交接后由外部进程换文件。Renderer 不接收
  路径、文件字节、凭据或下载 URL。
