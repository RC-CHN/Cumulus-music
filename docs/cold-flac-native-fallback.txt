Cold FLAC: a same-handle fallback for a declined seek

The optional in-process decoder can reject a valid FLAC seek when the
compressed search exceeds its bound. Neither the absence of a SEEKTABLE
nor the presence of one predicts whether a specific seek fits. The probe
can check the requested sample before publishing an optional sink: lend
the already verified ColdOfflineFlacReader to the bounded decoder, run
the seek, and destroy the trial decoder before returning the borrow. A
recognized budget/capability failure may select stock playback; a bad
grant, stale request or unrelated decoder fault must not trigger fallback.
Preflight proves the attempted seek only. It cannot guarantee that every
future seek will fit, or that a malformed index is safe.

MpvEngine::resume_cold_flac_native is an explicit native-only seam. It
takes the same owned cold reader, absolute full-track position, paused
intent and active request cancellation. It accepts no path, task ID,
URL or new authorization, and does not select a queue item. The caller
must own the intended reader/position and use an idle native sink after
an earlier output has stopped or been destroyed. An already active
entry is refused without changing that entry.

The handoff revalidates the reader's full cold grant. The pinned registry
rewinds that same held file or strict NCM payload and the stock FLAC
demuxer loads it paused. Before exposing the load, the helper rejects
unknown or out-of-range positions and commands an absolute exact seek.
Only a settled native clock for the same entry within 10 ms of the
requested position counts; native pause must still be active. It checks
the request and source authority again, and resumes only when the caller
asked for a playing intent. Any failed handoff retires its provisional
entry under the protected Stop/destruction contract. It never silently
restarts from zero or reopens the replaced pathname.

For verification:

    cargo test --locked -p cumulus-core --lib limiter_cold_flac_fallback -- --include-ignored --nocapture

The Linux proof uses the real cold grant, strict NCM-FLAC, libFLAC and
libmpv null audio output. The two compressed fixtures have no seektable
and a sparse 8192-frame table respectively. It substitutes the original
path, observes the bounded optional seek failure without a published
sink, and feeds the held verified payload to stock mpv with paused and
playing intent. Both fresh decoder attempts at source frame 40500 stop
after 131072 compressed bytes. The native target is 0.918367 s; the
paused clock matches it and the playing clock advances from there. The
second test also exercises an occupied sink, an out-of-range target,
and a real account detach before handoff. These tests use synthetic
profile adoption only and start no decoder subprocess.

The opt-in active-seek proof starts a protected optional limiter sink and
waits for its clock and buffered PCM. A seek for another native entry is
rejected without affecting it. The current entry is retired with its
exact native Stop, then the bounded seek is tried on the worker. A typed
128 KiB read limit is eligible for the stock handoff; other decoder
errors do not take that branch. The worker lends its sole reader to
libFLAC. Reclaim cancels a separate worker gate and has a 3 s deadline.
The reader is transferable only after libFLAC and its callbacks finish
and the worker joins; retaining an old callback factory cannot keep the
worker alive or start another pass. On timeout no reader is returned.
Closing the worker does not cancel the account or source lease. The
native host validates the cold authorization again before publishing a
new sink. The fixture tests both transport intents, an invalid logical
seek that must not start a second sink, and an actual cold session
detach after reclaim and before stock publication.

    cargo test --locked -p cumulus-core --lib limiter_cold_flac_active_seek -- --include-ignored --nocapture

The stock helper remains explicit. There is no automatic fallback or
production decoder selection; the optional worker is compiled only in
tests. The production host must preserve the public playback identity,
retain and poll the cold reader's authority, and report unavailable if
the stock sink cannot confirm the desired position. A separate native
failure-injection proof covers synchronous sink destruction when exact
Stop cannot be confirmed; the active-seek fixtures exercise successful
Stop. No claim covers CUE/trial ranges, online Range semantics, actual
sound hardware or Windows native runtime. Optional FLAC/limiter remains
disabled by default.
