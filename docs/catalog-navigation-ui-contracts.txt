模块与所有权
1. useMusic为新目录访问分配独立catalogVisit；复制当前歌手路由切换标签保留访问ID。
   专辑切换替换当前历史项。页面实例key包含账号、资源和访问ID，排除标签，因此标签
   切换仍由原有内容过渡完成；离开到其他资源时页面确实卸载，不保留整棵隐藏DOM。
2. useCatalogWorkspace拥有最多8次访问的LRU，只属于当前authenticated账号代次。
   useCatalogSession拥有详情、动态状态、关注/收藏日志读取、各标签分页、评论上下文
   和阅读位置。CatalogPage负责布局、选择、播放/下载入口和恢复DOM位置。
   账号切换/失效及应用退出释放所有模型、观察器、草稿和位置；迟到结果由原有代次
   及新session.valid校验丢弃。新打开同一资源的访问有独立位置和分页前缀。
3. 评论交互抽为useCommentContext，持有writer、floor和定位输入；独立评论页仍自行
   拥有/释放，专辑页则使用账号会话拥有的上下文。它没有DOM、窗口或Tauri依赖。
   确认窗口随组件关闭，未提交草稿/回复、待确认意图、分页、楼层读取保留在模型中。
   连接只监听账号代次和资源key，元数据对象更新不再重新连接并清空草稿。

实际行为
- 歌手歌曲→专辑→某专辑详情→返回：恢复歌手专辑标签、已读40条前缀、内外滚动和
  原专辑卡片焦点。随后简介→返回专辑→返回歌曲，逐步消费原历史项。
- 专辑歌曲→评论→详情，当前历史长度不增长；离开专辑后返回仍是原标签。
- 全部歌曲返回歌手后再次进入，仍有当前访问已加载的55首及列表位置；明确的“返回
  热门歌曲”和全局返回均走同一导航保护，不另建一条相反方向的历史记录。
- 评论第二页输入未提交文字及定位编号→每日推荐→返回：仍是第二页、草稿和原阅读
  位置；重新读取的目标是当前查询，不能跳回第一页。导航不会发布文字。
- 每次重新进入一个目录访问都重新读取页头、动态状态和持久化操作日志，评论当前页
  适用时也重新读取。已访问的歌手子列表保留完整前缀，不因返回而替换成第一页。
  播放仍交给Rust核对query/revision和当前音源/权益，UI浏览记忆不授予播放权限。
- 关注/收藏在其状态重新读取期间及读取失败时禁用，不能拿旧布尔值反向提交。
  进入、退出、返回、重开只inspect/读操作日志，不自动set/reconcile/发布/删除。
- App在真正提交导航前记录当前位置；既有批量编辑/歌单编辑离开保护仍优先。取消
  离开不会先改变路由、丢掉草稿或触发新的业务操作。

滚动、焦点与加载版式
- 记录按artist:<tab>/album:<tab>分开，核对当前实际面板标识。进入钩子使用传入的新
  DOM节点，等待网格测量和虚拟占位提交，再恢复；初次重新挂载也走相同路径。
  旧恢复同时受会话有效性、面板key、恢复代次和节点连接状态限制。
- 用户滚轮、触摸、指针或非标签键盘操作取消未完成的恢复，避免回写新操作。
- 虚拟卡片的原焦点必须在滚动事件更新范围、Vue提交新卡片之后恢复；只有焦点仍在
  原返回按钮/页面body时才转移，期间用户主动聚焦其他控件则保留用户选择。
  首次实际导航在此处捕获真实焦点丢失，修正后再运行完整两组52态。
- 页头重新读取使用现有刷新/更多按钮内的旋转图标、aria-busy及屏幕阅读状态，不再
  临时插入一段会撑动页面的正文。实际合成服务在返回时受控等待，验证关注禁用、
  正在更新状态可读，释放后卡片纵坐标变化<1px；等待有5秒上限，不是业务重试。
- 目录标签和卡片采用与搜索页相同的内侧-2px焦点描边，圆角分别4px/8px；滚动容器
  不再裁掉上/下或右边界。减少动态效果时旋转及过渡遵从现有统一策略。
  这属于社区键盘反馈，不声称是官方运行截图的描边定义。

接口边界
- 沿用CoreClient.catalogPage / catalogMembership / playSelection、下载入口及原评论
  commentsPage / commentsFloor / commentsWriteOperations等类型化接口。详情、分页、
  权益、关注/收藏与评论的实际API/字段见artist-detail-ui-contracts.txt、
  album-detail-ui-contracts.txt及core-comments-contracts.txt。
- 返回读取调用正常catalogPage流程：先可显示本地只读快照，仍执行force远端读取；
  接口既有的query匹配、revision、缓存、失败和账号校验保留。没有把历史Python输出
  当成新桌面通过，也不在前端持有Cookie、签名密钥或完整授权音源地址。

保留边界
- 浏览记忆当前是进程内8次访问的LRU；超限或进程退出会释放未提交的前端草稿及阅读
  位置，尚无独立草稿落盘。这不同于已经持久化的发送意图/未决操作，后者仍由Rust
  日志恢复。本项没有宣称跨进程恢复未提交草稿或无限历史保留。
- 当前保存像素滚动位置，离开期间调整窗口/DPI后的按内容锚点恢复尚未专项验证。
- 没有新增WebView地址栏URL/deep-link/popstate路由，也未完成官方全部吸顶、搜索/
  排序、完整更多菜单、个人主页/自身账号与全部AB分支。其他页面沿ui-ux-audit继续。
- 没有Windows实机截图或物理声卡结论；null与合成音源不能证明在线音源/听感。
  完整目标保持进行中，不能以本专项或编译/测试数量宣布全范围完成。
