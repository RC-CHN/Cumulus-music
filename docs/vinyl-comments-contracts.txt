实验分组与实际请求的版本绑定
内嵌读使用固定的 VinylCommentRead（仅当前歌曲 R_SO_4 线程、60 条和
受限 offset），不经普通评论页的通用发送入口。该范围由原恢复 M182/M438
确定，不新增上游路由。已验证 t1 的凭据版本传到 MusicHttpClient::execute，
在同一个 HTTP gate 内、读取真实请求 Cookie 快照时核对。实验和评论两个
精确 PC EAPI 路径还必须同时拥有相同的唯一 MUSIC_U 与本机 deviceId；
凭据记录版本相同不代表两个 Cookie 路径属于同一账号。原有 token 准备后
的版本核对也继续生效。没有回退或 Cookie 扩域，通用评论页不受这条绑定
影响。响应的凭据版本在解析业务状态及写评论缓存前重新核对；播放和账号
身份仍按原用例的前后快照检查。

封闭传输验证使用真实 MusicHttpClient 和 EAPI 解包。在请求锁被其它请求
占用时先轮询旧评论请求，再通过占用请求的响应更换测试 Cookie：旧评论
未到达 HTTP 后端；重新取得 t1 后才观察到一个携带新凭据的准确续页请求。
另一夹具在同一凭据版本让实验/评论路径分别看到不同的 MUSIC_U，拒绝发出
评论。原生用例同时验证旧响应不会写评论页缓存，以及普通、节目和旧播放
身份的既有边界。测试 Cookie 为合成数据。
