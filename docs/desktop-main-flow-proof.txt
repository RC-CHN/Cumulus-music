Cumulus 桌面主流程验收

单进程桌面合成验收
  测试入口 desktop/examples/main_flow_ui_probe.rs 使用应用实际打包的
  Vue、Tauri IPC、MusicClient、播放器与 SQLite。只在测试入口注入
  封闭的账号/API/媒体替身，正式产品没有替换源或凭据开关。
  由登录态恢复出发，依次进入每日推荐、搜索，使用实际 libmpv 播放
  并暂停；创建、编辑和删除一张固定合成歌单；下载一首合成 FLAC，
  切断替身 API 和媒体传输后从完成列表播放本地文件。

  这一条链证明正式桌面和原生业务在同一进程内可以串接。替身中
  在线音源交给 libmpv 前替换为合成文件，解码走真实引擎，输出为
  null。离线阶段验证替身禁止网络、没有新增音源请求和传输，且
  从下载文件真实解码。它不证明上游 CDN、真实会员权益或声卡输出。
  验证脚本独立核对原始歌单集合、合成歌单回执、下载任务、实际
  文件和引擎进度。不会加载真实账号或设备身份。
  最终 Linux WebView 10 阶段通过；测试运行产生 9 张截图，本机
  KDE/XWayland 125% 又复核 9 张。截图见
  .build/main-flow-desktop-integrated/contact.jpg，完整计数与 SQLite
  核对结果见 .build/main-flow-integrated-webview/report.json。
  Linux 和 Windows CI 有独立入口；本机未实跑 Windows。
  复跑：构建 cumulus-desktop 的 main_flow_ui_probe example（开启
  custom-protocol），用 scripts/ci/main_flow_smoke.py --binary <程序>
  --root <新目录>；Linux 可在 Openbox/Xvfb 和私有 D-Bus 下加 --screenshots。
  当前构建复跑发现：身份刚恢复时，前端仍在读取歌单和推荐，侧栏显示
  可点击但会忽略导航。现在主导航在该阶段禁用，完成后立即可用。
  修复后用同一探针通过 10 阶段，保留 9 张截图及 SQLite 核对报告
  （.build/main-flow-startup-fixed/）。下载菜单另通过 33 个桌面状态。

真实服务证据与剩余边界
  当前真实服务证据来自独立的授权测试，不能合并计为一次完整
  运行。11 月 3 日扫码、凭据下发和重开身份见
  refresh-token-issuance-evidence.txt；它是原生探针，不是桌面扫码。
  当前搜索实现（d2772ff）另用该授权 PC 会话的一致 SQLite 副本运行
  Rust search_results_read：身份回读、官方搜索标签和十类结果均成功；
  查询词为公开艺人名，零资源写入，凭据副本在运行后删除。只记录分类
  成功标记，不在公开记录保留响应数据。它验证当前 Rust 搜索请求和
  类型化结果，与合成 WebView 的交互证据分开；没有取得播放源或试听。
  同轮另用固定只读桌面探针取得一个真实音源，验证 libmpv 时钟前进并
  正常停止。该探针不运行生产 Vue 或正式账号宿主，声道输出为 null。
  五条请求的计数、无账号写入及复跑方法见 search-playback-read-proof.txt。
  当前生产 Vue 树（46523f5）已在独立的有界只读宿主完成真实 PC 服务
  回读：校验本人身份、本人歌单、日推、默认搜索词、综合搜索和单曲搜索，
  六个端点各成功一次。另一个非预设关键词在转发前被拒绝。Linux 进程
  仅有 loopback、无路由和宿主代理，通过唯一核对 CONNECT 与 TLS SNI 的
  私有 broker 出网。原始凭据记录与使用后的副本一致；复核后删除凭据与
  本机账号缓存副本。匿名报告 .build/main-flow-live-readonly-summary.json。
  本轮没有播放或下载媒体、歌单写入、续期，也没有运行正式 guardian 宿主。
  第一次线上尝试没有确认单曲回包，不计为通过；第二次限定等待实际单曲
  表格和成功回执后通过。隔离复跑程序保留在 research/main-flow-pinned-readonly。
  后续受控播放已用同一界面和单曲菜单跑到实际歌曲详情与音源授权；预设的
  单曲没有扩大为整页队列。首次记录一次媒体读取尝试但没有成功的解码；
  加入阶段诊断后，复验的八个业务回执都成功，媒体请求和 CDN 拨号均为零，
  尚不能确认两次卡在同一位置。正式页面的真实同会话播放仍未通过。
  两轮均无账号资源写入，凭据副本已清理。脱敏记录：
  .build/main-flow-live-audio-first-summary.json 和
  .build/main-flow-live-audio-diagnostic-summary.json。
  后续同回包监督复验（隔离研究提交 75784b5）通过上述八项读取：应用只
  使用同一次授权返回的 CDN，独立校验证书后只建立一次媒体隧道。实际
  媒体读取 HTTP 200，字节长度与 MD5 和授权回包一致。随后验收探针的
  私有文件句柄解码入口拒绝了格式（decoder_unsupported），原生播放
  时钟未推进。记录未识别媒体格式；该入口的格式限制不能用来判断生产
  libmpv URL 路径是否也失败。无账号资源写入，凭据副本已清理，媒体
  文件未保留。脱敏证据 .build/main-flow-live-supervised-summary.json。
  临时私密歌单编辑的隔离策略也新增了独立详情回读：完整字段一致才可
  计为编辑成功，应急清理不替代验收，未执行真实歌单修改。
  历史真实桌面目录 .build/ui-proof/ 下可检查 run-2-small 的账号
  恢复/推荐/歌单/搜索，player-6-small 的播放控制，
  playlist-3-small 的临时私密歌单与原始顺序恢复，
