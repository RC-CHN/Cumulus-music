当前实现
- SearchTrackCard独立承担综合单曲预览；最多六项，宽度足够时两列，较窄时一列，
  保留84px高度/64px封面。窄窗换列属于社区适配，避免把378px卡片硬挤入不足宽度。
- 标题旁分类入口替代页头右侧“查看全部”；仍有可访问名称“查看全部某分类”。
  单曲旁播放全部使用该区块完整已返回列表并替换队列；单张预览只播放该歌曲，
  保留原队列并插入当前项之后。封面按钮可暂停/恢复当前歌曲。
- 卡片悬停或焦点进入后显示下载/喜欢/更多；下载与更多使用已有正式对话框，
  关闭后回到原按钮。子按钮双击不冒泡为整行播放。封面解码失败回到占位图。
  喜欢按钮沿用busy/失败/恢复状态，未新增第二套账号写入逻辑。
- 分类网格只挂载实际列数范围内、最多六张预览；不以overflow隐藏仍可Tab到达的
  额外卡片。进入完整分类仍显示其完整分页/连续加载记录，返回恢复此前位置。
  缩窄时收起有焦点的预览，将焦点转到仍显示且可用的卡片，并滚入可见区域；
  没有可用卡片时返回区块标题，避免回到页面起点。
- 颜色沿用应用深浅主题；悬停仅过渡opacity，跟随全局减少动态效果。卡片动作28px
  点击区与8px间距是社区可用性选择；未声称所有图标/按下态与官方逐像素一致。

综合单曲的 MV 入口
官方 TrackCard/index.tsx:334–335、727–730 在歌手前放置小型 TrackMvTag。
TrackMvTag/index.tsx:55–75、92–125 从歌曲读取 mvid，并独立打开视频详情；
恢复 M21:549 将歌曲的 mv/mvid 归一化。Cumulus 综合结果保留最多 32 位
的正十进制直接 MV ID，v3 可来自其已恢复的扩展信息合并流程。负版权状态、
零、无效或缺失 ID 不绘制入口。未移植官方针对无版权歌曲的替代 MV 权限分支。
点击、键盘激活经现有 MV 路由读取 /api/mlog/detail/v1，再按实际权限调用
/api/song/enhance/play/mv/url；搜索卡片只接收 ID，不接收地址，也不触发歌曲播放。
--mv-play 同时验证分类 MV 卡片与单曲内 MV 入口的原生解码，--v3 验证综合扩展
字段被投影。以上使用合成数据，真实服务与 Windows 实机视觉未在本轮复验。

综合单曲的歌词命中与别名
官方 TrackCard/index.tsx:423–454、537–543、736–741 的实验版标签先呈现一行
歌词命中，再回退到 songAlias；恢复 M/21:544–579 合并 newSongExt 和 extInfo，
Lyric/index.tsx 及 M/123:98–112 用 UTF-16 下标 [first, second) 标出匹配片段。
综合结果在 v1/v3 保留这两个明确的元数据，不以普通曲目别名或关键词推断歌词。
Rust 校验边界和长度，拒绝控制字符、链接、无效范围及拆开的 UTF-16 代理对；
无效歌词可回退到有效别名。Vue 只接收文本及高亮位，使用文本节点展示，不插入
服务端 HTML。歌词优先，别名使用已有搜索词高亮；固定 84px 卡片高度。
当前在响应带有效标签时显示；没有查询官方独立的 PH-PC-search-result=t1 分桶，
也不把现有 PH-PC-searchHot 分桶当成相同实验。没有新增接口、播放分支或关键词
请求；完整算法标签和 Windows 实机视觉仍未验证。可复跑 `search_results_smoke.py --v3 --screenshots` 合成桌面验证。
Linux 实际 WebView 的四个 V3 检查点及截图通过；760×540 深色窗与宽窗均验证
歌词 UTF-16 高亮、别名回退和 84px 卡片高度。另有十项 Rust 搜索接口回归，
其中综合标签用例验证无效、越界和私密字段不会进入显示结果。

综合单曲的成人内容标识
官方 M/21:584–597 以歌曲 `mark` 的第 20 位判断 explicit；当歌曲没有非零数字
标记时，仅从完整 `album` 回退。TrackCard/index.tsx:719 将 12px 标识放在标题
末尾。综合搜索的 Rust 投影只向界面提供布尔值，V3 适配保留用于判断的数字字段，
不把原始位掩码送入前端。Vue 以独立的 12px “E” 提示和可访问名称呈现；长标题
截断时提示仍保留。未使用该字段推断播放权限或调整播放行为，也未增加接口。

### 综合歌曲的推荐原因与城市标签

- 来源：M/21 合并 `newSongExt` 与 `extInfo`（后者优先），
  `TrackCard/index.tsx` 在没有歌词/别名提示时显示 `algClickableTags`；
  `AlgSongTag/index.tsx` 仅允许 `clickable` 且原因类型 1 / 5 的标签进入
  `algPlaylist`。`hybrid_203/3141.js`、`hybrid_62/3112.js` 和 M/15 提供详情请求：
  - 1：`/api/homepage/rcmd/tag/songs`，字段 `reasonId`、`reasonName`、
    `reasonType=1`、`songId`；读取 `title`、`playCount` 和
    `reasonRcmdSongCommonVOS[].songData`。
  - 5：依次读 `/api/chart/detail` 和 `/api/chart/song/detail`；均传
    `chartCode`、`targetId`、`targetType`，读取 `name`、`playCount` 和
    `charts[].songData`。字段缺失时仅在 Rust 内取标签 URL 的三个参数，
    不打开或返回该 URL；重复或越界参数降为不可点击标签。
- 前端进入独立详情页，可筛选、播放和调用现有歌曲动作。只读接口采用当前账号代次，
  切页与换号不提交过期结果。播放仍走既有歌曲授权和原生队列；不会把算法资源 ID
  当成普通歌单 ID。每次普通歌曲队列最多 500 首，超过时按钮明确显示播放前 500 首，
  点击后面的歌曲从该曲所在区段开始。未声明分类歌曲表、官方分享、收藏全部或精确像素对齐。
- 合成验证：`core/tests/client_search_results.rs` 核对参数、覆盖优先级和脱敏；
  `scripts/ci/search_results_smoke.py --v3` 的 6 个 Linux WebView 检查点和截图
  验证两条实际 Tauri 路由、窄窗标签命中、返回焦点、筛选及原生播放（队列仅含
  返回的城市歌曲）。报告：.build/goal-search-reasons-playback-ui/audit.json。
  不使用真实账号，未验证上游个性化分桶和 Windows 实机。

### 推荐原因详情的下载和批量操作

- 官方 `pages/algPlaylist/views/TagCommon.jsx` 以完整 algPlaylist 为范围呈现播放全部、
  下载及菜单，菜单携带 `/algPlaylist/batch/:id`。恢复的 `BatchOperation.tsx` 提供
  选择、播放所选和下载所选；不会把这个列表收藏成用户歌单。
- Cumulus 把三项动作放在标题下方，局部搜索仅过滤歌曲表。下载、播放全部和批量
  选择仍使用已返回的完整可用歌曲；原始歌曲顺序不变。批量界面复用可键盘操作的
  虚拟列表，以模态框承载，不宣称对齐官方独立批量页面的全部样式、封面和吸顶动作。
- 下载进入现有目录、音质和确认流程（确认前不启动），调用现有
  `download_command(kind=start)`；播放仍走已验证的普通歌曲队列和原生播放器。
  批量播放超过 500 首时控件明确标注范围。切换账号或推荐目标时丢弃待交接动作；
  取消下载会返回发起按钮。未引入上游请求或新增账号写操作。
- Linux WebView 的 V3 合成回归通过八个检查点，含下载确认与两级焦点返回、按行
  选择与全选、实际原生队列播放及 760×540 深色截图。报告：
  .build/search-reason-batch-webview/audit.json。本项没有确认下载或访问真实账号。

### 推荐原因详情当前曲目的行按钮

- 恢复的 `pages/algPlaylist/views/index.tsx` 将「歌曲」页交给 TrackList；

  队列版本和进度均保留。

综合及单曲分类的原唱标签
- 官方 M/21:126、573 保留 originCoverType；TrackCard/index.tsx:337–351 和
  TrackViewer/common/TrackTitleCell.tsx:559–570 仅在数字值严格等于 1 时显示
  “原唱”，单曲表的这一标签仅用于搜索。Cumulus 在 Rust 中投影为布尔值，
  不暴露原始数字或接受字符串替代；综合卡片与单曲分类虚拟行都消费该字段。
- 标签是只读信息，不增加请求、不推断版权、播放权限或收藏行为。Rust 搜索回归
  核对数字/字符串与脱敏；V3 合成 WebView 同时检查窄窗综合卡片和单曲表，
  其中翻唱值不显示此标签。当前不以此项声称其他音质或权益标签已补齐。
- Linux V3 WebView 的七个检查点通过；760×540 深色单曲表中，长标题截断后
  “原唱”仍完整可见，几何命中断言避免把仅存在于 DOM 的标签计为通过。
  报告：.build/goal-search-original-final-ui/audit.json。无真实账号操作。
