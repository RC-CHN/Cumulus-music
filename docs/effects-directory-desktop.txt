独立参数均衡（PEQ）
2026-11-04：选择卡片仍只读取权益和本地状态。已确认普通权益时可明确点击
「检查独立参数均衡」，effect_peq_prepare 校验本机适配器、重新读取非试用权益，
再读取及核验参数材料；仅通过独立且已启用的 PEQ。无法验证的组合不开放启用。
「启用独立参数均衡」使用当前窗口的一次性准备凭据调用 effect_peq_activate。
只有实际播放器回读同一绑定时才显示已配置；等待加载和需处理分别显示，不把登记
或配置回执当作 PCM 已处理。关闭目录不自动停止或重发请求。

「停止并清理登记」通过当前一次性停止凭据调用 effect_peq_stop。先确认本地卸载，
再用账号锁和登记版本校验后发送停止。停止回包丢失后，effect_peq_reconcile
只回读本地状态；需要再次明确确认才发送新的停止。界面不会显示凭据、材料 URL
或文件路径。重新打开同一音效可以核对持久登记。这里不启用整套音效、试用、
设备调音或空间组件，也不自动支付、重发或恢复挂载。

本机 effect_peq_native_smoke.py 在 Linux WebView 中通过生产 IPC 用合成接口和
冻结参数、真实 libmpv 与空输出完成五个状态。实际处理 51200 样本、零失败块；
同一播放条目继续走时，一次登记、先卸载再发停止、停止回包丢失后显式第二次停止，
只读 SQLite 确认 Released。截图和原始合成证据位于 .build/peq-native-integrated/。
未操作真实账号、实体输出或 Windows，本次证据不替代各自验证。

本机音效登记
目录打开时，effect_peq_pending 只读本账号的持久日志，返回可清理非试用登记的
音效 ID 和阶段。未完成的停止会显示「停止待核对」。恢复入口不依赖该音效仍在
目录推荐中；缺名称时显示编号，选中后直接打开本机登记管理，不读取详情、权益或
材料，也不提供启用按钮。确认停止成功后清除列表项；查询本身不会发送停止。
若用户在启用或停止回执到达前切换音效、关闭并重开目录，同账号的当前目录会
重新读取本机登记。例如停止结果不明时，已重开的目录直接显示「停止待核对」，
无需再次打开。旧详情不会复活，也不会自动发送新的启动或停止请求。

Linux 跨进程合成验证：effect_peq_restart_smoke.py 启动两个不同 PID。
第一个进程收到停止回执丢失后退出，SQLite 保留 StopUncertain。第二个进程的目录
为空，仍能从本机列表找到登记；取消确认不写入，显式确认仅发送同一登记的停止。
重开不读取详情、权益或材料，不重新登记。只读 SQLite 核对同一操作变为 Released。
截图见 .build/peq-restart-integrated/reopen/。两端 CI 使用同一隔离夹具。

等待播放器挂载
原生返回 deferred 时，当前可见控件在 5 秒预算内最多读取 8 次本机精确绑定状态，
不发送权益或登记请求；只有播放器确认后才显示已配置。关闭面板或明确操作会废弃旧
观察，超出预算或读取失败仍可手动核对。WebView 夹具模拟两次本机读取后确认挂载，
核对无需再点按钮，且登记、停止和显式停止重试的次数不变。

播放栏独立参数均衡状态
恢复 PlayBar/AudioEffectTag.tsx:27–74 按正在使用的音效显示底栏入口。Cumulus
保留现有均衡器入口，原生播放器确认挂载独立 PEQ 时显示 PEQ，并分别说明等待挂载
和待清理状态。状态来自原生播放器更新，不查询目录、不传登记或材料身份，
也不把已配置视为已观测 PCM。现有图示均衡器或低高音状态仍有独立反馈。

播放栏管理入口
独立参数均衡已经挂载、等待挂载或待清理时，从播放栏打开本机登记管理。
此入口先读取本机登记，不请求目录或权益；仍可显式浏览目录，关闭管理后返回
图示均衡器。原生 WebView 探针在合成音频处理中关闭并从播放栏重开，核对
本机登记仍可管理、额外业务读取为零、停止前后沿用同一播放项。

均衡器面板中的开关仅控制十段曲线和低高音。独立 PEQ 已配置、等待加载
或需要清理时，面板显示原生回读的状态并说明它不受此开关控制；用户可
直接打开本机登记管理。切换本机旁路不变更独立 PEQ 登记或当前播放项。
原生 WebView 夹具核对两条管理入口都不发起额外目录、权益或材料请求，
仅在用户明确执行停止后发送合成停止请求。
