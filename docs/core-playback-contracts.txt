组织
core/src/playback/queue.rs、timeline.rs：持久化队列和授权时间轴。
engine/types.rs：原生媒体输入、可取消加载、事件与快照；engine/mod.rs：AudioEngine。
engine/ffi.rs：唯一 libmpv unsafe 边界；engine/mpv.rs：选项、命令应答、加载/事件协调。
source/{mod,fetch,cache}.rs：授权、共享请求、账号/音质/编码/场景缓存与本地库解析。
controller/{mod,types,state,load,actions,tick}.rs：命令、加载、状态、持久化与预取。
核心不依赖 Tauri、WebView、Python 或 D-Bus；同步音频调用位于 spawn_blocking 工作者。
宿主负责提供 Tokio runtime、StateStore、AccountSession、SourceResolver 和 AudioEngine。

原生音频边界
MpvEngine::open(MpvConfig) 动态载入系统或宿主显式指定的可信 libmpv。
Linux候选libmpv.so.2/.1，Windows候选libmpv-2.dll/mpv-2.dll，macOS候选libmpv.2.dylib/
libmpv.dylib；当前只在Linux实际加载，其他平台不宣称通过构建或运行。
验证client API 1.108+或2.x；拒绝未知大版本。Library存活期覆盖全部函数指针和句柄；
事件payload在下一次wait_event前复制；mpv属性字符串及时free；Native仅Send，不提供Sync。
LoadRequest含File或经MediaUrl验证的URL、start/end、加载超时（最多120秒，默认25秒）。
本地文件规范化且必须为普通文件，Unix非UTF8路径经原生字节传递；不经shell。
源地址、原生资源信息不实现Debug/Serialize，不得作为UI DTO直接暴露。
禁用用户配置、脚本、ytdl、视频/封面显示、终端、Cookie；保留真实音频输出。
每次加载先停止旧内容、排空旧事件、重置start/end和pause，loadfile完成时仍为暂停。
命令用递增sequence等待异步应答；控制等待有界，等待中检查取消，旧事件保留供控制器关联。
可执行暂停、绝对精确定位、0..100音量、0.25..4速度、停止；拒绝非有限数和越界输入。
libmpv默认输出选择通过不设置ao保留；显式ao=auto在本机初始化后加载会以-14结束，
已修正该旧适配假设。null_output只用于真实解码但丢弃PCM的测试。

音源请求与权限事实
SourceResolver::resolve(resource, token) 对在线资源调用：
  /api/song/enhance/player/url/v1
  ids=单ID JSON字符串；level=11档Quality码；encodeType默认aac；
  immerseType=c51；trialMode默认-1，限制为已恢复的场景枚举。
按ID匹配响应；M/163要求内层code=200、非空url和md5三项同时满足。
返回fee/flag/freeTrialInfo/freeTrialPrivilege/rightSource/level/type/br是独立事实，
不能根据“有会员”把服务端降级当作高音质，也不以其他地址替代被拒绝的授权。
actual_quality来自返回level，requested_quality来自队列资源。
仅试听且没有资源duration/dt时额外调用 /api/v3/song/detail 获取完整曲目时长。
有试听区间时先验证start/end，再做补充I/O；freeTrialPrivilege遵循官方JS真值语义。
媒体URL验证/域限制沿用download/transfer的MediaUrl；API Cookie不交给音频引擎。
缓存键为完整SessionToken（含generation）、ID、音质、编码、试听场景。
单调时钟expi减5秒作为有效期，数值字符串兼容；无效/过短TTL不缓存，最多128项。
相同键与resolver revision共享正在进行的请求；失败保留类型（含301/403），不自动重放。
请求拥有者取消会唤醒等待者；invalidate与账号切换使迟到结果不能发布或供新账号复用。
授权URL只驻留内存，队列/position/preferences不保存返回URL。
local_id经LocalLibrary复核revision；path经playable_path处理，NCM使用现有本地解码缓存。
该本地解析保留原研究行为；下载记录权益检查由OfflineLibrary提供，桌面离线入口尚待联动。

时间轴
完整歌曲显示时钟等于媒体时钟。CUE把容器offset映射为显示0，限定分轨end。
试听把媒体0映射为服务授权start，实际短片时长可进一步缩短可播末尾，不能扩大授权区间。
完整试听标记保留为FullTrial，不凭标记转换为普通无约束授权。
逻辑定位在控制器内转媒体坐标；超界/NaN拒绝。新源解码后再结合实际duration校验。
恢复旧记录若无timeline_version=1，按旧相对时间换算；超出新授权范围时回到可播起点并
设置position_reset，UI应说明进度重置。恢复结束状态从起点开始，但保持暂停。

控制器与持久化
PlaybackController::start(...), command(token, PlaybackCommand), queue(token),
snapshot(), subscribe(), queue_with_state(token)；后者一次回复状态与队列，避免跨时刻revision。
Snapshot是原生类型，包含账号Token和资源Value，必须另映射UI；client/player提供白名单DTO。
控制器revision单调递增，queue_revision独立记录队列变化，供前端拒绝迟到响应和按需回读。
命令包括替换/追加/选择/移除/排序队列、四模式、播放/暂停/定位/音量/速度/上下首、
停止、恢复、刷新源、音质变更、外部队列同步及快照。错误使用核心Error，不能冒充成功。
单actor串行处理队列/状态；授权与解码在独立任务，generation使被替换的任务失效。
调用方丢弃正在加载的Future时取消操作，停止旧解码；销毁controller会停止并关闭actor。
每200ms处理原生事件和进度，周期保存为1秒，暂停/定位/停止等转换立即保存。
状态：idle/preparing/loading/playing/paused/buffering/ended/error。
只有与已加载原生entry_id对应的EOF能自动推进；SingleLoop仅自动曲末重复当前，手动
下一首仍推进；Sequential到队尾保留ended；随机播放顺序随队列持久化。
账号变化停止旧音频、取消加载和清理源缓存，然后加载新owner队列/偏好。
即使新账号存储损坏，也先清掉旧账号可见资源；错误状态不把临时空队列写回覆盖原数据。
外部队列修改在准备/加载/播放状态均对账；删除或替换当前项取消旧加载。相同entry改变
资源时尽量保留位置/暂停，删除不恢复旧position记录。
位置事务同时比较完整已提交队列和已加载项；竞争变更不能重新写入已删除资源的进度。
position记录entry_id、seconds、paused、state、timeline_version=1；preferences保存volume/speed。
音量/速度持久化失败回滚引擎偏好；进度持久化失败停止播放并公开错误。
重开只恢复队列/偏好，显式Restore加载后仍暂停；显式Play才开始播放。
普通播放失败不会循环重试或悄悄切换音源。RefreshSource显式废弃授权缓存后重取，
尽可能保留位置/暂停；Quality先授权候选音质，拒绝时当前播放不变，成功后才更新队列并重载。
下首预取仅准备授权地址，不取媒体字节；上下文含播放generation、队列revision、源revision
和账号Token；旧结果不能改变当前队列/播放。TTL到期刷新有5秒下限，失败不立即无限重试。
