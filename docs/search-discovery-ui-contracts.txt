- 输入获得焦点显示历史/推荐/热搜；有输入时切换建议，推荐和建议支持直接搜索。
- 历史和推荐长标签截断；折叠后不可见的条目不能被Tab误选。历史支持删除和确认清空。
- 标签28高；历史/推荐分别2/8行距、64/66折叠高，区域底距14/24。展开图标24×24，
  在第二行预留位置，展开后移到最后一个标签后方。窗口变化重算，隐藏条目保留宽度
  供测量但不可见、不可聚焦；当前焦点条目被折叠时回到展开按钮。
- 查询变化、退出浮层及账号变化后，过时响应不能重新弹出旧内容。
- 中文输入合成期间不提交查询；方向键进入/移动候选项，Escape关闭并回到输入框。
  合成期间说明“输入完成后显示搜索建议”，直接搜索按钮禁用；不会伪装成已在请求。
- 错误保留对应区域重试入口；清空失败保留历史。会话失效时关闭浮层、禁用输入。
- 760窄窗浮层保持12边距，热搜改两列；高度在播放条上方受限，内部滚动。
- 深浅色使用Cumulus语义色和图标；沿用transform/opacity菜单动效和减少动态效果设置。

支撑界面的已接入用例（不计入UI一致性通过数）
frontend SearchClient → desktop/search.rs → MusicClient → catalog/search。
search_discovery(epoch,query)仅返回类型化展示数据：关键词、显示词、文本徽标、榜名、
建议分组。响应URL、跟踪上下文和其他服务字段不进入前端，账号代次变化拒绝迟到数据。
kind | 官方接口 | 参数 | 读取字段
defaults | /api/search/default/keyword/get | {} | data.keywords、refreshTime
recommendations | /api/search/pc/rcmd/keyword/get | lastQuery | data.operateWords、algWords
charts | /api/search/pc/chart/list | {} | data.tabInfo.list、items
chart | /api/search/pc/chart/detail | id | data.itemList
suggestions | /api/search/pc/suggest/keyword/get | keyword | data.recTitle、recs、suggests
建议接口依据M/623的Zf调用及M/15导出映射，修正旧产品报告中generic web建议的混用。
search_history(epoch,command)支持read/remember/remove/clear，在账号隔离的SQLite事务内
存储search-history-v1/keywords；去重、最近优先、最多30项。30项为社区上限，不冒称
官方精确限制。明确清空可恢复损坏记录；失败不更新前端列表。没有在线历史写入。
关键词限制256Unicode字符；默认词最多20、推荐40、榜单项20、建议20、推荐建议10；
默认词轮换间隔限制2至60秒。这些边界用于有界渲染和输入验证。

core/examples/search_discovery_read.rs是显式传入已有PC配置与新私有输出目录的只读例程，
不属于公开CI。search-discovery-live-1实际读取默认词6/推荐词18/榜单6、首榜详情成功，

热搜条件播放
- M/623 仅在 needPlay 为真时显示播放，调用 M/15 Dc：
  /api/hot/search/relate/song/get，keywords 是榜单 searchWord 的 JSON 字符串数组。
  可见卡片最多九项，但请求使用完整且可验证的榜单词（本实现上限20项）。
  缺少原 searchWord 或超出上限时禁用按钮，不以展示词替代。
- data.songs[].song.id 按服务顺序投影，保留重复项；不传回原始 URL/追踪字段。
  成功后复用账号隔离的播放选择，队列从首项开始。采用 M/11 的 searchBox 场景和
  M/91 的 search 试听模式 42；实际权益和媒体可用性仍由既有原生解析判定。
- 仅显式点击触发；读取失败不替换队列。其他榜单条件及 More 分支不在此专项。

长音频榜条目
SearchBox/view/searchRankCard.tsx:235–237、300–398 把播客榜/听书榜的 orpheus 条目
解析出 id 后进入 /audioDetail/:id；普通榜条目提交搜索。Cumulus 仅在两个已知榜单内
解析并投影一个明确的十进制播客 ID。外链、缺 ID 和歧义 ID 保留标签但禁用，
原始 URL 不跨 IPC，不以标题发起文字搜索。点击进入已有播客详情；同一详情再次点
只关闭搜索浮层，不重复加载或自动播放。官方外链、同页恢复/播放分支以及“更多”
公开发现/分类目的地没有接入。

搜索建议的原词回退
官方 SearchBox/view/searchResultsItems.jsx:103–147 和 M623:618–640、743–765 仅在
普通建议为空时显示“搜索当前词”作为该组回退，推荐组独立。Cumulus 在建议已加载
且非空时隐藏该回退；输入框 Enter 仍提交原词，加载、输入法及错误状态继续保留既有
提示和重试。search_smoke.py --exact-fallback 验证普通建议、只有推荐及全部为空。

搜索建议的关键词标记
官方 M623:610–616 调用 M87 的 MarkText，M123:62–86 对每个标签最多标记100处。
Cumulus 复用已有的有界字面匹配，保留原显示文本、浮层强调色和提交词；不在没有
命中时输出空标记。未移植官方全量字形映射或分词规则。
search_smoke.py --suggestion-matches 可验证重复命中、特殊符号和原样显示。

删除最后一条搜索历史
官方 SearchBox/view/history.jsx:173–182 单独删除至空时关闭当前搜索浮层。Cumulus
等待原生回读确认，保留删除失败及非最后一条的浮层状态；当前查询或页面已变化时，
迟到回包不能关闭新浮层。焦点仍归原浮层时回到搜索输入框。独立验证：
search_smoke.py --history-last。

顶栏搜索来源
官方 SearchBox/index.tsx:280–300、M623:1596–1600 区分输入词（typing）和空输入
时提交轮换默认词（defaultquery）。Cumulus 从当前输入判断，默认词使用其真实关键词；
输入与默认词同名仍属 typing。两种来源由原有搜索路由传给已有 channel 的结果端点，
不扩大端点范围。榜单 hotquery 与其他入口现有行为保持；不获取或传递官方不透明的
bizQueryInfo、追踪字段或链接。

发现区选词来源：官方 M623:325、908 以及 history.jsx:235、searchGuessLike.jsx:203
均将历史和发现区“猜你喜欢”选词标为 history。M623:695–700、1304–1310 将输入建议
中的推荐组标为 rec_query，普通建议保留 suggest。继续只发送固定来源值到支持的结果端点，
不传原始追踪字段；真实词、显示词和回退行为不变。

发现区推荐按官方 M623:1386–1390 等待本机历史读取，再使用最近一条作为 lastQuery。
Cumulus 同时等待已排队的本机历史更新；热搜可独立加载。等待期间离开空查询浮层或切换
账号不会发送迟到的推荐请求，不向新会话传递旧账号的搜索词。
