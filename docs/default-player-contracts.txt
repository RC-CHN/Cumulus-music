当前迁移：原生冷启动与 Linux 暖转交
- 新启动的 Cumulus 接受 --play=ABSOLUTE_PATH 或 --play ABSOLUTE_PATH …
  （最多 8 个）。路径保留为 OS 原生参数/PathBuf，不经过 shell、HTTP、
  file URI 或 WebView IPC；落入现有 Rust 队列存储前要求可无损表达的 UTF-8。
  Windows 拒绝 UNC/设备路径；相对路径和其他参数不作为打开授权。无法
  无损解码的 --play= 仍是失败的显式打开，不退化成普通启动。
- Linux 在正式窗口与业务初始化前取得规范化资料目录的独占进程锁；
  同目录普通重复启动退出 2，不创建第二套活跃播放会话。Windows 仍用原冷启动
  锁：普通进程共享，冷文件打开独占，已有实例时拒绝。自动启动 --autostart
  分支独立；旧版本/不同网络命名空间、组或其他用户可写的资料目录、以及
  CUMULUS_SESSION_DIR 指向历史会话的启动不承诺暖转交。
- 冷启动的第一条主 WebView player stream 到达有效账号代次后一次性取走原生参数；
  它不会在后续注册或失败重试中重新消费。显式打开会抑制旧队列本次自动播放，
  即使所有候选无效也保留旧队列和时钟。错误消息为固定本地文本，无原始路径。
- 当前只接受普通 MP3/FLAC：原生后缀、签名、ffprobe 音频编码和指纹都必须
  一致，按官方模式跳过无效文件、保留有效顺序。元数据准备最多等待 12 秒；
  新代次/显式播放动作可使已准备请求失效，不用旧结果覆盖新队列。
- 经过现有播放许可和账号代次/焦点栅栏，播放器在真正加载时检查打开句柄
  的文件身份，使用 libmpv 的受限 pinned stream 与固定解码格式，防止把
  伪装清单当作可联网媒体。只保存显式队列条目，不扫描或添加父目录、不创建
  本地库记录，不转成在线 ID。渲染层只得普通本地音轨投影和状态。
  NCM/CUE/CD 及其他普通后缀仍遵守各自现有入口，未暴露在冷启动关联流程。

Linux 暖转交
- 官方暖回调接同一 onPlayLocalMusic 模型；这里使用 Linux 原生 IPC 代替
  Windows 官方原生转交。规范目录 SHA-256 与有效 UID 区分地址，抽象 Unix
  域套接字不创建系统套接字文件；双方都验证内核 SO_PEERCRED 的有效 UID。
  套接字名称不是凭据，其他同 UID 进程与直接调用 CLI 同属用户授权边界。
  显式暖转交在发送方图形检测前完成；发送方无需启动另一个渲染器。
- 只有现有主窗口已经订阅当前账号代次时才开始处理。协议含 ready/busy、
  一次有长度上界的半关闭帧（32 KiB，最多 8 个绝对 UTF-8 路径，无控制
  字符）和独立回执。连接非阻塞，发送前握手和帧接收各限 2 秒；发送后最多
  等 20 秒，遇到断线或未知回执不自动重发。无有效项不会动旧队列。
- 暖请求沿用播放队列、账号代次、最新播放操作和媒体焦点的准备/提交栅栏；
  用户后来操作导致的变化使过时请求失效，主窗口销毁取消尚未提交的工作。
  接受后在主线程显示/恢复原窗口。
  返回 0 表示原进程接受了播放选择，解码/设备后续结果仍显示在原播放器；
  2 为原实例/账号播放器未就绪等不可用，3 为不支持的请求/文件，4 表示
  未确认（先看现有播放器），5 表示已有文件打开处理中。只接收 CLI 路径，
  不转发环境、账号、媒体 URL 或 WebView 命令。

Debian 打开方式候选与系统默认归属
- Cumulus 不写系统默认、Explorer UserChoice/Hash 或 Linux mimeapps.list，
  不展示默认播放器复选框，也不启动系统默认选择流程。Debian 包仅声明自己
  可被选为打开方式；便携包和 Windows 不增加关联元数据。
- Windows：固定 Tauri CLI 2.12.4 的 NSIS installer.nsi 调 APP_ASSOCIATE，
  FileAssociation.nsh 的 66–76 行会改写 Software\Classes\.ext 的
  默认值，卸载还会恢复备份，可能覆盖用户后来选择，因此保持关闭。
  后续应只装应用自有 ProgID/Capabilities/RegisteredApplications 候选和
  OpenWithProgids，再由用户从系统 Default Apps 选择。Windows 11 的
  ms-settings:defaultapps?registeredAppUser=… 只在候选已注册时才有意义；
  不复刻原版私有 UserChoice 行为。实际 Windows shell 与现代用户选择未测。
- Debian：保留 Tauri 2.12.4 的既有 Cumulus.desktop 名称、图标、分类和
  StartupWMClass；模板只添加 audio/mpeg、audio/flac，并把 Exec 改为
  cumulus --open-local-files %F。%F 是本地文件列表，不启用 %U、URL scheme、
  D-Bus activation 或 shell；路径仍逐项走原生校验。菜单启动时 %F 不产生
  文件参数，走普通启动（包括原有自动恢复和同实例策略）；显式 CLI --play
  的无效参数保护保持独立。
- Debian 的 desktop-file-utils 触发器监听 /usr/share/applications；无需
  Cumulus 安装/卸载脚本、xdg-mime 写入或用户文件修改。既有明确的默认应用
  由桌面保留；若未配置任何默认应用，freedesktop 规范允许桌面从现有候选中
  自行选出回退应用。应用无法在不退出候选列表的前提下禁止这种回退。
