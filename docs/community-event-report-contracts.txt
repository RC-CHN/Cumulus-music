Cumulus 状态和边界
- core/src/client/community/report.rs 只接收当前账号代次、已注册的顶层卡片
  UUID 与类型化动作。不能从界面传入任意事件 ID、作者 ID 或授权信息。关注流、
  用户笔记、话题和详情共享原有的注册/投影机制；本人、匿名、内嵌转发原文、
  无法展示或已删除的对象不可提交。不给附件或独立社区评论猜测举报接口。
- 预设和自填均需用户明确确认；自填原样发送并限制 4096 UTF-8 字节。确认票
  120 秒内有效，绑定账号代次、事件、作者及当前卡片 UUID；刷新替换句柄后，
  旧确认票不适用。提交前无缓存重读 /api/v1/event/{作者 ID}/{事件 ID} {}，
  只接受顶层事件和作者严格匹配且仍可见的响应，再检查原句柄仍注册。
- 共享 report_receipt 原生守卫。账号加顶层事件 ID 是持久回执键，因此同一事件
  从列表或详情重开可共用回执；提交前持久化 uncertain，只发一次。记录不包含
  原因、动态正文、响应或凭据。成功或明确重复是终态，未确认结果只允许本机
  核对。没有重试、切换接口或将未知响应当作成功。取消不请求，关闭恢复原操作
  按钮焦点，报告结果不移除或编辑卡片。
- 不替换本人动态删除、附件、评论等已有动作。未认证时从现有登录入口验证后
  重新操作；不会自动续发此前动作。只用合成请求做 Linux 实际 WebView 验证，
  没有真实账号或实际举报；原生 Windows、实际服务结果与全局 XEAPI 尚未验证。
