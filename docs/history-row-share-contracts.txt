最近播放歌曲／声音行「分享」契约

范围：网易云音乐桌面 3.1.42.205594 的最近播放普通歌曲和声音。区分官方
行为、Cumulus 本地分享及依赖官方宿主或第三方服务的渠道。

官方菜单与触发顺序
- HistoryTrack.tsx:109–121 传入 Scene.history／ResourceType.track；M195:399–411
  仅在多选时向父表格填入 selectedData。M556:400–457 把歌曲「分享」放在
  「下载」后、「复制链接」前；M35:33–42 认负版权状态，收费本身不隐藏。
  M556:68–79 的附加检查同时看直接行和父表格的 selectedData，多选时隐藏，
  包括修饰键打开组选区外的行。已下载包装可用其 origin 作为 track。
- VoiceTitleCell.tsx:433–449 把点中的节目作为 ResourceType.voice，组选区来自
  独立 parentData。M622:1323–1345 的「分享...」也在「下载」后；
  M622:1174–1182 只查直接 from.selectedData，普通历史多选仍可分享点中节目，
  与选区首项、播单 ID、主歌曲 ID 和本机下载状态无关。不把下载页另用的
  downloadedVoice 或其他资源包装当成本用例的 voice。
- M3085:1310–1372 只对 track 先调用 M15.Dg。M15:177–178,1699–1710 的请求是
  POST /api/song/enhance/privilege {ids: JSON.stringify([点中曲ID])}，无 trialMode；
  M21:344–362 把 sp 映射为 sharePriv，st 为 status，cs 归一为 cloudSong。
  没有权益对象时显示「分享失败」；有对象但 sp 缺失／为零／负时拒绝。
  st=0、cloudSong=1 且原行 songType=1 时提示无目录资源，否则原行 fee 命中
  数字专辑 bb 位时进入官方付费提示，其余提示暂无版权。该门槛与菜单版权显隐、
  播放权益、下载权益和会员标记独立。普通 voice 不请求歌曲权限。
- M3085:1373–1395 在上述检查之后判断匿名：匿名唤起登录；已登录且没有指定渠道
  才打开选择器。指定渠道走 host/share，使用资源类型与公开身份。官方歌曲的
  权限请求早于匿名判断；不要假定 Cumulus 已有的访客传输能完成此权益读取。
- M31:388–410 打开宽 442px、标题「分享到」、内容内边距为零且无页脚的 ShareModal。
  ShareModal/index.jsx:15–49,67–106 定义 64px 高的行，左内边距 26px、间距 18px、
  图标 48px、文字 16px；顺序为云音乐笔记、私信、微信好友、QQ好友、QQ空间、
  微博、复制链接。:115–137 先关闭选择器，再带原资源和所选渠道重新派发
  Action.share；因此歌曲选渠道再查一次 sp。取消不派发；二次拒绝时不打开渠道，
  重新选择是一次新操作，不能沿用第一次成功结果或自动重试。
- M198:1450–1514 为歌曲 /song、声音 /dj 构造带 userid 或 uct2 的链接。微信好友
  在本机显示二维码，官方还附 from；M31:1029–1050 的 QrcodeModal 为
  376×520px（默认），标题「分享到微信」，提示用微信扫一扫。
  QrcodeModal/index.jsx:34–60 使用 180px 二维码、ECC L、零绘制外边距。
  M198:1480–1506 的笔记和私信打开专有发布编辑器，打开本身不等于发布；
  :1515–1564 的 QQ／空间／微博依赖旧外部页面、账号归因和昵称。:1566–1567
  只在系统剪贴板写成功时提示。M3085:1578–1601 是独立「复制链接」动作，直接
  选择 link 渠道，不走歌曲分享权限预检、匿名登录或「分享到」弹窗。

Cumulus 接入
- 已有：HistoryPage.vue 的独立「复制链接」使用 history_row_menu_info 给出的
  安全公开身份和系统剪贴板；保留原显隐，只有 id 的 /song 或 /dj 链接。
  TrackShareDialog.vue 是其他页面的本地复制预览，不是官方的渠道列表。
  DownloadRowMenu.vue／download_song_share_access 已有下载任务范围内的 sp
  双读和错误语义；可参考其解析，不可用下载任务、任意歌曲 ID 或旧复制链接
  授权最近播放分享。播客／有声书历史已有独立播单分享，不能代替节目分享。
- `history_row_menu_info.canShare` 只投影当前历史快照的可见条件；不在打开行菜单时
  查分享权限。主窗口 `history_row_share_prepare` 接账号代次及原
  `{history_kind,revision,clicked_id,selected_ids}`，校验分类、快照、点中项和有序选区；
  只允许已证实的公开歌曲或节目。私有云盘、本机路径、无法证明的映射或包装不分享。
  普通账号通过检查后返回 180 秒单次回执，绑定当前 API 凭据实例；新准备会使旧回执
  失效，关闭或离开通过 `history_row_share_cancel` 撤销仍未使用的回执。
- `history_row_share_choose` 以同一范围和回执接受 `copy` 或 `wechat_qr`。歌曲在准备和
  选择时各做一次精确的非缓存权限读取；缺、错配、冲突、超时或返回后换账号／列表／
  访问均不打开或执行旧选择。数字专辑分支只说明限制。声音不读歌曲或媒体权限。
  匿名传输的隔离允许列表只有搜索，游客先提示登录；不借用已登录凭据或为分享
  自动注册新凭据。
- 「分享到」选择器在选择后关闭；复制用系统剪贴板写入不带 userid、uct2、from
  或授权参数的公开链接，写入成功后才反馈。微信好友用同一公开链接本地生成 L 级
  纠错的二维码，WebView 只收到模块矩阵；为可扫描性保留四模块静区。关闭后
  恢复点中行焦点。不把去掉账号归因的二维码称为官方渠道完全等价。
  不提供会发送私信、发布笔记或携带账号归因打开旧第三方页面的入口。专有
  宿主、第三方跳转、微信扫码后的结果和真实外部投递均未验证。
- 同一 Linux Tauri/WebKitGTK 探针完成 31 个实窗检查点和截图。合成歌曲恰好发出
  五次 `{ids:"[\"10\"]"}` 非缓存请求，权限结果依次为 1、1、0、1、1：取消不重查，
  二次拒绝不改系统剪贴板，授权时确实写入新链接。独立复制和声音没有额外歌曲权限
  请求；声音保留原选区但生成点中节目 `/dj?id=10` 的二维码。Python 对 WebView SVG
  模块解码，另用 ZXing 从实窗截图独立读出同一个链接及 L 级纠错。拒绝提示出现后
  也核对焦点和原行按钮仍在滚动区内。证据在
  .build/ui-proof/phase304-history-row-share-final/，另有 33 个历史下载、定位和收藏
  实窗回归。Rust 合成验证包括回执取消、账户与有序选区绑定、精确权限与失效。
  Windows 同一用例接入 CI，本批尚未取得 WebView2 结果；未使用真实账号或外部渠道。
