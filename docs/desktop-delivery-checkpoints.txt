如何核对结果
  - 正式程序：使用确切生产入口构建的程序；实例运行日志须给出源码与二进制
    哈希。启动或编译本身不能证明播放，原生解码时钟、音频输出路径和退出需
    单独验证。Linux 虚拟音频输出不等于实体设备。
  - 合成桌面：真实生产 Vue、Tauri 命令及 SQLite 可以与隔离的签名服务、
    音源和账号配合验证菜单、协议状态、渲染、交互和恢复。记录须区分请求
    断言、回执、原生队列、截图；不能据此宣布真实会话、真实写入或风控通过。
  - 实服：只以同次记录中获准的真实读取或私密隔离测试为证。账号续期、
    隐私、特权及 CDN 等条件须分别核对，不能拼接旧样本冒充新构建完整流程。
  - 安装发行：只接受目标提交的 GitHub CI gate、该次运行及 attempt 的
    Linux/Windows 产物和清单，以及后续唯一空发布标记的独立 CI 和 CD。开发可执行
    文件、可运行探针、另一提交的成功包均不能当作候选发行。
