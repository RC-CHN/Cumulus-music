下载列表离开与返回（2026-10-31）

来源与适配
- 官方 DownloadedMV.tsx 给 VideoCard 传本地路径/记录，VideoCard/index.tsx 通过
  Action.link 打开详情；ArtistNames/index.tsx 将有 ID 的艺人作为独立入口。
  DownloadedTrack/DownloadedVoice/DownloadedMV 用各自的列表和滚动容器。
  恢复材料不能证明跨路由返回时的精确滚动/键盘焦点政策。本文件描述 Cumulus
  对这条实际入口链路的可用性修复，不称其为官方已恢复热键或缓存实现。
- 没有引入 YesPlayMusic。没有更改请求签名、播放授权或下载文件权益政策。

状态与生命周期
- useDownloads 按每次下载访问分别持有当前账号的内存位置。DownloadViewport 保存
  查询指纹、锚点任务 ID/索引、行内偏移、最后聚焦的任务和动作、列宽分配；
  不保存完整 DOM、账号 Cookie、授权 URL 或下载文件内容，也不落盘。
- 查询指纹包含分类、活动/完成状态、关键词、排序及方向、offset。连续加载扩展
  limit 不改变指纹，返回可使用原已加载范围；查询改变、账号登录代次改变或 dispose 清理
  位置。保存必须同时匹配账号 epoch、访问对象和当前查询，旧账号或旧访问回调
  不能写入新位置；同一登录代次刷新保留状态。
- DownloadPage 离开前从实际可见列表同步记录锚点，卸载时再检查所有者。返回后，先等待下载状态读取和
  ResizeObserver 得到实际列数，再按该任务在新列表的位置计算滚动。不存在时
  使用原索引附近项并夹在有效范围；绝不恢复已脱离 DOM 的按钮。
- MV 用实际行高和两/四列布局；歌曲/声音/活动任务表用 64px 行高。原焦点动作
  仍可见时恢复到对应入口，原任务删除/移到不可见处时回滚动容器，后续方向键仍
  可操作。错误或提示压短视口时，若原入口只剩一条边，则最小滚动到可操作区域
  可见。相同表结构恢复列宽；返回期间改变宽度按现有列宽分配重新计算像素。
- 恢复有生命周期和查询检查；用户开始新的指针、键盘或滚轮操作即取消待执行恢复；读取失败的刷新入口除外。
  已取消的异步恢复不抢焦点或将列表拉回旧位置。账号数据更新后旧组件也不保存。
- 返回读取失败保留已有列表与明确错误；可重试原查询。重试不重发视频播放、文件
  删除或其他写操作。从 MV 返回时保留既有迷你视频；关闭视频走原生 stop 命令。

调用
- 返回继续使用原有 downloads(epoch, query) 只读 IPC。完整已加载前缀由 Rust 读取；
  不从 DOM 重建资源数据。位置恢复本身不调用播放、支付、收藏、邀请或文件写入。
- MV/艺人入口的既有视频和歌手接口见 download-page-ui-contracts.txt。此改动没有
  新增业务 API，也不绕过离线文件和账号隔离校验。

证据及边界
- download_navigation_ui_probe.js 通过真实页面卸载/挂载检查 14 态；实际视频由
  原生引擎解码，播放后返回与关闭迷你视频均走现有界面。数据来自隔离合成记录；
  故障/等待仅在测试提供的类型化下载读取适配器注入，正式实现无探针分支。
- 证据轮次、实机截图和回归结果见 ui-ux-validation.txt。本轮不验证 Windows
  实机视觉、不称已覆盖官方全部下载菜单，也不将 CI 或单元测试当作视觉证明。
- 2026-10-31 后续已补逐次访问记忆，原“最近视图”限制由下面的多层返回专项取代。
  大批量重排和缩减后的所有跨页锚点仍未全部枚举。

多层返回后续专项
- 每次 navigate/replace 到下载页生成独立 downloadVisit；返回保留原 Page 对象。
  useDownloads 用 WeakMap 按该对象记忆查询、已加载前缀大小、viewport 和续页错误；
  不把其他访问的结果列表当成原访问缓存，也不保留完整列表的多份副本。
  访问对象随导航历史释放即可回收记忆，不设一个任意容量后悄悄串到最近访问。
- 离开页面时同步检查当前 DOM 的锚点，再在进入下一访问前保存查询。退场动画期间
  旧页面的卸载回调必须仍匹配原访问才能保存；旧读取的序号已失效，不能提交到新页。
  打开独立批量页前也记录位置。静态筛选改变仍从头开始。
- 新下载完成后“查看正在下载”作为新页面的初始意图进入，不在离开前修改原访问
  查询；返回一个访问时以其后来保存的分类/筛选为准，不重新套用最初 active 意图。
- 搜索输入的防抖在离开前提交给原访问；未完成 IME 组合不强行提交。定时回调检查
  访问和登录代次，不能筛选另一个页面或新账号。续页错误随原访问保留，继续遵守
  显式重试政策；恢复失败后点刷新会继续原来的位置恢复，其他用户操作仍取消恢复。
- 同账号同代次 connect 只刷新数据，不清空访问或重启本地任务。代次变化清空下载
  查询/访问记忆及主导航返回栈；主内容区按账号与页面建立生命周期，旧组件不能
  接管新身份；包含资源 ID、评论标题或搜索词的当前页面回到每日推荐，避免带入
  原身份的上下文。合成账号检查与真实登录边界见 ui-ux-validation.txt。
- 切换到不同查询时先清除另一查询的列表并重新读取。读取失败会展示目标分类/
  关键词与错误，不把上一分类的旧行留下；重试成功后定位原锚点并返回原入口。
  本设计不为每次访问保存完整资源结果，IPC 或本地状态读取失败且无兼容缓存时只能显示错误并重试。
  下载记录读取本身走 Rust 本地存储，不因音乐服务网络不可用而改用其他分类。
- 官方恢复来源能证明入口和分类行为，不能证明上述逐次访问/键盘恢复是官方的
  原始缓存实现。它们是 Cumulus 为实际多层流程补充的状态与可访问性政策。
