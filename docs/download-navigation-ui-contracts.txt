下载列表离开与返回（2026-10-31）

来源与适配
- 官方 DownloadedMV.tsx 给 VideoCard 传本地路径/记录，VideoCard/index.tsx 通过
  Action.link 打开详情；ArtistNames/index.tsx 将有 ID 的艺人作为独立入口。
  DownloadedTrack/DownloadedVoice/DownloadedMV 用各自的列表和滚动容器。
  恢复材料不能证明跨路由返回时的精确滚动/键盘焦点政策。本文件描述 Cumulus
  对这条实际入口链路的可用性修复，不称其为官方已恢复热键或缓存实现。
- 没有引入 YesPlayMusic。没有更改请求签名、播放授权或下载文件权益政策。

状态与生命周期
- useDownloads 持有一份当前账号最近下载视图的内存位置。DownloadViewport 保存
  查询指纹、锚点任务 ID/索引、行内偏移、最后聚焦的任务和动作、列宽分配；
  不保存完整 DOM、账号 Cookie、授权 URL 或下载文件内容，也不落盘。
- 查询指纹包含分类、活动/完成状态、关键词、排序及方向、offset。连续加载扩展
  limit 不改变指纹，返回可使用原已加载范围；查询改变、connect 或 dispose 清理
  位置。保存必须同时匹配账号 epoch 和当前查询，旧账号回调不能写入新位置。
- DownloadPage 卸载前从实际可见列表记录锚点。返回后，先等待下载状态读取和
  ResizeObserver 得到实际列数，再按该任务在新列表的位置计算滚动。不存在时
  使用原索引附近项并夹在有效范围；绝不恢复已脱离 DOM 的按钮。
- MV 用实际行高和两/四列布局；歌曲/声音/活动任务表用 64px 行高。原焦点动作
  仍可见时恢复到对应入口，原任务删除/移到不可见处时回滚动容器，后续方向键仍
  可操作。错误或提示压短视口时，若原入口只剩一条边，则最小滚动到可操作区域
  可见。相同表结构恢复列宽；返回期间改变宽度按现有列宽分配重新计算像素。
- 恢复有生命周期和查询检查；用户开始指针、键盘或滚轮操作即取消待执行恢复。
  已取消的异步恢复不抢焦点或将列表拉回旧位置。账号数据更新后旧组件也不保存。
- 返回读取失败保留已有列表与明确错误；可重试原查询。重试不重发视频播放、文件
  删除或其他写操作。从 MV 返回时保留既有迷你视频；关闭视频走原生 stop 命令。

调用
- 返回继续使用原有 downloads(epoch, query) 只读 IPC。完整已加载前缀由 Rust 读取；
  不从 DOM 重建资源数据。位置恢复本身不调用播放、支付、收藏、邀请或文件写入。
- MV/艺人入口的既有视频和歌手接口见 download-page-ui-contracts.txt。此改动没有
  新增业务 API，也不绕过离线文件和账号隔离校验。

证据及边界
- download_navigation_ui_probe.js 通过真实页面卸载/挂载检查 14 态；实际视频由
  原生引擎解码，播放后返回与关闭迷你视频均走现有界面。数据来自隔离合成记录；
  故障/等待仅在测试提供的类型化下载读取适配器注入，正式实现无探针分支。
- 证据轮次、实机截图和回归结果见 ui-ux-validation.txt。本轮不验证 Windows
  实机视觉、不称已覆盖官方全部下载菜单，也不将 CI 或单元测试当作视觉证明。
- 当前是“最近下载视图”语义，没有为历史栈中每次下载访问保存独立查询快照。
  在其他页面另行切换下载分类再回退多层，不承诺恢复更早访问的独立分类/查询；
  这条多层历史分支要继续单独检查。大批量重排和缩减后的跨页锚点也未全部枚举。
