官方 SE 固定 bank1 迁移与桌面边界验证（2026-11-05）

范围与来源
----------
优先使用官方 3.1.42 解包逻辑。Rust 负责材料校验、参数、状态、缓冲、所有权和宿主；
恢复 C 内核通过有界安全 FFI 复用。不加载原官方 DLL，不调用 Python 业务进程。
本批新增的是 Environment bank1、完整 SE bank1 组件、动态库宿主边界、以及严格受限的
SE1→默认 B0 子图。没有把整个 neaudioeffects SDK、一般材料、在线音源或音效 UI 标成通过。
来源和细节见 core-effects-ambience-one.txt、core-effects-stereo-one.txt、
stereo-native-host-contracts.txt 和 local-stereo-subgraph-transport.txt。

与官方对照
----------
- Environment 的 14 组合成输入、1764 块冻结原机器码结果覆盖初始化、处理、重置和尾音。
- 完整 SE bank1 的 14 组、1764 块冻结结果覆盖父级预处理、双声道环境、参数和状态。
  已有 SE0 对照仍单独回归；SE1 的零输入 EOF 语义不向 SE0 公共入口扩散。
- 子图的 12 组覆盖 44.1/48/96kHz、512/2048 容量、连续和同实例重置；
  1032 次 B0 调用、796718 输出帧逐块哈希对照。SE 实际调用 1044 次，984 次截至
  各用例首个 EOF，其后零输入调用独立保留，不能混写成同一个数量。
- 以上是合成 PCM 和独立子节点对照，不是执行完整 SDK 的证明。原 SDK 关闭节点的
  首块也不能任意省略：正在恢复的原对象实验已观察到 GEQ、BT、RVB 首块有变化。
  该发现用于保留边界，没有据此臆造完整总图或放开正式入口。

真实桌面初始化后的动态库验证
----------------------------
Linux 真实 Tauri/GTK/WebKit 窗口已创建，系统 locale 为 en_US.UTF-8，正常启动仅调整
数字 locale 为 C。运行在独立无外网网络命名空间、Xvfb/X11、dbus 和新隔离 profile。
native_smoke.py --stereo-native-library 实际通过：
- 真 dlopen/versioned ABI 实例与独立 core SE1 逐有效采样 to_bits 比较。
- 20 个源块含 1/3/7 帧短块、4 个参数修订、同实例重置和开关。
- 显式零输入 EOF 排空 24 块、48000 帧真实非零尾音，不补造输入帧。
- 16424 源帧、64424 输出帧；实例、修订、重置、撤销、静音和新实例重开计数均核对。
- 真 libmpv/null 输出分别读取 48kHz 单声道和双声道 WAV，实际时钟前进，NODE
  解码元数据保留 1/2 声道。单声道拒绝、双声道接纳，旧 entry 和 stopped entry 拒绝。
  资格实例没有处理 PCM；这条解码流与上述动态库 PCM 对照是两条明确独立的检查。
报告明确 productionStereoAttachment=false、wholeMaterialVerified=false、
physicalAudioOutputVerified=false。这不是音效已附着该解码器、正式 UI 或实际声卡的证明。
