This archived material uses the modern aev2 object. Its GEQ, BT, nine-slot
PEQ and explicit limiter are enabled; SE, RVB and CMP are explicitly off.
No legacy fallback is merged with it. The other archived explicit-limiter
material has different sibling state. Neither the old settings EQ nor an
arbitrary aev2 material can inherit this receipt's proof.

The test runs the original native code from scripts/research/full_stereo_oracle's
bounded x64 instruction harness in a Linux network namespace with loopback
only. It checks that executable bytes are unchanged. CRT, allocation and
single-thread lock shims are the only applicable host substitutions; the
outer PCM FIFOs, two format converters, DSP nodes, settings setters, reset
and graph dispatcher are native. The inputs are deterministic synthetic
stereo f32, at 44.1/48 kHz with a 2048-frame graph quantum. There is no
Windows process, account, live material fetch, player, or audio device.

Native stream observations, per rate (44.1 / 48 kHz):

- Irregular 6151-frame input produces 6151 output frames. Sending the same
  samples with different write/read splits yields identical PCM bytes.
  Per-graph-call outputs are 1829/1810, 2048, 2048 and 226/245 frames.
- Exact 4096-frame input followed by an empty-FIFO EOF produces 4097
  frames, including the native one-frame sentinel. EOF remains set across
  subsequent nonzero-capacity reads. Zero-capacity read leaves the caller's
  EOF flag unchanged.
- Reset after EOF clears the read EOF state. Reset with 511 pending input
  frames and unread output from a prior full quantum discards both. A new
  4103-frame stream then produces 4103 frames. The old input/output does
  not carry into the new FIFO; reset does not reinstall the material.
- Explicit limiter off changes the output bytes but preserves total frames
  for the irregular stream. Disabling material PEQ through +E0 changes
  whole output and leaves steady +68 byte-identical to +70. The +70 node
  continues to pass through, so it is not the material PEQ node.

EOF and reset are verified for this native SDK entry. This does not show
when every official desktop UI action calls it, or qualify arbitrary hot
preset changes, loudness, disabled-sibling transitions, other formats,
other materials, decoder/seek integration or physical playback. Do not
activate this preset in production based on this test alone.

Candidate equivalence and next integration boundary

- The tracked C `netease_geq_stage_*` and `netease_peq_*` kernels, with
  separate modern BT and material PEQ state, match each native tap and the
  composed pre-B0 samples in 22 of 22 graph calls. This includes initial
  activation, steady quanta, EOF and both reset situations. The modern BT
  uses the shared PEQ kernel, not the standalone BT constructor. It is
  actually enabled even with this receipt's neutral gains.
- All three wrappers start with the off state synchronized before the
  material enables them. Skipping the initial dry-to-wet edges is a
  negative control: only 7 of 11 composed pre-B0 blocks per rate match.
  Reset on an active graph synchronizes its current target; it does not
  replay the first material activation.
- The retained Rust `effect_dsp_render material-limiter-render` CLI feeds
  the observed pre-B0 samples through the explicit B0 plan from the exact
  NCAE. It matches 20 of 20 original PCM output blocks and their frame/EOF
  geometry, across the initial full run and both reset suffixes. Lookahead
  is 219 frames at 44.1 kHz and 238 at 48 kHz. This direct B0 test creates
  a fresh stage for each suffix; it is separate from native FIFO reset.
- A second comparator feeds the composed C samples into one retained Rust
  `material-limiter-stream` per rate. Its 38 operations compare 6151,
  4097, 31 (a partial read before discard), and 4103 frames bit for bit
  against the real outer SDK. Three Rust resets actually run; the reset
  reads are empty and do not report EOF, completed reads retain EOF, and
  zero-capacity reads leave it unset. This test supplies the upstream
  graph quanta, including its processed sentinel, and does not claim
  that production already has a combined upstream FIFO or graph.
