设置页下载目录：官方 PC 3.1.42.205594 与 Cumulus

- setting/views/Download.tsx:893–925 在下载目录标签旁显示当前路径，
  「更改目录」直接调用 Storage.selectDir（:589–604），初始位置来自当前目录。
  取消选择不读取、不提交。路径显示仅缩短 Windows 盘符及 UNC 的规范化前缀；
  原生确认仍使用返回的完整路径。
- :604–673 按顺序检查同一目录、是否可写和已完成任务的总字节数；拒绝时给出
  原因和手动重选。本机的 download_directory_preview 仅接受当前主窗口账号下
  的绝对路径，核对目录可写性时用关闭即删除的探测文件。不创建缺失目录，
  不更改设置、不启动迁移、不访问服务；规范化后禁止文件系统根、私有状态
  目录和嵌套迁移。优先计量持久化输出字节，旧行回退到传输字节。
- :690–718 在上述检查后显示迁移确认；官方确认后通过 App.exitApp(move)
  重启后生效。Cumulus 用既有持久迁移替代退出：change_directory 必须明确
  携带预览的目录修订（第一次配置为 null），账号代次、目录锁、目标路径和
  写入条件均重新核对。原布局保留，第一次选择只保存路径；已有目录的移动由
  DownloadDirectory 记录、等待在途任务、检查实际文件/空间、恢复或撤销。
  前台提示当前状态，下载管理继续提供重开后的操作入口；不会重放不确定提交，
  不自动恢复曾因没有目录而拒绝的歌曲下载。独立音质设置仍在现有配置对话框。
- 窗口在同一设置访问中保持对话框焦点；取消返回原按钮，按钮因迁移暂不可用时
  返回迁移状态或下载管理。迟到的选择与预览不能替换换页、换号后的界面。

验收：core 的 download_directory 测试检查同目录、缺失目录、空间不足均无迁移
或残留探测文件，目录修订改变后旧确认失败，目标被替换成链接时拒绝，第一次设置
隔离其他账号；确切确认后用原生迁移移动实际合成 FLAC，并保留路径命名布局。
真实 Windows 选择器、操作系统卷限制和实体目录写入仍需在相应环境确认。
