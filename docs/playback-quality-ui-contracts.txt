修复的问题及流程
原实现只修改当前队列项 level，已排队的下一首仍可请求旧音质；退出后也没有账号偏好。
原 UI 系统 select 显示请求档位，可能在服务端降级后仍让用户误以为正在播放无损。

Rust controller/quality.rs 独立管理音质切换；quality_preferences.rs 保存账号/访客
隔离的偏好。初始标准、revision=initial；保存/显式修复产生不重复 UUID CAS 标识。
读取/保存都校验当前账号代次；损坏偏好不会阻止普通歌曲播放，也不会静默覆盖原记录。
“重置音质偏好”把原始损坏值和保存标记在本地事务中归档后重置，保留其它设置。

手动选择先请求 /api/song/enhance/player/url/v1 并确认 code/url/md5，不打断旧音频；
授权失败保持旧播放、位置及偏好。授权成功后在同一个 SQLite 事务内检查旧偏好 revision
和队列持久化 CAS、保存新偏好并更新当前资源，提交成功后才重新加载解码器。
保存偏好或队列任一失败均回滚两者，旧音频仍在。新解码失败仍明确回报播放错误；
不声称这时可恢复一条已失效的旧授权。授权成功但返回较低音质时，请求偏好保留，
actualQuality 始终来自实际返回音源；暂停/定位沿用原控制器时间线和授权范围。

队列资源内部附带 quality_preference_revision，仅存在 Rust/本地状态，不发给前端。
Replace/Append 给显式传入的音质附上当时的偏好标识，保留调用者的明确选择；
未指定或为 null 的档位使用当前偏好，voice_id:null 仍按普通歌曲处理。
以后用户修改偏好，旧队列项在普通加载/预取时应用新偏好，不需要重建整份队列。
预取键也包含偏好标识；旧预取不能冒充新档位的预取成功。恢复现成授权/输出设备
时保留该音源的请求，不把已授权的标准流标成新请求的无损流。

前端新播放/加入队列/下一首播放等入口默认读取 qualityPreferences.quality，而非
当前曲目的 requestedQuality 或 actualQuality。明确的 PlaySelection.quality 参数仍
受支持。普通歌曲偏好不改写本地/CUE/已下载文件，也不套用到播客。
播客继续走 voice_id -> 节目详情/播放检查 -> player/url 的原授权链路；手动音质
只更新该节目队列项，不能改动歌曲的账号偏好。

PlayerView 新增 qualityPreferences{revision,quality,damaged,appliesToCurrent} 和
canChangeQuality（选择资源种类是否支持切换；加载/忙碌时 UI 另行禁用选项）。
quality_for{play_id,expected_revision,level} 在产生新的播放意图前验证旧菜单目标，
随后再用 actor fence 校验竞争窗口，迟到的授权还检查账号、播放代次和偏好 CAS。
这样拒绝旧菜单不会顺带取消另一首已经在读取中的新播放请求。旧 quality 动作保留
供现有宿主使用，新菜单只发送带目标的动作。repair_quality 只恢复本地偏好，不请求
业务接口、不启动或恢复播放，也不作为一起听房间控制广播。

界面行为
PlaybackQuality.vue 使用共享 ActionMenu，沿用主题、定位、键盘和离场 inert 动画。
底栏显示“实际音质”；浮层分别说明正在播放/请求的音质和后续播放偏好，选中项与官方一致表示
实际音质。播客说明其选择不会改变歌曲偏好。选项在忙碌时禁用，保留标签焦点；
Escape 返回标签、外侧关闭、账号/曲目/偏好改变关闭旧菜单；周期播放器快照不会关闭菜单。
触发按钮提供当前实际音质的辅助说明，窄窗口限制标签宽度并保留完整悬停提示。打开时聚焦实际音质的选中行并滚到
可见位置，Home/End/方向键也同步滚动，不允许焦点停在被列表裁切的行。
378px 浮层在短窗口约束高度，仅选项区域滚动，标题和说明保持可见。减少动态效果
沿用全局策略，动画使用 opacity/transform；此项不以帧率计作验收。

边界与后续专项
此轮保留已有全部 11 档请求能力；higher/dolby/64aac 放在分隔线后的兼容区域。
官方主选择器会按逐曲 privilege/flag、实验配置和会员/使用权益过滤；当前浮层尚未
完成这组动态过滤，因此没有把静态列表称为“该歌曲全部可用档位”，页尾明确提示
以歌曲和账号权益为准。高清臻音、臻音全景声名称已按官方恢复定义修正。
规格文案是档位上限，不代表当前返回音源的实测采样率、位深或本机已启用空间 DSP。

官方读取现已迁移为独立 Rust 用例及注册 IPC，尚未接入本浮层的动态行展示。
实现、字段、82项官方对照向量和实际 IPC 验证详见 playback-quality-rights-contracts.txt：
- /api/song/enhance/privilege：当前歌曲试用场景的 privilege/flag/maxbr/fl 等；
- /api/song/music/detail/get：songId、immerseType；l/m/h/sq/hr/db/je/jm/sk/vi.size；
- /api/vipauth/app/auth/query：resourceIdList=0、resourceTypeList 为 PC 的
  vivid=41/jymaster=31/sky=32/jyeffect=33，读取可用/已使用/剩余时间；
- /api/vipauth/app/auth/set 是激活试用的写入，不能在打开菜单时调用或自行消耗额度。
官方还会保存试用前偏好、到期后恢复。此套权益提示/试用确认/未知写入对账及到期恢复
仍需专项实现；本轮未用真实账号激活试用、购买或写线上资源。已有其它会员/音效接口
的历史通过不能冒充此浮层的动态权益 UI 通过。
