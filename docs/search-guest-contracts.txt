匿名身份与原生约束
- M198:2262–2295 先复用正常/匿名凭据，无法恢复时才调用匿名注册。
  M115:106–110 复用本机匿名 token 或执行 native encodeAnonymousId(deviceId)；
  M100:53–57 与 M15:1312 发送 /api/register/anonimous {username} 并读取 userId。
  M198:645–677 取 Cookie、去 MUSIC_U 后保存私有匿名记录，再 switchUser；
  :998–1005 会刷新全局实验。M115:218–231 恢复需要原有匿名 UID 与 MUSIC_A。
  Windows 登出 M198:921–949 复用已有 host，不走仅 macOS 的立即注册分支。
- 使用现有独立安装 guest SQLite 与原生签名 PC MusicHttpClient；账号资源接口仍要求
  已验证的真实 SessionToken.uid。Cumulus 的现有运行时负责恢复/注册/未知回执保护；
  搜索请求和搜索失败不触发注册、续期、扩域、登录恢复或重新发送写请求。
  AccountSession 的匿名 adapter 不参与账户刷新/身份采纳；已登录授权仍从其原有 transport。
- 顶栏只从原生 PC presentation 订阅得到 `guestSearchReady`，不接收匿名 UID、Cookie、
  私有凭据代次或实验原值。为可浏览，要求同一隔离 transport 的已注册身份、本机 PC 上下文，
  且默认词和普通综合两个入口目标都具有唯一非空 MUSIC_A、无 MUSIC_U。每个读在发送前
  和回复后仍检查精确目标、代次、API、同一凭据版本；因此某个分类的 Cookie 路径不足时
  单独拒绝。返回 301 作为游客读取失败显示，不驱动已登录会话的恢复。账号切换后的迟到
  回复不会发布；Cookie 写入只在独立 guest 库，并继续过滤所有 MUSIC_U。

Cumulus 首批实现与已知差异
- 使用既有主窗口类型化搜索命令、输入校验、默认词原生回执和结果投影。支持默认词、
  手动输入、联想、普通推荐与热搜关键词、旧版综合与普通分类、纠错和分页；渲染仅展示
  目录卡片和相关词操作。已登录的播放、收藏、下载等入口不因游客结果开放。
- 原 `searchCache` 是官方安装级加密 localStorage（M16:216,492–547、M164:17–23）；
  Cumulus 保留本机独立游客历史，不复制任一账号历史。当前游客结果返回时重新查询，
  不借用已登录视口缓存。仍未开放游客实验的 V3/算法标签、播客/听书热榜或热点外链，
  没有已登录的权益刷新、队列拖入或展示回执。官方无匿名身份期间渲染器不阻止输入，但
  Cumulus 在原生确认已注册且具备目标 Cookie 前禁用游客搜索；不声称无 Cookie 能读上游。
