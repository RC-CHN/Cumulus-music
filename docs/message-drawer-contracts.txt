只读请求和游标
动作                       参数 / 回执
未读                       /api/pl/count {} -> msg, comment, forward, notice
私信列表                   /api/msg/private/users {limit:15, offset:0, time}
                           -> msgs, more；续页游标是最后一条 lastMsgTime
评论                       /api/v1/user/comments/<当前认证UID> {limit:10, beforeTime}
                           -> comments, total, more；续页游标是最后一条 time
提及                       /api/forwards/get {total:true, limit:10, offset:0, time}
                           -> forwards, lasttime, more；续页使用 lasttime
通知                       /api/msg/notices {total:true, limit:10, offset:0, time}
                           -> notices, lastTime, more；续页使用 lastTime
会话                       /api/msg/private/history {userId, limit:10, offset:0, time}
                           -> msgs, hint, more；续页游标是最后一条 time

所有首读的 time/beforeTime 为 -1。只接受账号会话自身的 UID 进入评论 URL；
WebView 不能指定评论账号或请求路径。会话 userId 是当前界面选中私信的对方 ID；
Rust 检查非零数字、游标正整数且不超过 JS 安全整数，拒绝非会话夹带 userId、
不前进的分页及坏包。每次发送前、回包后验证账号代际；仅返回有界文字/计数、
显示所需 ID 和时间。客户端不持久化私信、附件、通知及聊天正文，不暴露附件地址，
不执行服务端提供的 HTML、链接或脚本。未知消息明确显示当前客户端无法展示。

用户流程
账号按钮旁的信封打开独立右侧抽屉；未认证沿用登录入口。只在打开或主动刷新时
读取未读数，无后台请求。初始读取私信，其余三类按激活读取，重复点击当前标签
回顶部；已打开的标签保留当前抽屉内的页和滚动位置。列表触底请求续页，另有
键盘可操作的加载更多。会话时间顺序从旧到新，最新一条在底部；上翻更早页保持视口。
短列表切换时不会把滚动归零误当作触边，可使用“加载更多”或“查看更早消息”；
返回恢复滚动及原会话按钮焦点。失败留住已有列表，重试相同游标；再次刷新读首屏。
关闭或切账号作废待返回结果；每类每次抽屉至多保留 300 条，避免无限 DOM/内存增长。
抽屉以应用顶栏、播放器区域为边界，宽度沿用 386 px；打开动画遵守系统减弱
动态效果设置，关闭立即移除私密内容，不保留动画中的旧账号消息。

明确差异
官方对私信及标签未读有本机清零；官方可快速轮询 /api/pl/count，并对正在看的
会话接入云信推送刷新。Cumulus 保留服务端回报的计数，打开/切换/返回不清零，
关闭不留私密缓存，也不实现轮询、系统通知或云信推送。官方按未读数可预取评论、
提及及通知首屏；这里统一以恢复出的常规 10 条分页按需读取，显式刷新替换首屏。
原版关闭时 `clearNotice` 只重置本地 notice 列表（M/2171:536–550）。
“一键全读”先弹确认，然后调用 /api/msg/count/clear；Cumulus 不执行一键全读、
举报或通知删除。私信写入仅开放下面的明确删除和当前会话纯文本回复。图片仅显示类型；
外链和任意原生跳转留作惰性文本；下面的附件扩展只开放已识别的客户端动作。
未进行真实账户请求；
静态证据可证明客户端不调用显式清零写接口，不能排除服务端对读取接口的隐式计数策略。

Cumulus 流程与边界
- 右击当前行或用可聚焦的“私信操作”按钮打开菜单，删除需要对应的单独确认。
  取消是确认框的默认焦点；取消、关闭或切账号不会提交。服务端明确成功后只移除
  相应会话或单条消息，不清未读数，不改其他列表，不删除通知。
- 原生只为当前认证代际、确实读到的会话签发不透明凭据；单条消息还必须来自已读到
  的对方会话、具有服务端原始正数 ID、且发送者是本人或会话对方。存在明确接收者时
  还必须一致。保留服务端的数字或十进制字符串型别，不经前端数字转换；散列或
  commentId 等展示回退 ID 不能授权删除。IPC 不接受任意 peer、消息 ID 或路径。
  成功后撤掉原凭据；在成功之前发出的迟到读取也不能重新签发删除凭据。
- 写请求前将待核对记录写入认证账号本机 SQLite，持久化内容仅是目标 ID、
  必要的参数型别与随机凭据，没有昵称、正文、附件、Cookie 或 URL。按会话持有
  跨进程锁；同一目标的未知结果不再发送，整段会话与其未决单条删除不能交叉写。
  确认成功或明确拒绝才结清记录；连接中断、异常响应、账号切换后的迟到回复等
  保守保留。关闭抽屉丢弃正文，但待核对凭据可在同账号下再次打开后恢复。
- 核对只发原有的私信列表首屏（15 条）或对应会话首屏（10 条）读取。分别说明
  仍可见、当前页未见或读不到；三种情况都不能证明之前成功，都不自动重发或清
  待核对记录。同一抽屉访问内保留未知结果的原行，即使刷新时没再看到；跨访问
  没有正文缓存时，提供不含消息内容的单独核对入口。该更保守行为超出恢复到的
  官方单次回调；没有找到可精确查询删除任务的服务端回执，不能把分页缺席当成功。
  本地至多保留每账号 300 条未决写，达到上限时拒绝新增删除；读取仍可用。

私信回复：现有会话内的纯文本
================================================================
- 证据：MessageSheet/views/TalkDetail.jsx:169–250,342–368（编译 M/3090:
  3213–3275,3383–3408）显式点发送或 Enter，Shift+Enter 换行；发送前 useBinding，
  以 /^\s*$/ 拒绝空白。共享 TextArea/index.jsx:108–140,450 默认 maxCount=1000，
  按 JavaScript string.length 计算 UTF-16 单元；代理对占两个，允许显示超限输入。
  Cumulus 同时在按钮、Enter 和 Rust 入口阻止超限，避开官方 Enter 调用分支
  未再显式检查 overlength 的差异；输入法合成中的 Enter 不发送。
- M/224.h:84–143 核对已有 bindings 中的数字类型 1；缓存缺失时使用 M/15.Zi
  读取 POST /api/w/v1/user/bindings/{当前认证 UID} {userId}。无已确认手机号时
  展示官方 orpheus://settings/bindaccount 固定二维码；不发绑定写入。
  官方初次重新查询成功却返回空数组时的布尔表达式可放行；Cumulus 未确认存在
  类型 1 就不发送。查询失败明确显示未发出；没有把空/坏回包当已绑定。
- M/2070:288–328（hybrid_47）和 API-0217：POST /api/msg/private/send
  {type:"text",id:0,userIds:[peer],msg}。M/2070 的私信联系人经 M/21:467
  归一化为字符串 ID，因此 userIds 是一个十进制字符串的 JSON 数组；
  id 是数字 0，不带图片 picinfo。正文原样发送，不先去除首尾空白。
- 已读到当前认证账号的私信列表、且该对方的会话读取成功后，才签发不透明的单次
  回复凭据；空会话也需要成功读取。IPC 不接受自行指定的对方 ID。成功删除整段
  会话撤销该对方原有凭据。发送与删除共用同会话的跨进程锁；会话删除未决时不
  提交回复。编辑器草稿仅在抽屉内按账号和会话保留，返回同一会话可继续编辑；
  关闭或切换账号清除内存草稿，不写磁盘。
- 官方接收 code=200 的 newMsgs，归一化 fromUser 并 prepend 到 talkmsgs
  （M/2171:216–227）；刷新视口底部并清空发送成功的草稿。Cumulus 对单条文本要求
  恰好一条可信记录、当前账号的发送者、原始非零 ID，且不能重复发送前本机有界观察内的 ID。
  回包若明确带 toUser/toUserId 必须是当前对方；M/2070 的单收件人调用未要求
  服务器总是带该字段。界面只添加原生投影后的实际回包记录，不按提交正文伪造新行。
  新行的删除能力与旧行相同，由之后重新读取历史获得。
- 2202 明确拦截或原生确认请求未发出时保留原文，不展示原始服务错误正文。
  发出前 SQLite 先存账号、对方、操作凭据和未确认阶段；确定回执仅记录消息 ID，
  不持久化私信正文、昵称、手机号或 URL。重复同一凭据只读原结果，确定结果后
  更换凭据。发送中返回列表时，同一抽屉保留操作身份；重开后只有对应回执才能
  清除旧草稿。回包丢失、形状不完整或身份冲突时保留当前编辑内容并锁定该会话发送；
  同账号重开只恢复未决元数据。核对只读本机回执，没有已证实的服务器请求 ID
  或送达查询；同正文历史和分页缺席均不确认送达，不自动重发。
- 当前不实现新建联系人、群发、图片上传、私信附件发送、转发、撤回、云信实时推送
  或标记远端已读。核对没有使用真实联系人，不外推服务端风控或 Windows 实机。

  scripts/ci/message_drawer_smoke.py --reply 使用封闭合成响应验证相同的真实 WebView
