  M556:362–377 让已完成目录歌曲不显示下载；仅匹配到本地时，该目录歌曲仍可下载。

Cumulus
- 目录歌曲的「更多」、右键和 Shift+F10 复用既有评论计数、播放/暂停、收藏、分享及
  来源分支。本批仅改变原文件定位。目录候选读取只查本机，与既有两秒评论计数并行；
  不发新的接口。失败的候选不会移除其他菜单项。
- 当前账号有完成任务时，只接受唯一、未移动且有原生发布证明的任务。完成记录
  在位但文件缺失、旧账本不全、或同歌有多个完成任务时不转到本地匹配；状态仍是
  已下载。没有完成记录时才查该账号的本地映射，要求唯一可用的当前索引条目。
  不按标题、标签的无归属 ID 或另一账号猜测。多个不同本地候选的原 SQL 顺序不可靠，
  因此不显示目录动作。CUE 选实际音频而非 cue sheet；NCM 选原件而非解码缓存。
- 队列菜单只返回不透明、短期且一次性的 directoryReceipt。新目录菜单取代上一次；
  慢回包不能覆盖后发的目录选择。仅主窗口，定位传 epoch、queue revision、entryId
  和 receipt。Rust 绑定了同一个选择、账号、队列版本和资源类型。没有把完成任务 ID、
  文件路径、签名/媒体 URL 交给 renderer。
- 下载菜单打开时用原生发布记录、路径及文件身份作轻量核对；点击后核对固定文件和
  完整哈希。本地匹配复核账号映射、索引/音频版本和父目录/文件身份，不额外上传或
  查询线上音源。原路径变化、权限消失、隐藏/重扫、原件改写、切换账号或队列时拒绝
  旧选择，绝不转到第二路径，也不改变播放。下载与本地匹配已经绑定的不同文件类型
  不交换。Linux 仅系统明确不支持选择时沿用受检的原父目录回退；交给系统的是路径，
  无法原子防止交接后另一进程再替换路径。Windows 使用既有 Shell 选择适配。
- FM、心动和已附着房间没有这个目录凭据；已下载条目、已索引本地条目和普通在线
  声音仍分别走原菜单。涉及官方付费弹窗的条件不能用 NCM 后缀推断，本批不发支付。

- 原生测试在同一首歌有完成下载与已匹配文件时取得前者，拒绝重复使用、用任务 ID
  冒充队列条目、改写下载后改开本地文件，以及多本地映射；取到映射后变更其归属也
  拒绝。Linux 实窗探针使用实际发布的合成单曲和有归属的合成索引文件，核对目录
  优先级、遮罩/焦点、一次性凭据和原暂停播放。隔离 D-Bus 文件管理器，无真实账号
  写入、音乐请求、实体声卡或 Windows Explorer 结论。
- 本机隔离 Linux 实窗四个截图状态通过：优先打开已发布单曲、打开唯一映射的
  原文件、双匹配不给出定位入口、改动下载原件时报告失败。私有 FileManager1
  收到前两项恰好两次调用，无目录回退；旧菜单凭据、原队列和暂停进度均核对。
  共享发布凭据的既有已下载单曲/声音菜单也重新通过四个实窗状态。
