Cumulus 已实现的只读和本地分支
- 关注页「写笔记」可保存、恢复、删除当前账号的一份本机草稿；文字和最多一个附件
  保存在 Rust 管理的 SQLite，不在 WebView 持久化。文本可单独存为草稿，不等于官方
  允许无附件发布。显式保存或确认公开发布才更新记录；关闭未保存时可继续编辑或放弃，
  账户变化关闭窗口并清空表单。保存和删除校验当前版本，避免覆盖另一窗口/进程的修改。
- community_composer_search 根据账号代次绑定请求和候选，返回有界名称/来源、合规公开
  封面及临时候选号；过滤缺失身份、下架和已知无版权歌曲，仍用服务原始条数判断续页。
  UI 支持换标签、重试和继续加载，后发状态优先。词和 offset 有本地上限。
- community_composer_draft 的 Read/Save/Discard 只读写本机。Save 选新附件必须使用
  当前账号原生候选号；保留或移除现有附件不需要网络。搜索原始结果、私密字段和授权 URL
  不进入草稿；账号代次已失效或版本冲突时不落盘。
- 草稿可以仅保存正文或附件；当前公开发布只接入有正文及一项音乐附件的范围。

公开发布与恢复边界
- hybrid_56/3106.js（SHA256 0c6c4f8ad65e9ff7332bf669cf1148c7aaadcd7cffa30c5e0f26786759de0ed2）
  1403–1563 先执行 host/binding；hybrid_app/198.js:1772–1801 先检查已有 bindings
  的手机号类型 1，缺失时读 /api/w/v1/user/bindings/{uid}，仍无绑定则展示
  orpheus://settings/bindaccount 扫码并返回 false。Cumulus 复用原生固定二维码，不在
  客户端修改绑定；绑定查询失败、身份变化或缺少原生设备 ID 时不提交。
- events 且有附件时，官方 POST /api/share/friends/resource {id,msg,type,uuid,active:0,pics}
  （评论附件另带 threadId）。uuid 由八位随机值、share、时间、uid、deviceId 组合经
  M/3106:1203–1206 的辅助函数生成；pics 是上传完成后的 JSON 数组字符串。
  M/32:11–13,84–89 的 u(8) 是大写 36 进制字符；M/18:21–24 将原生
  deviceId 先 encodeURIComponent；M/314.a 对连接串的 UTF-16 单元低字节做 MD5，
  输出小写十六进制。Rust 使用相同八位大写 36 进制字符集，由原生随机源选取；
  不复刻 V8 的浮点数转 36 进制过程。最终输入为 ASCII，使用三条执行原模块得到的
  固定向量验证摘要、百分号转义与保留字符。
  官方搜索附件类型来自 EventPublish/components/searchTab/index.jsx:17–41 和
  frame.jsx:117–128，分别为 song、artist、album、playlist、djradio。
  Cumulus 保留精确字符串 ID；当前无图片，pics 固定为 JSON 字符串 "[]"。
  hybrid_app/577.js:33–42 要求 code=200 并归一化 response.event；正常回包才能
  给出动态 ID/作者，后续只读详情路径为 /api/v1/event/{owner}/{event}。
- 官方错误分支 512 转购买提醒、510 提示云盘不支持、401 提示不可分享，其余提示失败；
  部分失败将编辑内容存账号草稿。其草稿重开再次提交会生成新 uuid。M/21:1276 可读取
  返回事件的 uuid 字段，但未确认它必然回显请求 uuid、是幂等键或能通过自己的 feed
  找回回包丢失的提交；详情端点必须先有动态 ID。没有把内容相等、成功提示、
  返回值缺失或没有看到新动态当作可安全重发的证据。
- Cumulus 仅从当前账号的原生搜索附件和保存的精确草稿版本生成请求。用户先点击
  “发布笔记”再确认公开发布；确认框先聚焦取消。保存本机草稿、点取消、切页、
  重开、核对回执、查看详情均不会触发发布。没有纯正文或纯附件发布、图片、评论
  附件、转发、私信、自动付款或自动绑定。遇 401/510/512 时展示相应拒绝并保留
  草稿；512 不直接发起购买。
- 发请求前同一账号的 SQLite 事务记录草稿版本和 UUID，并按账号持有跨进程锁；
  不在发布记录重复存正文、手机号、设备 ID 或 Cookie。明确的 code=200 回包必须有
  正确作者及动态 ID；若回包还携带非空 UUID，必须精确匹配。明确成功后原子落盘
  动态 ID 并清除同一版本草稿；详情凭据只由该账号的持久成功回执签发，查看详情
  走既有 /api/v1/event/{owner}/{event}，不能把输入 ID 当授权。
- 对连接中断、缺事件 ID、身份不符或其他无法确认的回包，显示未确认，保留本机
  草稿和提交记录；同账号重开仍可查看，并阻止再次提交和覆盖草稿。核对按钮只读
  本机持久回执，可区分已经保存的成功和仍未确认；没有已证实的服务端 UUID 查询
  或明确的读取回显，故不扫描关注列表、本人主页或相同正文来推测，不自动重试。
  官方在 M/3106 和 M/3105:622–632 以临时“发布中”卡占位，回调后移除；
  Cumulus 保留编辑框，显示本机回执状态，不把临时卡误呈为已经发出的动态。
