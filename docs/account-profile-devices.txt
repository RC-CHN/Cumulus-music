Cumulus 账号资料、绑定及登录设备读取

入口：设置 → 账号 → 个人资料 / 登录设备管理。两页独立加载，
返回设置不提交资料，打开设备卡片只显示详情。未登录不会请求这些接口。

官方来源与网络契约：
  PC 3.1.42.205594 M15:1742–1756、M100:63–82
    POST /api/w/v1/user/detail/{uid} {all:true,userId:uid}
    读 profile 与 level；profile.userId 必须与原生会话 UID 相同。
  PC M15:3642–3644、M100:179–185、pages/bind/views/index.js:260–339
    POST /api/w/v1/user/bindings/{uid} {userId:uid}
    读 bindings[]，按 type 投影。0 邮箱，1 手机，2 微博，5 QQ，10 微信。
    原始 tokenJsonStr、第三方身份 ID 和跳转 URL 不传给 WebView。
  PC M15:4962–4981、M3122:14–80/304、pages/loginDevice/index.tsx
    POST /api/middle/user/device/list {excStatus:9}
    读 data.userDeviceList 与可选 userDeviceLimitInfoDTO；
    当前设备优先，status 1/“1”归已登录，未知字段不填默认值。
    WebView 只收到本次响应生成的行 ID，不得到原始 deviceKey。
  设备额度：pages/loginDevice/index.tsx:229–244、
    pages/loginDevice/components/UserMembershipCard.tsx:251–269、367–437。
    资料卡位于两个设备分组上方。使用同一设备列表响应里的 nickname、
    avatarUrl 和 currentNum，不从设备分组计数推导。数字 0 按官方显示为未知。
    vipType 1（畅听）与 0 同列；6 和 15 分别标为黑胶 VIP 与 SVIP。
    无法识别的类型不标当前档；额度按 deviceLimitRule 的 0→1、6、15
    取值，缺值采用官方组件的 5/8/10；不把 DTO 的 deviceLimit 当成三档额度。
    M3122:14–31、292–322 在找不到设备时不会更新 DTO；本端在无设备、
    DTO 缺失、标记 isEmpty、加载、失败或切换账号时不渲染卡片，避免露出
    官方初始化模型的占位数据或上一账号的内容。
  地区显示使用 M591 的静态回退表：31 个省级分组、472 个城市映射。
    源文件 SHA-256 7c07d9246b81e74422479a3d99c8972fbcf0c58e259cfa1b4abc337ee1a41351。
    只移植地名和代码；未知值显示原代码，暂未移植 M198 的地区表文件与服务器更新。

Rust 与 IPC：
  account::profile::AccountProfile 提供快照、资料、绑定及合并读取。
  本客户端在个人资料页显式串行读取资料和绑定；官方分别按页面读取。
  client::MusicClient::account_profile_detail / login_devices 获取当前 epoch 的
  SessionToken；每次请求完成核对账号代次，返回前再次核对。
  desktop 主窗口只暴露 account_profile_detail / account_login_devices，
  参数为当前 epoch；不接受目标 UID、设备键或任意业务路径。
  响应外壳为 {epoch,value}。读取不新增持久状态，也不改账号资料。
  额度卡的头像只接受已知网易音乐图床；强制 HTTPS，并替换上游查询参数和片段。
  缺失必需结构、归属不符及服务错误返回错误；成功的空数组才是空列表。
