原生投影
- PlayerView.voiceDetail 为可选字段；存在时是
  {id,creator:{id:string|null,name:string}|null,releaseTime:number|null}。
  releaseTime 仍为原始整数毫秒，不进行日期或时区格式化。
- 投影只读取同一个 PlaybackSnapshot 的非空 playId 和 selected.resource。节目声明 ID、
  voice.id（及存在时的 programId）必须相同；resource.id、存在的 song.id 和声音
  mainTrackId/track.id/mainSong.id 必须相同，且至少有一个声音主歌曲字段证明关联。
- 普通在线声音必须属于原生 Voice 命名空间。下载声音额外要求合法本地任务身份、
  download_voice_id 与 song.voice_id 一致。download_voice_id 只在 native
  download_resources 从 DownloadOrigin::Voice 填入；Song/Cloud 任务不能靠任意
  原始 voice JSON 自称节目。该内部标记不进入 PlayerView、TrackView 或队列 IPC。
- 下载列表与新播放资源共用一份按原生 DownloadOrigin 规范的 metadata 副本。
  非 Voice 任务移除 voice 和 voice_id，避免原始节目 JSON 让普通 Song/Cloud
  任务误入前端节目布局、隐藏歌手/专辑与下载来源；无效的原始 voice_id 也不会在
  类型规范前令 track 映射失败。Voice 任务的 song.voice_id 采用 typed voice_id，
  不信任同名原始字段。原始 voice 对象保持不变，只有现有节目/主歌曲关联核对通过
  才投影主播和日期；typed ID 不能覆盖冲突的 voice.id 来伪造详情。
  这些规范只作用于读取时的副本，不重写原下载任务，也不迁移历史恢复队列。
- 本地音乐/CUE、云盘、普通歌曲及含有冲突身份的下载记录不借用声音标题信息。
  没有增加每次时钟更新的数据库读取，也没有通过 UI 接收此内部标记。
- 主播名字按官方优先级取字符串；缺有效 userId 时保留纯文字名称，不猜导航目标。
  ID 最多128个十进制字符；昵称最多512个 UTF-16 单元，不投影空白或控制字符名称。
  原始 creator 对象中的头像、权限、账号和授权字段均不经过 IPC。
- 发布时间只接受 1…8640000000000000 的整数毫秒，缺失、0、负数、字符串、分数
  或超出 JS Date 范围均为 null。不能拿 publishTime/scheduledPublishTime、歌曲
  专辑日期、文件 mtime 或当前时间替代。缺失时间的界面占位由前端单独说明。

兼容边界
- 历史已经恢复的下载队列可能没有 download_voice_id；不在播放时猜其原始下载种类。

节目简介
--------
官方 M21 W:939–945 原样投影节目对象的 description。VoiceDisplay.tsx:69–80
在订阅卡之后放置 DescCard；DescCard.tsx:14–55、64–68、112–149 在空简介时
不显示，非空正文保留段落空白，默认四行，可展开再收起，文字可选。

Cumulus 从现有 `/api/dj/program/detail` 所得或从下载任务已保存的、能与
当前播放和节目身份匹配的 description 投影。无额外请求。只接收普通文本，
最多 8192 个 UTF-16 单元；忽略空值、非字符串、超长和除 CR/LF/Tab 外的
控制字符。保留其他有效文本原样。不借用播客节目单、主音轨或其他资源的描述。

简介在右侧详情栏显示；若同一节目也有现有歌词，简介作为独立的滚动区在歌词
前出现。布局按实际文本宽度计算四行预览；折叠时只复制可见预览，展开后才
能选择全文。宽度变化重算，焦点不随展开或收起丢失。换账号或换集后重置。
通用排版组件的内联展开按钮和官方遥测不在此切片。

Linux 真实 WebView 验证 15 个阶段：四行 104px、六行 156px、收起后恢复
四行、焦点及暂停时钟不变，随后恢复播放并切到短简介或无简介的下一集。
真实鼠标和 Gtk 系统剪贴板读回四行纯文本，不含隐藏文字或 HTML。展开、
收起与复制不会增加节目请求；播放和切集只走已有节目请求。7 项定向 Rust
测试另覆盖下载回读、缺失/非法文本及身份边界。使用合成数据及空音频输出，
未实测 Windows WebView2 或实体声卡。
