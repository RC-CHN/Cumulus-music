三、工程与桌面职责
core/ 是独立跨平台 Rust 核心，不依赖 Tauri/WebView/前端，不通过调用归档 Python 进程冒充迁移；恢复的 C DSP 可经明确安全 FFI 复用并对照。按领域和职责组织 API、用例、状态机、持久化、适配与测试，避免单文件全能模块。desktop/ 负责 Tauri 生命周期、应用目录、窗口、托盘、快捷键/媒体键及适用的平台媒体控制；frontend/ 通过类型化 CoreClient/IPC命令和事件通信，不直接持有Cookie/签名密钥/完整授权URL或访问官方业务API。接入真实音频引擎，不能用进度条模拟播放。账号隔离、代次校验、取消、并发互斥、未知远端写入对账、断点与崩溃恢复必须落到业务流程。默认保存账号获准下载的普通音频，NCM保留显式兼容选项。研究材料继续置于 references，不把私有会话、官方安装包或无关恢复制品带入正式产物。
