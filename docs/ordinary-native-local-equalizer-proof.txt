Ordinary native file / local equalizer actor probe
=================================================

Product scope
-------------

The ordinary native file-open route can pass the saved GEQ and bass/treble
controls into the recovered M3091 local material graph. See
core-effects-local-equalizer.txt for the original reset, enable, bypass and
B0 processing order. These original proof cases leave SE and RVB off. The
additional source-bound SE controls are specified in that contract; the
original proof cases below are unchanged. The decoder
must be a verified packaged libFLAC 1.5.0; only the supported 44.1 kHz stereo
FLAC geometry with a full independent source timeline qualifies. An absent
or mismatched packaged decoder keeps the ordinary stock decoder.

The checked audio handle remains owned by one source. Before the first
unpause, a recoverable optional preparation failure can return that same
handle to the stock decoder. A seek retires the original native stream,
reclaims the source, resets the graph and publishes a replacement native
entry while retaining the queue item and logical play. A failed replacement
does not restart the audible source. If an independent PEQ is explicitly
selected, the paused handoff retains the held file and source clock, restores
the ordinary GEQ controls, and then applies the independent component.

The worker acknowledges controls separately from the native playback clock.
Buffered samples keep the setting that produced them. Edits after the graph
has finished are kept for a later seek or load; the native sink may still
play its already generated tail. Online tracks, CUE/trial windows, library
items without a native open handle, and other audio geometries retain their
existing paths.

Reproducible desktop checks
---------------------------

The dedicated native_local_equalizer_probe example starts a real Tauri
WebView with the production frontend, numeric locale setup and the
production MusicClient. Its registry is a new isolated guest profile and
its Api can only defer synthetic guest account restoration; all other
requests are rejected. On Linux start it with en_US.UTF-8 in the existing private
Xvfb/D-Bus/network harness. The example checks that GTK startup retains the
message locale while setting LC_NUMERIC to C.

From a native handler after page load, the example applies a nonzero GEQ
curve and bass/treble through the ordinary equalizer action, selects
sequential mode, and calls play_native_open_files with the existing frozen
synthetic FLAC (44.1 kHz, two channels, 16-bit, 1024-sample blocks,
88207 frames, real seektable). No renderer pathname, new IPC, audio rights,
fixture engine, or independent cold playback controller is used.

The same concrete MpvEngine is wrapped only to report the bound native
entry, acknowledged seek replacement, real processor observation and EOF.
The initial EQ must persist and select the combined graph before .1s of
source clock is observed. Pausing holds the clock, changing a band while
paused retains the logical play, and a .5s seek replaces only the native
entry on the held graph. Resuming must observe processing and then actual
EOF on the replacement entry. The public timeline ends at the original
source duration and the durable EQ record keeps the edit. The fixture does
not enable SE or claim its one-second tail; the sealed cold source and DSP
reference vectors cover that separately.

A second fresh process uses the same verified FLAC library and source bytes
but deliberately passes a different expected digest. The same actor route
must select the existing native decoder without a local graph, preserve
the user's EQ preference, pause, seek without a replacement receipt and
reach the real stock EOF. The driver independently checks the native trace
and durable-preference fields of both cases.

With --filter-library ABS_FILTER, a third fresh process uses the actual
independent LADSPA PEQ library. After the held graph has processed on both
native entries, it pauses again and applies a small synthetic plan using the
trusted native-only MusicClient method; no entitlement transport is involved.
The actor must retain the same logical play and queue, acknowledge exactly
one change from the current raw graph entry to a new stock entry, and keep
both its logical clock and the settled native paused clock near the prior
source position. After resume, the native plugin must report real processed
samples on the new stock entry only. That entry must reach actual EOF and
the local GEQ/BT edit must remain durable. This checks handoff and isolation
of native processing, not the full official effect-selection graph or
audible parity.

These runs are not an argv or
package-resource-path test; native_file_open_smoke remains the registered
production entry test. They use null audio, no physical output.

Build on the exact integration source with:
  cargo build -p cumulus-desktop --example native_local_equalizer_probe --features custom-protocol --locked

Run with a staged trusted 1.5.0 library and its expected digest:
  GDK_BACKEND=x11 LC_ALL=en_US.UTF-8 xvfb-run -a dbus-run-session -- \
    python3 scripts/ci/native_local_equalizer_smoke.py --binary ABS_PROBE \
    --flac-library ABS_STAGE_FLAC --flac-sha256 PACKAGE_FLAC_SHA256 --root NEW_REPORT_ROOT
Put the command in the established no-egress CI namespace; the Python
launcher does not independently create one. An explicit --mpv-library can
select the same verified package libmpv for a native runner, and
--frontend-dist is only for an already built exact frontend snapshot.

Observed Linux results
----------------------

With the locked Linux libFLAC 1.5.0 stage and the frontend assets unchanged
from 47a85d71, the real Linux WebView example built from 4e5c2e77 passed all
three isolated cases. In the qualified case the native raw entry 1 was
replaced by entry 2 after a paused seek to 0.5 s. The actor kept the same
logical play and reached real EOF at 88207/44100 s. The stock case used the
same audio with an intentionally mismatched decoder digest. Its seek and
EOF stayed on the original stock entry. The independent PEQ case went from
raw entry 1 to seek entry 2 to paused stock entry 3. Only entry 3 reported
PEQ processing samples and EOF; the handoff retained playback position,
queue identity and the durable GEQ/BT edit.

These results use a local guest, a real GTK/WebView and null audio output.
They do not cover the OS file picker gesture, physical output, Windows
execution of this route, or the native opener's remote sources. The
package resource checks and proof using the concrete native decoder are
separate. The local aggregate is in
.build/ui-proof/phase65-ordinary-local-equalizer-r4/report.json.

Paused replacement startup regression
-------------------------------------

Linux CI 42092833982 verified its packaged library and then timed out waiting
for the paused 0.5 s seek in the trusted case. Its failure receipt had real
entry 1 → 2 and both saved EQ settings; no successful EOF was recorded. That
receipt did not expose per-poll seeking state. A bounded producer/reader test
reproduced the deadlock before the fix: the new paused entry could not supply
two raw audio packets, even though its native clock had not advanced.

libmpv 0.37 reads about 5,512 frames per raw packet at 44.1 kHz
(demux/demux_raw.c:164–171). Its null output defaults to a 0.2 s soft buffer;
the audio readiness path requires a full queue or actual EOF before restart
(audio/out/ao_null.c:195–200, player/audio.c:830–856,
player/playloop.c:1024–1059). The old startup credit could supply less than
the soft-buffer target; binding the new entry paused then froze production.
The same fixed budget used during unpaused startup can now supply at most
the quarter-second lead plus one processing quantum while the newly bound
paused entry is seeking. A matching, valid native clock sample ends this
allowance permanently, even at zero. No synthetic clock or unpause is sent.
The actor keeps its seek indicator until the replacement entry reports its
actual state; ordinary settled pause and later seeks retain their old limits.

Windows CI 42101827974 reported a separate cold-path regression: all 11 Rust
cold cases passed, but the real WebView/libmpv probe exceeded its first-packet
bound. The first paused replacement change had allowed additional reads for
both channels. `native_channel` now supplies that allowance only to an ordinary
held source; the older cold channel keeps its original first-packet grant.
The Rust tests exercise both distinct channels and prove a settled zero clock
closes the ordinary allowance. On real Linux GTK with the packaged libFLAC and
local libmpv 0.41, the old cold path produced 7,973 paused frames (limit 9,609),
then reached native EOF; the three ordinary trusted, wrong-digest and paused
PEQ cases also passed. Exact candidate `e8297a9f`; evidence:
`.build/ui-proof/phase70-cold-stereo-r1.json` and
`.build/ui-proof/phase70-ordinary-eq-r1/report.json`. This does not establish the
same result on Windows or on the older Ubuntu CI libmpv.

The updated real WebView probe requires two distinct native polls at the
replacement ID with pause true, seeking false and clock near 0.5 s before
explicit Resume. It also keeps a bounded tail of native poll observations in
failures. All three cases passed on local libmpv 0.41 with the same FLAC 1.5.0
decoder/filter bytes from CI 42092833982. Evidence:
.build/ui-proof/phase68-native-eq-r2/report.json. This local result does not
substitute for a repeat on the CI runner's libmpv 0.37 or physical output.

Spatial control continuation
----------------------------

Use the same trusted staged libFLAC and ordinary example, with the runner's
--spatial-controls-only option. This opt-in case requires the matching real
frontend bundle. The sealed fixture explicitly opens only the same frozen
FLAC twice; all slider commits, master, seek, resume and reset are driven
through the rendered main window and its production Tauri commands. It
distinguishes an uncommitted slider preview, saved-but-unavailable stock
settings with no restart, qualified stereo-only raw PCM, paused hot apply,
master disable/reapply, actual paused replacement seek, resumed processing,
and native EOF. The runner compares each UI state with the local SQLite EQ
record and the actual engine trace; the original three EQ/PEQ cases retain
their checks and command line. The ordinary Linux app also started and
played synthetic local audio in a private PipeWire sink; its monitor had
nonzero PCM in play and zero PCM in pause. This does not test a physical device.

On isolated Linux Xvfb/D-Bus, add --screenshots to --spatial-controls-only
to capture all seven actual stages. The proof waits for each PNG receipt
before advancing; actual opaque dialog/footer padding is checked against the
compositor image, with a bounded wait for GTK paint. These images remain
separate from the native sink/EOF assertions and do not validate frame rate.

Linux verification on `e8297a9f` captured 7 real WebKitGTK states and 7 PNGs:
`.build/ui-proof/phase70-local-spatial-r3/report.json`. The browser range's
2.00016 ms step accepted 0.50003968 s for a requested 0.5 s; the native seek
used exactly that accepted value, switched the decoder entry 2→3, preserved
the logical play, paused correctly and ended on entry 3 at the source's
2.00015873 s. The same test proved hot changes and the main switch preserve the
paused play; reset clears all four enhancement controls without modifying GEQ.
