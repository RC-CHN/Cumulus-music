Cumulus 独立 Rust 实现
- Native host 用 MusicClient::configure_streaming_media_cache 显式加载设备
  偏好并启用；失败不改动已有播放器，调用方可继续使用普通 URL。另保留内部
  自定容量的试验入口。只选普通、线上、完整、明确非试用、免费 MP3 的已授权表示。
  只认实际 standard/higher/exhigh，严格校验 id、type、fee、
  flag、trial、size、完整 MD5 和短期过期信息。FM、私人雷达、一起听、云盘、
  本地、下载、试听、未知字段及其它格式保留原路径。
- 先使用原播放源解析。当前播放直接拥有的原请求如果返回新授权且符合规则，
  可以查找或填充字节；内存 URL 或共享的进行中请求不能授权字节复用。仅当
  原选源对应同账号/歌曲/实际音质/长度/完整 MD5 的已完成且经解码确认条目时，
  才专门请求新的原授权。拒绝时不使用旧字节或旧内存 URL；授权内容变更时
  使用新的普通路径。不符合规则的源和没有字节命中的内存 URL 沿用原路径，
  不多发授权请求。播放进程只在内存持有 URL 和强 ETag；它们不写到文件、
  SQLite、UI 或日志。磁盘索引不授权、不离线命中。
- MP3 最多 8 MiB。一个首块 (<=64 KiB) 用来验证范围和媒体头；没有额外
  全量下载。libmpv 通过其本机只读 stream_cb 读取/定位，按需要取固定窗口，
  一个未决请求，不重试，不重定向，不接受压缩、重复响应头、弱/变化 ETag、
  错位或越界范围；后续范围带 If-Match。只有本次播放确实覆盖全部窗口并
  与来源完整 MD5 一致、且 libmpv 成功确认 MP3 解码后才可复用。仅本机
  选源前失败可用原 URL；原生已
  选用此读者后不自动重放第二条路径。
- 私有状态目录内固定 streaming-audio-v1，只为新内容创建 tempfile；Unix
  不留可重开的文件名，Windows 按句柄关闭时删除。不遍历或删除目录内容。
  索引在内存，操作系统按实际句柄寿命释放文件；
  跨重启不保留缓存。预算按整条表示预留，包括未完成、正在使用、已清除
  但还持有的文件；还限制总持有文件数，容量不足仅逐出无租用的最旧完整对象。
  clear 让新查找和未完成旧填充失效；当前已授权读者可以继续，结束后归还
  空间。已退休的进行中读者仍可在已有预留内读取/写入临时窗口，但不能重新发布。
  没有搬运目录、内容持久恢复、整套官方 AB/权重、解密或旧缓存导入。

设备偏好和状态
- 配额 512 MiB–10 GiB、512 MiB 步进，默认 1 GiB；只存容量和防陈旧修订，
  设备作用域 local-device，无需账号。每次读/写核对持久记录；旧界面、同机
  其它进程变更后的旧修订及上次启动的修订不能写。字节用量变化不刷新控件
  修订。缩容先收回未使用的最旧数据；活动预留仍超额时移除旧索引/禁止旧填充
  发布，当前播放继续，关闭后释放，不用停播兑现立即清空。
- 状态报告固定目录（只展示，不作调用参数）、容量、已成功写入的媒体字节、
  预留字节、可立即回收字节与预留超额。数字不是文件系统实际扇区数；清除
  后活动句柄仍可能持有数据，不能提示为全部立即释放。清理仅作用于当前
  宿主进程的字节缓存；不清其他进程、下载、离线授权、曲库、或普通内存 URL。

验证入口
  cargo test --locked -p cumulus-core --lib stream_cache
可选真实 libmpv/null 验证：先生成一份 64–128 KiB 的合成 MP3，例如
  ffmpeg -f lavfi -i sine=frequency=439:sample_rate=44100:duration=3.8 \
    -c:a libmp3lame -b:a 192k /tmp/cumulus-synthetic-cache.mp3
  CUMULUS_PROOF_STREAM_MP3=/tmp/cumulus-synthetic-cache.mp3 \
    cargo test --locked -p cumulus-core --lib actual_native_streaming_cache_reauthorizes_each_play -- --ignored
2026-11-05 Linux 本机验证：92,830 字节合成 MP3，真实 libmpv/播放器 actor
首次读取两个窗口，再次播放发新授权但读取零远端字节；清理期间同一 playId
可定位并继续推进；模拟下一次新授权后重新填充，合成 403 时不能播放已有
字节。未命中的有效内存 URL 不为缓存额外刷新；不符合规则的播放沿用普通路径。
验证关闭普通 URL 解码，合成 API/字节传输不访问真实服务；不代表实体音频
输出、真实 CDN 覆盖、Windows 运行或跨进程磁盘缓存通过。

桌面设置与真实 WebView 验收
- 正式桌面在创建播放器前按本机应用目录配置缓存；初始化失败仅禁用缓存，
  正常打开应用并沿用原音源。主窗口的设备级 IPC 为 playback_cache_state、
  playback_cache_set_capacity、playback_cache_clear。写操作接受当前修订；
  只有容量提交额外接收字节数，没有路径、账号或音源参数。状态未确认时只回读。
- 设置页下载区之后显示「在线播放缓存」。按官方 0.5G 滑块步长及松手后提交；
  清除按钮直接请求，成功或部分仍使用分别显示。实际目录只读；不移植旧官方
  客户端的换目录、重启和删除旧目录。调整容量不更改下载目录或下载文件。
- Linux X11 的真实 Vue、IPC 和原生配置通过五态：1G 初次读取、1.5G 预览与
  单次提交、显式清理、关闭并重开后保留设置、缓存路径不可用时继续用原生
  libmpv 播放。非法容量和过期修订均拒绝，未删任何不属于本进程的文件。
  设置试验的缓存库存为空；字节命中、范围读取和活动句柄依赖上面的独立
  libmpv 试验证明。Windows 流程已接入独立 CI，未据 Linux 宣称 Windows 通过。
  重现：scripts/ci/playback_cache_smoke.py --binary PATH_TO_UX_UI_PROBE --root NEW_DIR。
