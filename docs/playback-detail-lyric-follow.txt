歌词辅助模式和时差控件
----------------------
官方恢复证据：TrackPage/components/TrackLyric/LyricOperator.tsx 仅在存在对应
文本时显示音译或翻译；LyricDisplay/LyricDisplayInner.tsx 按单个 lyricMode
显示辅助行。时差控件只用于可滚动的歌词，变化步长仍走官方 gain ±1
（半秒）；切换辅助模式或调整时差后恢复跟随。显示层读取对应 LRC 或逐字
歌词实际提供的辅助文本，写入时继续走 Rust 的账号隔离歌词偏好接口。旧偏好
可能同时启用两项：两项均存在时先显示翻译，首次切换后保存单项或关闭状态。
这是旧偏好的兼容策略，官方默认值没有从上述代码确认。此模式切换只显示
服务响应已有的辅助文本，不发新的翻译请求；桌面浮动歌词设置保持独立。

player_layout_smoke 用合成双辅助歌词和仅原文歌词验证互斥、恢复跟随、
±0.5 秒回读以及无对应内容时隐藏按钮。

停止和切歌时的歌词读取
--------------------
播放详情沿用官方按当前资源更新的歌词来源。主界面将读取、调整与
账号和 playId 绑定；停止、换曲、重连或销毁时立即清除旧歌词、转圈
和错误。详情仍可见且没有播放 ID 时，页头改为「播放详情」，
歌词区显示「暂无播放中的歌曲」。
同一文档读取与调整互斥，防止重新加载的回执盖掉刚完成的偏移；下一
首不用等待旧调整。只接收同一操作的回执，不自动重发写入。这个状态
隔离是 Cumulus 的异步处理，没有新增服务接口或改变官方半秒步长。

Linux 实际 Tauri WebView 的 player_layout_smoke.py 让合成歌曲的歌词
接口延迟两秒，在加载中按底栏「停止播放」。旧前端复现转圈不消失；
修复版显示空闲说明，延迟回执到达后仍没有旧歌词或调整按钮。独立
前端回归验证读写不能互相覆盖、旧请求不阻挡新歌曲。测试使用合成
歌词和 libmpv 的空音频输出，无真实账号写入。

选择与复制歌词
------------
官方 LyricDisplayInner.tsx:560–588 在原文及可见辅助行开启文本选择；
vinyl-page/index.tsx:308–326、341–374 在打开黑胶页时启用剪贴板过滤，
关闭时撤销。恢复的 288.js:10–44 过滤不可选元素并按块写入换行，
调用端将连续 CR/LF 归一化为一个 LF，并只写入 text/plain。

Cumulus 在播放详情使用原生文本选择，原文、逐字歌词及已显示的翻译
或音译都可复制。复制保留实际选中的字符和段落顺序，跨段落以 LF 分隔，
并保留官方外层段落产生的末尾 LF。歌词工具、贡献者和空行占位符不进入
剪贴板。范围延伸到播放详情外，或在输入框和文本编辑器内复制时，交给
系统默认行为。普通点击或
Enter/空格仍通过已有 seek_for 定位；拖选本身不发送播放命令。试听限制
只约束定位，仍可选中可见文本。拖动中暂停自动跟随，松开后恢复原有规则；
切歌、换账号或离开歌词栏时清除本栏的旧选区。没有新增请求、IPC 或权限。

LyricDisplayInner.tsx:265–330 中按 Windows 翻译实验开放的全选、持久
选区停止跟随，是不同范围的行为；本实现不拦截全页或全局快捷键。
浮动桌面歌词不是播放详情内的选区，不在此范围。

划词查询是另一条链路。官方 components/LyricMenu/index.tsx 提供「复制／
翻译」菜单，TranslateContent.tsx:288–345 在用户选择翻译后向
https://dict.youdao.com/dictserver/cloudmusic/searchq 发送 GET；参数是
keyid、截断至 600 个 UTF-16 单元的 q、以及排序并附加集成密钥后得到的
MD5 sign。code=0 读取 from、to、itemList；业务失败、网络异常和离线分开
显示。另有 Windows 的注册表查找和启动有道客户端。该第三方集成凭据和
宿主应用入口不随 Cumulus 分发；本次只做本地复制，没有把用户选择的歌词
发送给任何服务。已有服务端随歌词返回的翻译和音译保持可显示、可复制。

Linux 的 vinyl_lyric_copy_smoke.py 使用实际 WebKitGTK、X11 鼠标和键盘、
系统剪贴板与 libmpv 验证 8 个状态并截图。跨行复制的剪贴板只有纯文本，
准确保留中间可见翻译；同一行拖动虽产生真实 click 事件，仍保持原生暂停
时钟。点击、Enter 和空格各自定位，同一播放 ID、队列项和队列版本不变。
播放详情的 30 个既有检查点另行通过。使用合成媒体和空音频输出；未验证
Windows WebView2 或实体声卡。
