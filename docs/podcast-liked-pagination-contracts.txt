Rust 候选：MusicClient::podcast_liked_page(epoch, query)
- open 仅创建原生 visit/revision 和首个 continuation；瀑布流挂载后用 next
  消耗该令牌。一次 next 最多发一页，返回新增行、累计 loadedCount、最新已知
  count 和下一 continuation；没有 continuation 表示自然结束或明确 capped。
- suspend(visit,revision) 使行和后续页令牌失效。restore(visit,revision) 只在
  同账号代次和原生播客失效代次，且本进程保留这一离开回执时，返回完整前缀；
  不读接口，重新签发活动 revision。旧 active revision 和更早的回退回执均无效。
  保留一个进程内离开前缀，最多离开后 1 小时；未迁移官方跨进程持久化与 7 天清理。
- UI 不接触原始 cursor/主音频凭据。只读活动前缀的节目投影由
  podcast_liked_page_program 校验 visit、revision 与已见节目 ID，下架行继续
  显示不可用。其他行没有本视图的原生凭据。分页动作不授予播放器或下载权限。
- 当前续页同次只发一个；重进、离开或账号/播客写入切换期间到达的旧页不能提交。
  按节目 ID 保留首次显示；游标始终取原始页末行，包括跨页重叠末行。保留发送
  游标原始 JSON 类型，数字/文本同值重复也拒绝。失败、缺失字段或不前进时
  保留已提交前缀和可显式重试的游标；区别于官方非 200 空对象分支，不将失败
  误呈现为翻页结束。单页限 100，最多 500 页，截断明确标为 capped。
- podcast_liked_count 独立执行上述计数请求，缺失/失败不视为 0，不修改前缀
  或成员快照。后续页面仍须丢弃失效路由的计数回复。
