Rust 候选：MusicClient::podcast_liked_page(epoch, query)
- open 仅创建原生 visit/revision 和首个 continuation；瀑布流挂载后用 next
  消耗该令牌。一次 next 最多发一页，返回新增行、累计 loadedCount、最新已知
  count 和下一 continuation；没有 continuation 表示自然结束或明确 capped。
- suspend(visit,revision) 使行和后续页令牌失效。restore(visit,revision) 只在
  同账号代次和原生播客失效代次，且本进程保留这一离开回执时，返回完整前缀；
  不读接口，重新签发活动 revision。旧 active revision 和更早的回退回执均无效。
  保留一个进程内离开前缀，最多离开后 1 小时；未迁移官方跨进程持久化与 7 天清理。
- UI 不接触原始 cursor/主音频凭据。只读活动前缀的节目投影由
  podcast_liked_page_program 校验 visit、revision 与已见节目 ID，下架行继续
  显示不可用。其他行没有本视图的原生凭据。分页动作不授予播放器或下载权限。
- 当前续页同次只发一个；重进、离开或账号/播客写入切换期间到达的旧页不能提交。
  按节目 ID 保留首次显示；游标始终取原始页末行，包括跨页重叠末行。保留发送
  游标原始 JSON 类型，数字/文本同值重复也拒绝。失败、缺失字段或不前进时
  保留已提交前缀和可显式重试的游标；区别于官方非 200 空对象分支，不将失败
  误呈现为翻页结束。单页限 100，最多 500 页，截断明确标为 capped。
- podcast_liked_count 独立执行上述计数请求，缺失/失败不视为 0，不修改前缀
  或成员快照。后续页面仍须丢弃失效路由的计数回复。

主窗口 IPC 已提供 podcast_liked_page、podcast_liked_count 和
podcast_liked_page_program。TypeScript adapter 只发送类型规定的字段并核对回复 epoch。
usePodcastLiked 独立管理前缀、计数、滚动位置和回退：open 触发首读，next 只在活动
前缀有 continuation 时执行，suspend 先在界面撤销行凭据，restore 复用前缀和原滚动位置。
恢复前缀为空时由虚拟列表的首读观察触发 next；只有确定原生回执已失效时 Back 重新打开。
count 可独立调用，由外层路由安排 M3108 的计数触发；迟到回复不会覆盖新视图。
既有 PodcastScope::Liked 全量快照、点赞写入前状态检查与写后回读、节目菜单/下载/队列

分页节目播放（原生）
- 使用普通原生播放准备票据，动作 podcast_liked_page_episode 接收活动 visit、
  revision、voiceId 和可选 double_click。仅右键/更多中的单项播放默认不传
  double_click；插入选中项，当前节目已播不切换、暂停则继续（M308:1671–1685）。
  行双击对当前节目只切换暂停；其他节目按 replaceQueue 选择插入单项或以当前
  已载入前缀替换并选中原行（M3085:243–253,309–311,382–411,531–546）。
  替换普通节目切换顺序模式，保留 anime/electric/cover 例外（M3085:478–485）。
- 只为缺少主音频的选中节目补 /api/dj/program/detail {id}，不扫未载入页、
  不读完整点赞快照、不为相邻行补详情。下架、灰态及缺已知主音频的其他行不进队；
  队列按原生上限保留首 10000 个有效条目，超过且所选未能入队时保持原队列。

- 新建 visit、离开、恢复签发新 revision、换号、原生播客缓存失效或凭据变化会

  队列代次校验。已提交的播放继续由播放器维护，离开列表不终止它。

分页节目下载准入
主窗口 download_liked_page_voice_prepare(epoch,{visit,revision,voiceId}) 拒绝
列表之外的节目、退场后的 revision、其他账号、下架或灰态。不需要完整喜欢快照。
单集仍按 M3085/M334 的既有下载音质流程：先 /api/dj/voices/download/check，
再 /api/dj/program/song/musics，始终使用节目 ID。两个读取后都重新校验活动视图，
仅生成一次性音质选择回执；确认继续用现有 confirm_voice，不能替换 ID 或输出格式。
确认读取同一节目详情；下架、灰态或与列表已知主音频 ID 冲突时不建任务。
网络读取不持锁。提交在下载目录/任务锁内，先取账号锁，再持有点赞列表原生锁到
SQLite 事务提交；事务从同一连接核对当前播客失效代次，不从部分列表推导完整成员。
离开、恢复产生新 revision 或更换账号时，迟到确认不可入队；入队成功后仍由原生
下载工作器按节目权限和实际主音频 ID 授权、传输和校验。此批不改对话框或入口 UI。
