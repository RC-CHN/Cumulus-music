随心听 FM：封面取色与原生来源边界
================================

官方 PC 3.1.42.205594 恢复证据优先；本功能没有参考 YesPlayMusic。
覆盖播客经典首页与独立随心听 FM 卡片，不等于所有页面的封面取色或完整节目详情已对齐。

官方来源
- SceneFm.tsx:234,291–303 调 useImageColor，并从 dominant RGB 构造渐变。
- M2060:48–86 初始所有通道为 -1，URL 改变时请求；同组件等待新颜色时保留旧颜色，
  空 URL 不发请求。卸载后不更新 state。
- M54:196–260 先尝试 NOS 响应头 X-Nos-Meta-N-M-Cl：M/T/B 分别对应整体、顶部、底部，
  去掉分号后的附加值；V 和未知键不参与颜色。缺头、空头、实际解析抛错或 fetch 错误才
  转图片。只有 T/B/V 或未知键也会得到 truthy 对象，不再请求图片；不存在整体色就用底色。
  这不是“没有 M 就采样”。非标准十六进制的 JS parseInt/NaN 与短值语义有冻结向量。
- 图片回退为 M54→M279→M258。原浏览器解码后，canvas 宽为 min(naturalWidth,50)，
  高按原纵横比向上取整，保留默认平滑缩放；从 RGBA 取五位 RGB，再按颜色盒量化。
  最多 16 色，按人口和盒体积分裂，保留原版黑/白过滤及缓冲索引行为，不改成平均色。
- 仅 dominant.r>0 才生成渐变。RGB→HSV；饱和度>0.04 时置0.6，明度置0.7。
  245deg：原色0%、色相-10度的颜色48%、原色100%。纯绿/纯蓝 r=0 也回退底色。
- M3:609 的底色是 var(--colorBlack8)。官方 M691 music_pc 0.0.14 的 token 表
  :517–533 明确 light/color_red/color_custom=rgba(40,50,72,0.3)，
  dark/transparentglass=rgba(255,255,255,0.3)。因此移除旧的固定紫色渐变。
  M691 SHA256：d88d915163a1920fb24781fa6be31d445fb1d2a95bb5367387eb856b1834f318。

实现与分层
- core/src/podcast/scene/palette/ 是纯 Rust 响应头、量化、HSV、渐变领域模块。
  ThemeFallback 和 Gradient{first,middle} 是有界类型；通道 null 保留 JS NaN。
  冻结的合成向量来自直接运行未改动的恢复工厂，不把另一份手写算法当对照。
- core/src/client/scene_fm/palette{.rs,/artwork.rs} 从本账号原生场景快照取得当前单集封面，
  前端不能选择 URL；请求由独立、无业务 Cookie 的 MediaBackend 执行。请求不重定向、
  不携账号授权/刷新令牌，也不使用授权音源。普通下载默认头保留行为不变，只有取色
  传输显式启用 content-type 和颜色元数据头；不返回 Set-Cookie。
- 元数据：GET <原生封面>?xnos=1&imageView=&thumbnail=round(300*DPR)yround(300*DPR)。
  命中则不在应用层消费图片 body。需要图片时另取
  ?imageView=&thumbnail=<同尺寸>&type=webp&rotate=0&tostatic=0。
  不把网络响应整包、任意 HTTP 头或原始地址传给页面。
- frontend/services/sceneFmCanvas.ts 只接收原生给的本地图片字节，用 Blob/Image/canvas
  按官方尺寸取样；不调用远端图片 URL。量化与 HSV 仍交 Rust。不能声称 Rust 图片缩放
  等同浏览器，本实现没有用 image::thumbnail 代替 canvas。Tauri CSP 只为 img-src 增加
  blob:，没有放宽 connect-src 或脚本来源。
- 请求等待期间保留同账号的旧背景；切账号和销毁清空。同账号同一规范封面URL换节目，
  保留已完成或在途的同一颜色读取/本地采样，不按节目ID取消；URL改变才退休旧取色。
  暂停等视图版本变化不重复取色，原生已有完成结果按账号与规范封面只缓存一项。
  图片取色和卡片展示均不构造音频队列、不更改播放、音量、效果或远端账号资源。
- 同账号且同一封面 URL 的已完成颜色，在节目 ID 改变时直接保留；包含正式返回的主题
  底色、原生媒体限额拒绝、普通网络/图片失败及本地解码失败后的官方默认色，不重复读取。
  普通失败与正在读取的同URL都保持这一次尝试；原生 stale/profile_changed/session_expired
  或错误账号回包不使尝试完成，新权威视图仍可发起请求。不同账号/URL、取消、销毁后的
  旧工作不能更新当前卡片。以下在途身份拆分已进入phase57；分层验收与未完成项见末节。

类型化 IPC（仅主窗口）
1. scene_fm_palette_read {epoch,revision,voiceId,pixelRatio}：
   AccountData<Ready{background}|Sample{receipt,mimeType,bytes,width,height}>。
   revision 必须规范、不能在未来；可接受同一当前单集的较旧观察版本，避免目录读取到自动
   播放提交间的版本变化使取色永久失效。新请求实际来源始终从当前原生快照取得，
   旧单集准入仍拒绝；准入后只处理封面，当前换成同URL的另一节目不使该图片变为旧来源。
2. scene_fm_palette_sample {epoch,receipt,width,height,rgba}：
   AccountData<{background}>。一次性 receipt 绑定账号代次、请求sequence和规范封面，接受的
   canvas 尺寸必须等于该原生图片的官方采样尺寸。完成后消费凭据并缓存结果。
3. scene_fm_palette_cancel {epoch,receipt}：
   只取消相符的本机待取样；迟到取消不能撤销新来源。图片请求会在来源 supersede、
   账号变更、10 秒总期限到达时结束。没有前端可安装传输或提供媒体地址的命令。
   RGBA 的有界反序列化最多65536字节；这限制工作数组，不代替 Tauri 的消息解析。

实际限额与边界
- 公共封面只接受现有原生 artwork 规范化后的 pNN.music.126.net，剔除广告素材和非法地址；
  不支持的来源回退主题，不扩大到任意域。DPR 接受0.5…4。
- 编码图片最多3MiB，PNG/JPEG/GIF/BMP/WebP 的 MIME/文件格式和尺寸互相核对，
  单边4096、总像素1200万、最终取样16384像素。JPEG EXIF 转向纳入原生尺寸；
  WebP 的 RIFF 尺寸有界检查，不在原生重编码或重新采样。若 WebView 实际自然尺寸不同，
  回退主题，不收任意几何数据。未验证所有动态图片、WebP EXIF 或各系统色彩管理。
- 颜色响应头最多4096字节；超限保留“已返回元数据”的分支并回退主题，不继续下载。
- 同账号同单集封面可能仍有服务权限和网络失败；不把本机合成测试当实服取色成功。
  Linux WebKitGTK 和 Windows WebView2 的解码、缩放和色彩管理可能有平台差别，不能把
  供给原 quantizer 的冻结 RGBA 向量称为跨浏览器像素一致证明。

同URL在途生命周期：phase57实现与分层验收
- scene_palette_source 与 scene_palette_check 的原始当前节目/版本准入保持不变；
  scene_fm_palette_read 开始时仍要求传入voiceId是本账号原生快照的当前单集。
  不允许在已经切到602后，再用601发起新读取，即使二者封面URL相同。
- 准入后拆为 ArtworkSource{SessionToken,规范cover}。header、image的完成及采样结果
  再从当前原生SceneFM选中项核对规范cover；只允许同账号同URL跨单集继续原在途工作。
  这不是把当前节目、主歌曲或播放权限改按封面判断。scene_fm/actions的播放fence与
  SourceResolver的节目到主歌曲校验没有改动，前端也没有新增可传任意URL的IPC。
- Pending保留原image宽高、唯一receipt和sequence。新读取递增sequence并撤销旧待取样；
  A→B→A时，即使原A的URL重新成为当前封面，旧A的promise/receipt也不能重新有效。
  旧receipt的精确取消不能撤销新任务；尺寸、RGBA反序列化和图片/域名限额保持原样。
- useSceneFmPalette以账号与coverKey管理generation。601→602但coverKey相同，保留
  原header/image promise、Blob/canvas与receipt，不新发取色；账号或URL变化、销毁
  仍退休旧generation。原生stale/身份失败仍允许新权威视图恢复，不当成已确认默认色。
- 取色使用独立、无Cookie的公共媒体transport，不读取业务Api或credential revision。
  同账号、同一原生规范URL不变时，仅Cookie/API对象更换不改变这张公开图片的来源；
  不为此新增PC实验或账号权限门槛。若账号generation或当前原生封面改变，仍拒绝旧结果。
  业务API自己的凭据版本、账号与音源身份校验继续独立执行，图片不获取或替代它们。
- 新增原生/Node用例覆盖header待回、image待回、canvas/采样待回、旧voice新准入、
