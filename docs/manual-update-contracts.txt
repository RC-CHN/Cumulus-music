设置／关于：手动检查 Cumulus 更新
=================================

官方交互依据（网易云音乐 PC 3.1.42.205594）

- hybrid_64/3097.js:5603–5672 的“关于网易云音乐”显示当前版本；商店版不显示
  “检查更新”，普通客户端显式点击才发 async:update/checkUpdate
  {action:"manual",isSilence:false}。本功能采用相同的关于入口和手动反馈节奏。
- async_update.txt → hybrid_119/3131.js:396–809：原生读取 core 版本，区分新包、
  无新版、静默与手动分支；无新版时弹出“检查更新／知道了”，手动确认新包后
  可进入下载窗口。原生 Update.startUpgrade（同模块 :356–395）有整包、增量、
  MD5、跟踪头、安装状态等官方专用协议。Cumulus 不访问网易更新接口，不做原生
  下载/安装、后台检查、强制更新、增量补丁或遥测。当前没有商店更新渠道。

公开发布读取

- 原生一次 HTTPS GET
  https://api.github.com/repos/RC-CHN/Cumulus-music/releases/latest
  Accept: application/vnd.github+json；X-GitHub-Api-Version: 2026-03-10；
  固定非身份 User-Agent；8 秒总超时，512 KiB 最大回包。无账号、Cookie、令牌、
  代理凭据、重定向、自动重试或直接附件读取。网络只在用户打开检查或显式重试时
  访问 GitHub。依据：
  https://docs.github.com/en/rest/releases/releases#get-the-latest-release
  https://docs.github.com/en/rest/about-the-rest-api/api-versions
  https://docs.github.com/en/rest/using-the-rest-api/rate-limits-for-the-rest-api
- GitHub latest 接口提供该仓库公开非草稿、非预发布的最新发行记录；仍独立核对
  draft/prerelease、published_at、严格 vX.Y.Z 与固定仓库的 HTML 发布页形状，
  并确认当前发布流水线预期的 8 个附件记录各有唯一名称、uploaded 状态、正大小和
  SHA256 摘要格式：Linux .deb/.tar.gz、Windows .zip/-setup.exe、两平台 manifest、
  SHA256SUMS、release-provenance.json。使用编译内置当前版本按数字比较；
  同版或较旧不生成打开凭据。404 只表示本次未返回可检查的发行；限流、网络故障、
  无效数据明确区分，未核验的结果不冒充最新版。
- CD 在实际发布前执行 AGENTS.md 的唯一空发布提交、标签、精确 SHA 完整 CI gate
  和产物来源/摘要核对（release.yml、scripts/ci/publish.py）。客户端只核对
  GitHub 公布的元数据及预期附件清单，不重新验证 CI、不读取证明或下载/比对文件、
  不验证包的签名或真伪。不能据此宣称本机安装包已验证。升级选择、下载和安装
  由用户在发布页独立处理；没有任何写 GitHub 或安装的 IPC。
- check_for_updates 和 open_update_release_page 无渲染层参数、仅主窗口可调用。
  只有当前检查得到更高的有效稳定版本才允许打开；固定
  https://github.com/RC-CHN/Cumulus-music/releases/tag/v{X.Y.Z} 由 Rust 构造，
  不使用回包中的 URL 或正文。成功后消费本次打开凭据，系统浏览器失败可重试。
  Linux 使用现有 xdg-open；Windows 使用现有 ShellExecuteW 原生适配器。关闭弹窗
  复位焦点，迟到的只读结果不会弹回窗口；已开始的读取可在超时前完成。

验证

- Rust 合成用例检查数字版本、相同/较旧、无发布、网络/限流、伪造仓库、
  草稿/预发布、无效或重复附件、只投影公开版本。
- manual_update_ui_probe 在未登录的真实 Linux WebView 中注入封闭的更新响应，
  通过隔离 xdg-open 记录实际原生浏览器调用参数。覆盖无自动请求、当前最新版、
  网络失败和重试、新版、首次浏览器失败后重试、无发布、不完整发布、关闭等待
  和返回焦点；无真实查询、浏览器访问、更新下载或安装。
- 构建：cargo build -p cumulus-desktop --features custom-protocol
  --example manual_update_ui_probe --locked。运行：
  python3 scripts/ci/manual_update_smoke.py --binary <probe> --root <new-dir>
  （真实 Linux GTK 可加 --screenshots）。Windows 使用同一原生浏览器封装；
  此处不将 Linux WebView 证据当作 Windows 现场验证。
