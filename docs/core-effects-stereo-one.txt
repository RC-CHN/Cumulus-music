==============================================

Scope
-----
StereoAmbienceOneStage executes the complete fixed-bank1 SE parent, including
M/S transform, two sidechain EQs, two dynamics, two main EQs, the real bank1
environment child, stereo reconstruction, tail propagation and native-shaped
bypass. It loads no original DLL, opaque parameter table or Python process.
It is not the full GEQ/BT/RVB/limiter/material graph, arbitrary ambience bank,
player renderer, sound-device or official UI activation. completeGraph=false
on the CLI deliberately refers to that larger material graph.

Exact parent sequence
---------------------
B28E0:2944–299b applies f32(presence*.6) as a difference from the last applied
increment to M-main-EQ slot1; bank1 leaves that slot disabled. Presence must
not silently enable the slot. M=L+R, S=L-R, with no .707 normalization.
S ramps from prior parent side gain (initially0) to powf(10,stereoizer*.05).
When sshaper is true, copies of M/S run through their sidechain EQs and then
act as external detector inputs to each original mono dynamics. Both main
EQs run afterwards. Shaper-off retains its caches/history for later use.

B28E0:2ceb–2d43 copies exactly the original valid S prefix into both planar
environment channels, forwards the caller's end state, and invokes B6EB0.
B28E0:2e00–2ff6 reconstructs only the original input prefix and adds the
corresponding environment output. The vector prefix computes the L half-
products separately; scalar tail sums then halves. R subtracts then halves.
B28E0:3012–304b copies ONLY environment output for any appended tail frames
and propagates the child valid-frame count and end state. It never pretends
those appended samples were input to the EQ/dynamics.

A80D0 changes bypass through a full-capacity dry/wet blend. Stable bypass
does not advance parent/child state or drain a pending environment tail; its
frames/EOF simply pass through. Re-enabling invokes all-child reset before
the next wet block. Explicit reset and re-enable preserve parent side gain,
applied presence, child prior gains, ring cursors and active EOF budget.
The outer plugin enables FTZ only while processing and restores the caller's
FTZ bit, unlike the standalone environment child that inherits caller mode.

Zero-valid-frame finding and compatibility
-----------------------------------------
The first private composition incorrectly treated all shaper work at n=0 as
a no-op. Original 8kHz/cap64 block4 exposed an actual detector mismatch:
M band0 power original1.30592671e-5 vs candidate1.12955458e-5. This was not a
rounding tolerance issue and was not fixed by changing the assertion.

C0650:0750–08fd reads the first retained external band sample and enters a
sample do-while once even if the descriptor's valid count is0. C2B20 already
clears the full main allocation and keeps its internal band caches; zero-
length copy/crossover/gain operations do not refresh those samples. The fixed
bank1 gains remain stable. A dedicated internal SE1 path reproduces that one
detector update using the actual retained main/side band-cache first samples.
It returns zero audio frames when there is no environment tail; it does not
fabricate a one-frame input or route one invented sample through the graph.

Every cache and complete PCM block is initialized and owned even when valid
count is zero. The safe Rust API never passes an empty allocation, uninitialized
sample or out-of-bounds first pointer. Public raw MultibandDynamics zero-frame
settle remains unchanged (no detector advancement), as does SE0's rejection
of zero frames. The new behavior is isolated to SE1's proven original internal
dispatch, not a change to generic synchronization or all native DSP calls.

Ownership and failure boundary
------------------------------
C layout kind9 is queried, aligned and owned in Rust. The shared parent state,
complete band caches and environment-input storage are embedded in that one
allocation. Rust separately owns the stable bounded delay arena and disjoint
full-capacity dry buffer. There is no per-process allocation, callback, original
asset dependency or escaped pointer. Send permits transfer; !Sync and &mut
prevent concurrent mutation. Stereo, integer8000..384000Hz and capacities
4..4096 divisible by4 are checked before allocation.

Public controls reject nonfinite/out-of-range tuples before mutation. PCM
must match the full initialized Format and be finite, including padding.
Wrong count/format/NaN rejection is atomic. The private C entry rejects full
and partial dry/output overlap; Rust borrows guarantee disjoint buffers.
Numerical failure restores the caller FTZ, silences the owned full output,
quarantines the stage, and requires reconstruction; reset/bypass cannot repair
a partially failed object. Only returned valid frames may be consumed.

Remaining product work
----------------------
Fixed-bank1 SE PCM is now a candidate, while arbitrary ambience banks, ER,
extra EQ, RVB and full GEQ/BT/SE/limiter material composition are separate.
The official slider write/apply/enable eligibility must be bound to its real
material route, not invented from this kernel. Linux/Windows host audio clock,
seek/reset, EOF, routing, rollback and real Windows math/output proof are still
