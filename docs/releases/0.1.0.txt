Cumulus Music 0.1.0

首个社区桌面版本，面向 Linux x86_64 和 Windows x86_64；这是仍有已知边界的早期版本。
Rust core 独立于 Tauri，Vue 界面通过类型化 IPC 调用业务逻辑。

已接入的主要能力
- 账号登录/已有会话恢复、账号隔离、二维码与挑战入口、失效提示、续期状态管理。
- 搜索、推荐、排行榜、FM、歌单/专辑/歌手、账号收藏、歌单管理。
- libmpv 实际播放、队列、歌词、音质/会员权益处理、播客及 MV。
- 下载与断点恢复、完成文件管理、本地库/CUE/NCM、云盘和上传恢复。
- 评论、同账号接续、已恢复的一起听控制、音效参数与本地 DSP。

安装
- Linux：优先安装 .deb（Ubuntu 24.04 或兼容发行版），由包管理器安装 WebKitGTK 4.1 和 libmpv2 等依赖。
  tar.gz 是同一构建的文件包，需要系统先安装 libmpv2、WebKitGTK 4.1 等依赖；不是无依赖 AppImage。
- Windows：x64 NSIS 安装包或 zip；包含 libmpv 及其动态依赖，需要 Microsoft Edge WebView2。
  未配置代码签名证书，系统可能显示未知发布者。
- 不发布 macOS 包。

已知边界
- 服务端挑战、风控和会员授权仍由网易云服务决定，不能保证所有账号/网络均能登录或写入成功。
- 当前研究账号未持有 refresh token；续期逻辑有对照及故障恢复测试，真实 token 轮换没有完成验证。
- JSK 新登录的完整迁移、部分验证/设备管理分支仍在推进；不能将已有会话恢复理解为全部登录分支完成。
- 本机硬件身份采集目前仅 Linux 实现；Windows 默认请求上下文可以使用，local/windows-local 采集模式暂不支持。
- 一起听实时双账号验证未完成，专有 IM SDK 不随发行包提供；不要据单账号测试推断全部同步功能通过。
- 原生音效播放依赖 libmpv/FFmpeg 的 LADSPA 能力；没有此能力的系统/Windows 依赖构建不能启用该音效链。
- CI 的合成音频/null 输出测试不代表所有声卡、显示驱动和真实账号已经实测。
- 详细映射和限制见 docs/ 及 README.txt；本次发布不代表完整迁移目标已完成。

发行包不含真实会话、网易云官方安装包、研究解包归档和商业音频样本。
SHA256SUMS 与对应 CI 提交/运行信息随版本发布。源码及项目许可见同一标签。
