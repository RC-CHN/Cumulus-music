Cumulus Music 0.2.0

支持 Linux x86_64 和 Windows x86_64。本版汇集 0.2.0 候选阶段及后续主线改进，
功能范围仍以各专项契约的已验证分支为准，不代表完整复刻官方客户端。

重点变化
- 登录与账号：补齐扫码、手机号和邮箱的已恢复流程，隔离候选凭据与现有账号；完善持久化、续期、过期提示和恢复。
- 播放与队列：完善歌曲、播客及本地媒体的队列操作、续播、来源跳转、自然结束与失败恢复。Windows 本地文件交接保留已核验的文件句柄；索引 WAV 接入原生音效。歌曲菜单增加倍速入口，已购下载使用当前曲目的有效权益。
- 音质与音效：设置页直接保存播放和下载默认音质，会员信息核验后同步两组可用档位；修改默认播放音质不切换正在播放的音源。音效面板提供共享的空间音效开关与当前效果标记。
- 搜索与发现：扩展歌曲、歌词和声音结果的展示、队列、评论、下载与公开链接分享；完善联想键盘/指针行为、离线提示和返回位置。首页标题可进入歌单广场并恢复分类。
- 播客与历史：完善节目详情的元数据、推荐与包含歌曲读取；支持节目曲目多选、菜单和封面播放。最近播放支持歌曲及节目播放、收藏、下载、评论、分享和本地文件定位。
- 下载与云盘：设置页内选择并确认下载目录、保存文件布局；完善批量收藏、取消确认、传输速率、暂停续传、文件定位及云盘筛选与返回。
- 桌面体验：完善迷你播放器、桌面歌词、字体设置和窗口焦点恢复。一起听退出后显示已确认的本次记录，修复重复共享读取与本机暂停重叠时的状态保护。
- 回归验证：修复播客封面被临时提示遮挡时的点击时序，以及暂停时钟、页面动画、菜单焦点等实窗检查竞态；保留真实命中、原生状态和全部发布门禁。

安装
- Linux：.deb 或 tar.gz；需要 WebKitGTK 4.1（>= 2.42）、libmpv2 和 FFmpeg 等系统依赖。
- Windows：x64 NSIS 安装包或便携 zip；需要 Microsoft Edge WebView2。安装包未配置签名证书。
- 使用 SHA256SUMS 核对附件。release-provenance.json 记录精确提交和 CI 运行；两平台产物来自同一次完整 CI，发布阶段不重新构建。

已知边界
- 账号、会员权限、版权和风控由上游服务决定；合成回归不保证所有账号、音源或写接口可用。
- 微信、QQ 授权成功回调与凭据隔离仍待完整验证，客户端不开放登录入口。网易客服、意见反馈与日志上传、通用远程页面桥及官方更新下载/安装不移植；保留 Cumulus 本地诊断和自身正式版本查询。
- 一起听的第二账号同步和语音仍待验证，专有 IM SDK 不随包分发。部分专有音效仍未覆盖。
- 合成音频与 null 输出只能验证相应解码和控制行为，不代表实体声卡听感；虚拟 runner 的 WebView 结果不代表实机刷新率。
- 不支持 macOS。本版不包含真实账号数据、下载音乐、官方安装包或研究归档。
