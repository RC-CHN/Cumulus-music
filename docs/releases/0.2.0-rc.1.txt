Cumulus Music 0.2.0 RC 1

这是阶段候选版，供 Linux x86_64 和 Windows x86_64 用户试用。0.1.0 仍是最新正式版。

重点变化
- 登录与账号：补齐扫码、手机号及邮箱的已恢复分支；隔离登录候选和现有账号，处理凭据持久化、续期、过期提示与恢复。取消普通扫码后，仅回收本次隔离候选的凭据，不碰已保存账号。
- 播放：补齐队列、偏好、选曲及恢复；专辑双击遵守保留或替换队列设置。修复多种音源、播放失败恢复和 Windows 回到前台后的队列提示。均衡器可用「重置增强音效」恢复旁路前保存的曲线。Linux 兼容的本地 FLAC 增量播放路径接受最大块 4608 帧。
- 搜索与音乐库：扩展搜索表现、歌单/专辑/艺人和账号资源；修复授权表现迟到时脚注不显示。本地库可定位文件夹、从列表移除分组并重新扫描恢复，源文件不受影响。满足上游策略时，主窗前台可展示启动后的每日推荐和版权回归提醒。版权回归可打开已有歌单，或直接播放回归歌曲。
- 下载与云盘：下载行可收藏到已核验的歌单，回包不明时提供只读核对；已下载声音按节目打开评论。云盘显示已验证的容量提示；新选的普通音频超过 100 MiB 会被过滤，已有任务仍可按原流程继续。
- 播客和设备：补齐播客续播、订阅角标、设置及系统集成。普通电台节目支持行菜单，提供播放、下载、评论及公开链接分享。修复随心听 FM 快速切集后卡片仍显示上一集或误提示选择未完成的问题。Cumulus 自己的版本查询仍只检查正式发布。

安装
- Linux：使用 .deb 或 tar.gz；需要 WebKitGTK 4.1（>= 2.42）、libmpv2 和 FFmpeg 等系统依赖。
- Windows：使用 x64 NSIS 安装包或 zip，需要 Microsoft Edge WebView2；安装包未配置签名证书。
- 可用 SHA256SUMS 校验安装文件。Windows 和 Linux 产物来自同一完整 CI 的各平台构建。

已知边界
- 微信、QQ 登录仍在研究：已对照官方换票请求，真实授权成功回调未验证，客户端没有登录入口。网易客服与官方更新器不在产品范围内。
- 账号、会员权限及风控由上游决定；不会据合成测试承诺真实凭据轮换或所有账号均可播放、写入。
- 一起听的第二账号同步和语音仍待验证；专有 IM SDK 不随包分发。部分专有音效仍未覆盖。本地 FLAC 路径的合成 PCM 验证不能代表所有声卡或其他音源。
- 详见 docs/desktop-feature-matrix.md 及各专项契约。本候选不包含真实账号数据、官方安装包或研究归档。
