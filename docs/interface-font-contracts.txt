Cumulus
- 设置→常规的字体下拉框使用本机目录，打开设置时按当前代次读取，关闭或切号后不接收
  上次返回的目录。默认始终可用。选中后直接写入安装级 SQLite 偏好，成功后立即应用；
  成功反馈“设置已更新”，失败保留原值。没有音乐服务请求、账号写入、原生播放控制或重建页面。
- Rust 复用既有 GTK/Pango 和 DirectWrite 枚举，仅返回名称；本地化家族优先使用
  目录主名称中合格者，否则使用首个合格别名；不发送字体文件、路径或字体字节。
  类型化主窗口 IPC 读取、保存选择，Rust 计算尺寸，不接受任意 CSS 或字号。正常目录
  使用一个下拉菜单；超出 128 项时提供分页，当前保存的字体仍可见。无此字体时仍保留
  名称，用字体栈回退；用户可选默认。Linux 另加本机 CJK / 系统字体回退。
- 新进程在主界面读取保存值，桌面歌词/迷你窗口保留自身规则，播放详情中已有独立
  歌词字号仍由其组件控制。不复用官方专有 player.setFont 原生字形渲染，也不导入网易
  旧版配置；无法从此证明像素、系统字体安装行为或 Windows 实机效果。
