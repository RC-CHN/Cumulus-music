当前页面与状态
- CloudPage保留Cumulus页标题，采用官方两页签文案、容量区位置、默认64px行及
  工具栏尺寸。格式/日期/大小沿用原Rust来源；标题/歌手/专辑长文本省略可读全名。
- 表头排序保留已对照的五/三态，重置页码及选中；歌手正文不再伪装成排序按钮，
  排序仅由明确表头触发。恢复目录未含UploadedTrackTitleCell实现，不能声称其
  作者跳转已按官方复刻。本批不新增猜测的歌手/专辑ID。
- useCloud保留请求query与成功返回query的关联。只有关键词、类型、顺序、页码、
  大小全部相同，page才暴露当前列表；不把旧行配上新条件执行播放/下载/删除。
  新查询失败展示明确重试页；同查询远端失败可继续显示缓存，并保留远端错误。
- 容量是当前账号最近已知元数据，不随分页/筛选被当成空容量。没有有效快照时
  不显示伪造零计数或空库；搜索未提交的输入不改变已应用的空结果文案。
- 新账号重置关键词、类型、顺序和页码，关闭上传/删除弹窗并清除选择；同账号
  重连保留搜索条件。迟到读取/写入/文件选择不进入替代账号。页签有方向/Home/End
  键与单一Tab入口，搜索有实际提交及清空按钮。

删除结果与焦点
- CloudDeleteTarget捕获epoch、revision、所选ID和名称。确认明确只移除云盘资源，
  不删除本地文件。列表revision已变化则要求回列表重选，不自动套用新快照提交。
- core CloudDeleteView增加原记录的ids；useCloudDelete按真实目标识别已有未决
  操作，不凭总数或最近一条记录猜测归属。持久化/互斥/先保存后发送/重叠未决阻断
  继续由CloudLibrary执行，UI没有另造删除实现。
- 只有confirmed关闭；rejected/partial保留实际结果供查看。uncertain显示只读
  核对入口，重开同一目标也接续未决操作。IPC回执丢失先读本地记录；没有记录
  不能断言未执行，因此当前表单继续禁止重发。核对只用reconcile_delete，不重POST。
- 两弹窗统一ModalTransition和账号焦点边界；退出动画完成后才恢复入口，账号变化
  不回旧焦点。正文滚动、标题和页脚固定，发送/核对中聚焦稳定容器并禁用重复动作。
  上传附件/文件选择保持原正式用例，本批没有改上传协议或用前端模拟上传。

- core/src/client/cloud/{dto,view,commands}.rs及cloud/library/*：原列表/完整筛选播放/
  删除日志；frontend useCloud/useCloudDelete、CloudPage、Cloud*Dialog；云盘样式独立。
- 列表POST /api/v1/cloud/get，offset/limit=200；完整拉取后在本地快照筛选分页。

  1000分批、记录每批状态，再只读重新取完整列表确认。未知不会由刷新重发。

  不使用simpleSong.id替换。上传、附件、OSS/NOS与其他下载详见desktop-cloud-contracts.txt。
