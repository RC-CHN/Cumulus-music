Paced stereo PCM native CI boundary
===================================

The sealed --stereo-pcm-flac-library native_audio_probe path is run after actual
GTK/WebView or WebView2 initialization. The current V2 report requires the
complete fixed local equalizer scope (LocalFixedStereoMaterial), not the former
SE1 -> defaultB0 subgraph. It retains real synthetic NCM publication, cold held-
file authorization, libFLAC1.5.0 decode, unknown-size raw PCM, same-entry controls,
stop/join/seek, exact tail frames and buffered revocation. The validator rejects
old V1 reports and arbitrary SDK/normal-setting/UI/physical-output claims.
The complete fixed scope still requires GEQ/BT/RVB off and the documented SE1
controls; it is not arbitrary SDK material support. This native-only source seam
does not install a normal production setting or replace shipping artifacts.
The existing60s outer process limit and8s individual native waits are retained;
no source-specific timeout extension is used to mask startup failures.

Linux
-----
Ubuntu 24.04's distribution libFLAC is not accepted as a substitute for the exact
1.5.0 decoder contract. scripts/ci/linux_flac150.py downloads the official source:
https://downloads.xiph.org/releases/flac/flac-1.5.0.tar.xz
SHA256 f2c1c76592a82ffff8413ba3c4a1299b6c7ab06c734dee03fd88630485c2b920
Official checksum publication: https://www.xiph.org/downloads/

A new task-private directory receives a bounded HTTPS archive, hash verification,
regular-file-only bounded extraction and CMake shared FLAC target build. Ogg,
programs, tests, C++ library, examples and docs are disabled. No cmake install,
sudo, global library replacement or package-stage write occurs. The explicit
private library is ELF x86_64 and FLAC__VERSION_STRING must equal 1.5.0; the report
records its exact path/SHA, source SHA, options and CMake version. The existing
Linux WebView job builds the same native_audio_probe once, then runs the new
flow in en_US.UTF-8 through Xvfb/dbus. Actual GUI initialization must still set
only numeric locale to C; the proof retains its existing message-locale check.
Only report.json and build.log enter the diagnostic closed set, not source,
archives, binaries or CMake cache. --build-dir deliberately is not --root, so
the automatic UI-proof root archiver does not collect this build directory.

Windows
-------
windows_cold_flac.py retains its pinned MSYS2 libFLAC archive/DLL hashes and
verified package media imports. The new ignored native stereo case joins the
explicit test case list. Optional --native-audio-probe runs the same compiled
GUI example before the temporary runtime is destroyed. It passes explicit
absolute libFLAC and libmpv paths, while the core test subprocess PATH remains
restricted to System32/Windows. A proof-only native helper uses MpvConfig.library
for that exact libmpv and resolves its live mpv_client_api_version symbol back to
the actual loaded module with GetModuleHandleExW/GetModuleFileNameW. It checks
canonical file identity and emits a receipt. Python verifies samefile again and
rechecks every staged DLL hash after the GUI process ends. PATH prepending alone
is insufficient: the production Windows loader intentionally ignores ambient
PATH/CWD for SDK/import selection. This helper is not a frontend/product option.
The temporary runtime is non-shipping and no downloaded library is repackaged.

Linux packaging candidate (separate from the shipping path)
-----------------------------------------------------------
scripts/ci/linux_flac150_package.py is a build-time helper, independent from
the unchanged linux_flac150.py proof CLI. It returns one verified runtime
and writes a stage report; package.py, Tauri startup, CI artifact selection
and ordinary playback do not call it yet. It does not build a Debian/tar
package or install libraries. It accepts only the same locked Xiph archive,
whether fetched through the existing bounded helper or supplied via
--locked-archive from a prior verified download. The old proof output can
remain beside this new stage and is not suitable for shipping by renaming.

Only the extracted FLAC CMake target receives two link changes: OUTPUT_NAME
cumulus_flac150 (real SONAME libcumulus_flac150.so.14), and -Bsymbolic to bind
both functions and data inside the library. Linux x86-64 generic C flags
preserve the target baseline; upstream's CPU dispatch is unchanged.
Before dynamic loading, the candidate must be a bounded regular ELF64
x86_64 shared object, with the exact private SONAME, only libc.so.6 and
libm.so.6 DT_NEEDED, symbolic binding, no ELF search-path/audit/filter/text
relocation tags, no named FLAC__ dynamic relocations/imports, and all nine
public Rust decoder symbols plus the version object. The maximum required
glibc symbol version cannot exceed 2.39 (Ubuntu 24.04 baseline). The full
source COPYING.Xiph is checked and copied into
runtime/third-party/licenses/flac-1.5.0/. The source archive hash, exact
artifact SHA/size, options/patch hash, ELF details, and license SHA are
recorded in report.json. A locally generated ELF digest is evidence for
that build only; it is not a universal 1.5.0 signature.

Reproduce with:
  python3 scripts/ci/linux_flac150_package.py --build-dir NEW_DIRECTORY \
    --locked-archive VERIFIED_FLAC_1_5_0_ARCHIVE \
    --ambient-library ABSOLUTE_TRUSTED_SYSTEM_LIBFLAC
The two optional inputs are for the build operator only. The script uses a
fresh child with ambient LD_* settings removed. It verifies dladdr file
identity for the version object and nine live decoder symbols, requires
version 1.5.0, allocates/deletes a decoder, and audits actual glibc binding
trace with receipt sentinels. If supplied, the distinct trusted system
library is already global when the candidate loads. A correctly resolved
entrypoint alone does not prove isolation: on the reference machine the
original proof ELF passed entrypoint and allocation checks but had 155
internal FLAC__ bindings to the ambient system library. The CMake candidate
had none under the same preload, with the exact same helper's native probe.
Local evidence: .build/research/trusted-flac-packaging/
linux-package-candidate-r1/{report,ambient-comparison}.json. This is real ELF
build/loader evidence, not PCM, installed package, GTK, Windows or playback
activation. Bundling still needs same-run digest binding in the application,
package-layout verification, and actual packaged GUI/authorized-held-source
and stock-fallback tests.
