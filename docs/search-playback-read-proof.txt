固定只读搜索到播放桌面探针

  构建示例需要生产前端 dist 供 Tauri 生成上下文，但运行时替换为固定的本地
  静态页。启动真实 WebView 后只开放一个无参数、单次调用的 IPC，不注册
  正式应用的账号、续期、写操作和事件插件，也不接受外部脚本或关键词。
  这证明当前 Rust 搜索投影和原生播放接线，不能当成真实 Vue 搜索界面验收。

  npm --prefix frontend ci
  npm --prefix frontend run build
  cargo build --offline --locked -p cumulus-desktop --example search_playback_read --features custom-protocol

  Linux 合成验证（新目录不得已存在；保留系统 locale，桌面初始化后只设 LC_NUMERIC）：
  LC_ALL=en_US.UTF-8 xvfb-run -a python3 scripts/ci/search_playback_read_smoke.py \
    --binary .build/target/debug/examples/search_playback_read --root .build/NEW_SYNTHETIC_PROOF

  真实验证需要现有明确授权的 PC 会话副本；不操作原库，不接受有 SQLite sidecar
  或符号链接的目录/数据库文件。已关闭的一致性副本放在私有目录。
  LC_ALL=en_US.UTF-8 .build/target/debug/examples/search_playback_read \
    --live "$CLOSED_PC_PROFILE_COPY" "$NEW_PRIVATE_PROOF"

  live 启动会实际联网：账号身份、综合、单曲、歌曲详情、音源授权各最多一次，
  只播放固定公开搜索的首个可辨识单曲，标准音质，无自动换曲、重试或续期。
  原生播放器只接受官方音乐 CDN 的初始 HTTPS 地址；媒体网络不受 API 路径
  白名单覆盖，不能把探针视作网络沙盒。读取会在私有副本保存服务 Cookie 更新，
  不会修改提供的副本或账号资源。失败仅给出静态阶段名；不要自动重试。
  真实和合成均用 mpv null 输出检查同一曲目的时钟前进和停止，不代表声卡听感。
  report.json 仅含阶段、计数及布尔结果；credential-copy、local-state、
  WebView 目录和日志一律保留私有，不归档或提交。

  2026-11-03 授权账号只读观察（Linux WebView 初始化后）：综合 11 个区块，

  公开 CI 不启动真实模式。全目标编译可检查示例；合成驱动只接受二进制与
  输出目录、可选媒体运行库目录及固定的合成模式，不接受会话。Linux 和
  Windows 的原生 CI 各执行旧版对照组、v3 组和下载后本地播放。二进制也拒绝
  在设有 CI 环境变量时使用任何真实模式。

  普通 URL 入口，原生播放时钟推进并停止。没有实际账号资源写入，

  此探针用固定公开查询、独立 WebView、默认请求身份和 null 输出，
  不能替代正式页面、用户截图中每首歌或物理声音设备的复验。
  选择失败报告区分授权、API 网络、打开媒体和输出等固定阶段；
  不记录授权 URL 或原生错误原文，也不会自动重试。

  独立下载验收（不改变普通只读模式）：将 Python 合成命令加
  `--download`，或用二进制 `--synthetic-download NEW_ROOT`。探针只选
  同一个搜索结果；只有详情及权限都明确为免费、可下载时才发起一次
  standard 下载授权，拒绝试听、要求加密、异常格式、超出 32 MiB 或
  无大小及 MD5 的回执。下载与播放使用不同授权，不互相代替。
  原生下载任务通过生产调度器运行，校验回执、原始摘要、成品及
  SQLite 离线账本。完成后关闭探针的 API 和媒体传输入口，原生仅
  允许打开已核对目录里的本地文件；播放进度推进并停止。合成 Linux
  对照使用真实 WebView 和 libmpv/null，通过一次媒体读取，成品与
  夹具逐字节一致。报告见 .build/search-download-proof-current 指向的
  download/run/report.json。

  真实下载需要与普通只读验证分开的明确授权；入口为
  `--live-download CLOSED_PC_PROFILE_COPY NEW_ROOT`，CI 中拒绝使用。
  此模式尚未对真实服务执行。即使免费媒体可用，也只允许一次下载
  授权和一次匹配回执的 CDN 读取，不跟随下载重定向、不自动重试。
  关闭的是该探针允许的传输，不是系统断网；真实播放 URL 的范围
  仍按前述普通探针限制。临时目录含凭据副本及媒体，只能保留匿名
  报告；此独立窗口不替代正式 Vue 下载页面或真实账号完整往返。

  当前实验分流的独立只读模式
  ------------------------
  普通 --live 和下载模式保持旧版搜索路径。需要另行核对真实实验分流时，
  使用 --live-search-experiment CLOSED_PC_PROFILE_COPY NEW_PRIVATE_ROOT。
  它只允许原账号、固定公开查询和一首已在单曲结果中的曲目。首次请求只读
  PH-PC-searchHot；收到 t1 后才允许一次页签读取和一次 v3 综合请求，
  否则只允许旧综合。有效实验响应中没有该条目也归为 control（使用旧分支），
  不声称账号已明确获得对照组。实验读取失败或响应不完整时拒绝继续，
  不自动退回旧接口；同一进程不会请求两个综合接口。

  合成 WebView 预验分别加 --search-experiment v3 与 --search-experiment control；
  每次使用全新运行目录。前者核对一次实验、页签和 v3 请求，后者核对一次实验
  与旧综合请求。两者都核对同曲目详情、standard 音源授权、原生进度和停止。
  新模式仍使用固定静态 WebView、默认请求身份和 libmpv/null，不替代正式 Vue
  页面、生产设备身份或物理输出。没有系统网络隔离保证；初始 CDN 限制不涵盖
  重定向。公开 CI 只用合成模式。真实模式与下载不可组合，本批未发真实请求。

  Linux 真实 WebView 合成回归：无外网路由，保留 en_US.UTF-8 系统 locale，
  四个独立进程的 v3、control、旧版、下载后本地播放均通过。新增两个实验分支
