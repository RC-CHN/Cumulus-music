实际桌面验证（Linux）
-------------------

desktop/examples/audiobook_skip_ui_probe.rs 和 scripts/ci/audiobook_skip_smoke.py
用真实 Tauri WebKitGTK、libmpv null 输出、独立配置目录和合成帐号验证了
18 个界面状态，并保存 18 张截图。220 秒样本从详情进入弹窗，编辑未保存
时本机值仍为关闭；保存手动 35/25 后，首集从 35 秒起播。底栏重新打开能
读回相同值，改为 65/25 时不会把当前集拖到新片头。在 197.4 秒暂停不触发
跳转或断点请求；恢复后由实际原生时钟触发跳尾，合成断点准确提交
节目 501 / 220000ms / 已听完，接着从 65 秒起播下一集。智能模式请求体
含节目 ID 字符串数组，复验第 501 集从服务返回的 45 秒起播。关闭后从头
起播；普通节目列表和底栏均未显示该入口。199 秒样本从头起播，播放越过
手动尾段边界时仍留在本集，未提交已听完断点。同库其他播单及另一合成
帐号的设置始终为空。

该验证在隔离网络运行，不向真实账号读写；原生数字 locale 为 C，消息和
字符 locale 仍为 en_US.UTF-8。Linux CI 持续运行该用例；Windows 可由
独立 runner 编译和运行工作区测试，本例当前没有 Windows GUI 验证。
