普通自建歌单：已读取快照与断网回读

官方恢复证据
- M/2997:247–372：服务详情是在线顺序来源；普通自建歌单从 M/239 的
  playlistTrackIds 找数值 v=-1，要求同 ID 的 dbTrack 记录仍在，然后按原位置
  插回（超出长度时放到末尾）。官方先补全/更新已有的曲目记录，服务 updateTime
  大于原缓存时覆盖完整 ID 顺序。M/2997:384–411 在离线或请求异常时从当前
  自建歌单元数据、原 ID 顺序和 dbTrack 投影。没有可据此恢复的音源授权。
- M/404:138–200 播放解析先用已经全量水合的页实体，否则读服务详情；失败或
  显式离线时按 playlistTrackIds 查 dbTrack。M/239:18–74 将 ID 顺序与 dbTrack
  分别存入原生数据库。M/163:278–331 本地文件、CUE 和已下载音源是独立可用性
  判断；缓存过元数据的在线曲目不自动取得离线播放资格。

Rust 对应
- 当前普通自建详情 playlist_page_at 根据完整 V6 顺序及本机叠加的双版次返回
  分页。内存只积累同已验证账号代次、同远端/本机版次、同总数、同服务更新时间且
  自 offset=0 连续成功的页；最多四份在途，不将不完整快照写盘。完整后在同账号
  SQLite 一次提交，按歌单 ID 隔离；保留原完整快照直到新的一份提交。若两份服务
  更新时间可比较，较旧的一份不能覆盖较新。最多 50,000 项，与混合播放相同；
  空的已确认歌单可缓存。不同于官方早于元数据水合写 ID 的分支，此处故意要求
  完整可重读的快照。个人喜欢列表、外部歌单、冷启动无验证账号不在此范围。
- 快照仅存安全投影后的歌单标题/描述、在线显示元数据、位置和本机引用；不保存
  服务原始包、图片/音源授权 URL、Cookie 或路径。本机条目保存索引摘要与修订，
  每次回读重新核对本机成员代次及当前索引，失效项不冒充可播放。没有本机记录的
  服务端 v=-1 项仍只显示占位；未授予离线权限的在线条目保留原名但不可播放。
- 只有 V6 或详情曲目请求的传输错误、明确网络预备失败、502/503/504 且没有非
  5xx 的业务代码，才可以读回快照。会话失效、明确拒绝、业务/协议错误不替代为
  缓存成功。V6 401/403/404/410 或明确不再属于此账号使此前快照失效；分页回读
  仍须匹配原双版次。成功的页面带 playlistOffline.cachedAtMs，不以此恢复账号。
- offline_playlist 播放只接受同账号快照的混合版次和已绑定本机行；当前索引租约
  持有至 actor 提交，保留文件/CUE 身份与原歌单相对顺序。双击按既有保留队列
  偏好及同曲播放/暂停处理，不获取线上音源、不写服务。另有 DownloadService /
  OfflineLibrary 的离线登记和权益流程；本入口尚未为快照中的目录 ID 接线，不能
  用元数据替代验证或从其他账号采用下载文件。退出账号后旧快照也不能用于播放。
- 已读取实体的跨路由复用、原生冷入口缓存、收藏列表以及官方 32/64 位二进制
  未见的缓存清理周期仍是独立边界；不可把本机合成回归当作真实账号验证。
- 自建歌单删除由在线列表回读确认时，在保存 Confirmed 日志的同一 SQLite
  事务删除快照并写账号/歌单删除标记。等待确认或请求失败不能提前作删除结论；
  已确认删除后迟到的详情不能重建离线快照。其他在线修改后，断网展示仍以最后
  一份完成读取的快照为准，本机成员代次变化则拒绝使用旧快照。

桌面状态与验证
- 歌单详情显示本机缓存提示和「重试联网读取」。缓存状态只保留查看、筛选、
  分页和原生验证可用的本地播放；编辑、下载、喜欢、评论、收藏者和拖放
  不使用这个来源。保持在同一份缓存内时才允许追加页；在请求间切换来源，
  要重新从第一页读取。恢复联网采用实时页；明确拒绝清除已显示的缓存。
- 「播放可用曲目」与行播放走 offline_playlist，并以组合版次、歌单 ID 和
  本机条目绑定；官方双击保留队列偏好仍由 Rust 处理。缓存页只读，不续期
  账号，不把在线元数据或本机路径交给服务。
