验收分层
S 来源核对：标出官方模块/原生地址、归档文件与差异。
L 本地通过：Rust 故障/状态/持久化/对照测试通过。
I 集成通过：实际 HTTP、引擎或文件管线通过，记录所用平台及条件。
R 服务通过：真实服务读取/隔离可逆写入通过，清理与回读完成。
单项可能仅达到 S/L；只有明确标注的 I/R 才表示真实流程通过。
历史 Python 202 项测试和旧线上证据只作来源，不混入 Rust 通过数。
