Cumulus 实现及边界
- 仅真实 Windows SMTC 宿主准备好时查询引导分组；已安装的 Linux MPRIS
  不等于 SMTC。WinRT 工作线程初始化成功后登记本机能力；未启动、设置
  损坏、读取失败、宿主报不可用时不消费 SMTC 提示。功能可用并不声称
  已向系统发布歌曲；设备开关关闭或播放器空闲仍可显示引导。
- 新 IPC system_media_guide_available(epoch) 仅供主窗口，核对原生账号代次
  和宿主能力，只返回一个布尔值。复用已有签名 PC 实验请求
  POST /api/rtrs/abt/front/expinfo/list、同一有界分组投影和账号代次缓存；
  SMTC 不依赖防休眠宿主。不读取时不开新网络连接，不传给前端实验字段、
  启动日志或遥测。原生失败不构造入口，离开页面后的旧响应不能记录提示。
- 同一 Vue 主窗调度严格先检查 SMTC，未显示才在首页开始第二个 3 秒等待。
  既有模态、登录和账号窗口优先；无产品对应的官方推广、广告、桌宠等引导
  不模拟。各自的单值已看过标记留在 WebView 安装资料目录，不含账号信息；
  已看过的提示不再查询自己的条件。两个提示共用启动级限额。
- CTA 聚焦真实「系统媒体控制」设置项，若已在设置则在当前页定位。Cumulus
  保持现有跨平台默认值和已有用户选择，不用这次分组改写 SMTC/MPRIS 策略或仿造官方
  旧组历史，不做自动开启。仅在设置页明确操作时才走原有本机 CAS 保存。
