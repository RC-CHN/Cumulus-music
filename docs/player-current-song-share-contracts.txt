Core 原生边界
-------------

- 仅由普通播放本来就有的精确 V3 歌曲 detail 和同 ID 的明确公共 privilege
  生成私有资格标记。记录一个布尔值表达数字专辑 bb 位；非负状态、同一
  目录 ID、来源及私人标记先在原始数据核对。不会把播放质量、展示 fee、
  旧公开复制链接、搜索行/历史/下载回执当成当前播放器分享权限。未带
  该标记的旧持久队列或其他来源不自动重查、不回退到通用链接。
- 只接受活跃的 full 普通公开目录歌曲；Rust 从原生快照查实际 playId、
  entryId、账号、当前音频焦点与选曲代次，并自行取得歌曲 ID。暂停保持
  资格，原生正常时钟不使同一个选择失效。FM、心动、房间、视频替代、
  私人云盘、本地、下载来源、CUE/试用和未知包装不进入。当前展示
  currentSongShareAvailable 只是这个快照的按钮资格，不是一张授权。
- player_song_share_prepare(epoch, {playId, entryId}) 只在明确动作后读取
  权限，返回 ready{receipt}、login_required、unavailable 或 album_required。
  一次性回执只绑定当前账户、原生实例、API、凭据版本、选曲及焦点；
  有效 180 秒，新的准备撤销之前的回执。
- player_song_share_choose(epoch, 同一目标, receipt, copy|wechat_qr)
  消费回执并重新核对。原生 EAPI 在请求排队后、交给 HTTP 前重新核对
  原账户、V3 detail 和权限端点的同一唯一 MUSIC_U 与精确凭据版本，
  并复验当前播放和回执；返回后仍核对。缺失、重复、错 ID、私人/替代
  资源、撤销、过期、切歌、换号或凭据轮换均不能发布旧结果。每次读取
  上限 5 秒，无自动重发。player_song_share_cancel 只取消原目标和回执。
- 核对通过后，Core 只返回不含跟踪参数的公开 /song?id=...，或用同一个
  URL 在本机生成 L 级纠错 QR 模块矩阵。Core 不写剪贴板、不生成外部
  页面导航、不发送任何内容。数字专辑拒绝只返回需要购买的语义；
  不付款、不启动现金台。当前无验证的匿名歌曲权限读取；仅当同一活跃
  歌曲满足本地资格时可返回登录意图，不用其他账号凭据、不自动注册。
  不据此声称游客完整流程、被排除的原版场景或任一真实账号已通过。

桌面与交互
----------

三个 player_song_share_* 命令只开放给 main。回执保存开始准备时的确切主窗
订阅；同账号、同播放和同队列条目的新订阅也不能使用旧回执。订阅失效会
阻止还未发送的查权，迟到的准备和选择不发布结果。复制由 Tauri 在 Core
末次核对实际播放和回执之后同步完成，只接收 Core 刚生成的 URL。
WebView 只收到 copied/copy_failed 或 QR
矩阵，不再通过通用复制 IPC 递交一个旧 URL。旧回执不能取消新窗口的分享。

底栏更多菜单只在原生资格为真时显示「分享」，保留原歌手、专辑及音效动作。
打开更多本身不核权；点击分享后显示短暂核对提示，确切的准备回执才打开
共用的「分享到」选择器。微信和复制是现有本地渠道；Esc、关闭及选择结果
归还同一原生播放的入口焦点。切歌、换号、收到无资格状态或组件退出会关闭
旧窗口且不恢复已过期的焦点。访客的可确认登录意图使用已有登录窗口；未确认
的歌曲权限、第三方发送、替代 MV 和购买继续不接入。

验证
----

- Core 单测检查原始资格投影和目标输入；client_player 的播放器合成回归
  走真正的播放选择、暂停及二次权限，验证回执取消、付费提示、错 ID、
  私有返回、账户/凭据/切歌和取消竞态。PC 传输用真实加密请求构造配合
  隔离后端验证请求体、权限排队失效和 Search / Player Cookie 作用域分离。
- desktop/tests/ipc.rs 加入三条注册命令的旧账号及非主窗边界；现有双平台
  player_layout_smoke.py 的普通模式追加六个 WebView 检查点，核对准确的
  只读权限请求、取消焦点、二次拒绝不改系统剪贴板、真实复制、本机 QR
  模块解码、换曲时撤销旧选择且不发布，以及原生 IPC 在同账号、同播放下
  替换订阅后只准新回执。其余分享操作不动原播放和队列。
  复用已有 ux_ui_probe 和 runner，不新增构建或外部账号流量。
