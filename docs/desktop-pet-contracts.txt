渲染材料与实际 Linux 能力
- 本地 orpheus.ntpk 的 1345 项清单含 10 张 pet PNG，均为引导、管理页、回退和
  抽奖等插图，没有宠物本体动作 WebM 或实例播放计划。native.ntpk 只有 start.html
  和 version.dat。M247/M58 中还有远端引导 PNG 和蛋的 Lottie，不能代替本体。
- M2125:418–508 按 detail 读 petId、petType、petName，要求非空 petActionList
  {action,webmUrl}、合法 petPlayPlan，以及可选 backgroundList/foregroundAssetList
  {assetType,action,url} 和 petCorpusUrl。三层映射为背景、本体、前景；计划含
  protocolVersion、按层 sequences/rules 和 defaults，输入事件为 resume/pause/
  long_pause/tap/heart/drag，切换策略为 hard/after_current/ignore，支持 clip、
  interval、repeat 和 loop。M2125:27–53 还要求 playing/paused 绑定及其引用
  素材；构造计划成功只是数据校验，不代表媒体已解码。
- M3093:1147–1158,1201–1211 把媒体交给官方 orpheus://cache 适配；M2026:553–593
  用 HTTP(S) 直读或请求字节生成 video/webm Blob，有界重试。M2026:203–215,
  1029–1104 使用 muted 内联视频，后台预载和共享 128 MiB 预算；
  alpha 不可用时 mountInternal 直接返回，不创建三层，没有静态桌宠回退。
- M2026:43–166 的两个内联 2×2 VP9/VP8 alpha WebM 是能力向量，不是桌宠素材。
  ffprobe 分别确认 568/577 字节及 alpha_mode=1；libvpx 参考解码的四个 alpha
  均为 128。GTK WebKit 2.52.6、en_US.UTF-8、Xvfb/X11、断网命名空间执行原
  I() 判定，默认与 ALWAYS 硬件策略均返回 VP9=false、VP8=false。附加诊断中
  两者 canPlayType="probably"，readyState=4、尺寸 2×2，但 Canvas alpha 都是
  [255,255,255,255]，说明能播图像却丢了透明度。实际 GStreamer registry 含
  vp8dec、vp9dec、matroskademux，缺 vp8alphadecodebin、vp9alphadecodebin、
  codecalphademux；安装/选择正确解码链尚未验证，不能外推为所有 Linux/WebKit。
  ALWAYS 只是请求的策略，不是 Xvfb 实机 GPU 加速证明。
- 私有复现证据 .build/desktop-pet-audit-evidence/：从恢复的 M2026:43–166
  提取两个 data URL 与 I()，在最小 WebKitGTK 宿主打开本地 HTML；alpha-probe-meta.json
  是 ffprobe/参考解码结果，webkit-alpha-{default,always,diagnostics}.json 和
  gstreamer-element-registry.json 是本机结果。此过程不使用账号或远端媒体。

可实施边界
- 下一步可只做 Rust 的 entry/check、my/pets、现有宠物 detail，保留入口/权益/
  生成状态及账号代次，先用合成冻结样本审计。不开领取、设置、上传或付费；不会
  在启动、登录或打开页面时创建宠物或修改自启。这个读面不算桌宠已可用。
- 显示桌宠前先取得一份用户许可的、已领养且可用的 detail 与真实运行材料，
  保持鉴权和完整 URL 在原生，子窗只收有边界的媒体标识和计划。用当前账号和
  窗口代次绑定输入、资源和就绪；未通过透明首帧不展示。生产不开玩具占位。
- Linux 先复核可分发的 alpha 解码链，或另证原生解码与合成能保持真实透明度、
  首帧、隐藏释放和帧率；Windows WebView2 另跑原始向量、透明窗口及输入穿透。
  现有桌面歌词 Tauri 窗只能复用透明窗/置顶等原语，整窗穿透不能替代活动区域。
  X11/XWayland 与原生 Wayland、Windows 高 DPI/多屏、全屏自动隐藏单独验收。
  未核对到真实宠物库存、服务权限、真实计划/素材或 Windows 运行结果，本契约
  不能把音乐桌宠记为已迁移。
