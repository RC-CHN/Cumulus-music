声音播放页「包含歌曲」：原生数据和普通歌曲选择
====================================

官方 PC 3.1.42.205594。该卡的数据来自节目曲目接口，与节目 detail 中可选的
songs 字段不同。不能拿嵌套的 songs、正在播放的主音轨或下载缓存代替。

官方来源与顺序
- hybrid_app M182:7107–7132 的节目页使用当前 curVoice，在它变化时 dispatch
  page:vinylPage/initVoicePage。M69:184–204 从 host.uid 取格式化用户，并用
  all 同时发起 M109.j（节目详情）、M109.e（推荐）和 M109.f（包含歌曲）。
  三路完成后，模型一起提交当前节目详情与第三路的 relatedTracks。
- M109:98–118 的 f→g 将节目 id 交给 M15.Rh，并以空业务对象和
  {formatOption:{uid}} 调用；M15:741–742,4139–4155 的 Rh→pa 用
  `/api/v1/dj/program/tracks?id=<节目ID>`，缓存关闭（M15:1012–1014）。
  M12:115–154 与 M402:387–450 把 URL 的 id 字符串并入请求数据，最终
  POST 到不带该查询串的标准 API 路径。uid 只给格式化层，不进业务请求。
- M15 将响应顶层 tracks 交给 M21.D→I（293–325）与 M21.x→D（537–624）。
  Promise.all 保持输入顺序。D 用 `album ?? al`，R（484–505）用
  `id || albumId`、`name || albumName`、`cover || picUrl`，D 用
  `ar || artists` 和 `dt || duration`。M21:1013–1018 格式化嵌套
  voice.songs 的是另一条路径。官方本地 Database.put 是格式化副作用，
  并非额外的业务请求。
- VoicePage/components/SongCard.tsx:43–72 与 M182:7017–7060 过滤掉没有
  album 的行；空则隐藏，非空显示「包含歌曲」、行数及 VinalPageTrackViewer。
  VoiceDisplay.tsx:69–78 的顺序为收藏、简介、推荐、包含歌曲。
  VinalPageTrackViewer.tsx:70–105 是无表头标题列，scene=song-song-recommend，
  pageType=voicePlaying。M182:7569,7613 用 M23.w（M23:49–50,860）选择节目页，
  包含 voice、downloadVoice、localVoice。M308:487–505 从下载 origin 取得 curVoice；
  M3004:334–347 的随心听动作使用 voice 类型与 sceneFm 来源，可打开同一播放页，
  M3004:524–541 直接核对当前 curVoice；M308:538–546 是在线 voice 的共同模型。
  听过的书章节点击（M2120:80–99，M404:202–259）进入普通节目队列，不因书来源禁用。
  TrackTitleCell.tsx:621–634,729–751,816–831 的
  点赞、适用时下载及封面播歌是另有动作资格的交互；没有普通更多菜单。

原生接口及边界
- MusicClient::player_voice_songs(epoch, play_id) 返回
  {playId, voiceId, receipt, tracks, availability}。availability 与 tracks 按行对齐，
  分别给出普通在线播放的 onlineEligible 和明确负版权状态 copyrightBlocked；
  不外发原始权限字段或把这些标记当成下载、会员、付费权益。
  是三路中的曲目读取；不加到每次播放 snapshot、音源解析或本地文件读取，也不重复
  请求详情／推荐。桌面只在当前节目播放页打开时读取，关闭或切集立即清除；不声称
  已迁移官方对三路请求共同等待的行为。
- 只接已验证账号的普通在线节目；节目、主音轨、队列条目、playId、账号/API 和
  凭据修订来自原生状态。检查发送前及交付前，使用与百科共用的 PC EAPI
  有界读取门；不查实验组，不把原始响应、节目 URL、Cookie 或其他授权字段交出去。
  同修订但节目接口与 PC 凭据校验范围的 Cookie 不同也不发送。不接收调用方传入的
  节目 ID 或下载任务。随心听必须具有 actor 当前解码确认，待切换／待加载条目不合格；
  下载必须来自原生 typed Voice 任务并核对节目与主歌曲。读取仍需可用的同账号 PC
  会话，不靠本地文件获得联网资格。纯本地文件、无账号、一起听与旧队列无下载节目
  标记分支未接入，不能据此推断官方也拒绝它们。
- 按响应保留顺序与重复项。返回现有 TrackView 的普通曲目展示字段，图片限已知
  公共图片域并移除原始查询串和片段；未用原客户端 picId 推算图、版权替代 MV 图、
  数据库副作用、权限详情或专用列。没有曲目播放/下载授权、没有原料回写。
- 缺 tracks 使用空表，显式 null／非数组为无效响应。限制100条曲目、每行32位歌手、
  文本1024字节、图片 URL 2048字节与32位十进制 ID。保留有 album 对象的原始行，
  包括空对象；异常形状不猜替代值。标题译名的既有有界原生字段没有新增公开输出。

普通在线曲目选择
- 封面在 TrackTitleCell.tsx:816–831 用 Action.play + ResourceType.track；它不传
  列表和双击事件。M3085:180–196,243–251,309–314,380–399,564–585 从双击
  事件及 replaceQueue 决定列表和 clear；按表格实际展示顺序替换，否则只选中被点曲目。
  普通行单击属于表格选择，不调用这个播放接口。M3085:532–541 只有同类型的当前资源
  才可能切换暂停；节目主音轨和同 ID 的普通歌曲不是同一个资源。
- player_voice_song_play(epoch, play_id, receipt, {kind,index}, quality) 接收
  `cover` / `double_click` / `next_play`。receipt 是仅本进程、单页、10分钟内有效
  的原生能力；新成功
  快照替换，读错保留仍有效的旧页。账号/API、凭据修订、实际节目/主歌曲/条目、随心听
  修订和下载任务身份随页绑定；队列与播放意图在 actor 接受时验证。绑定已切换到普通歌
  曲时旧卡不接收动作。没有 renderer 歌曲 ID、原料、文件路径或 URL。保持音频焦点，
  不抢其他原生媒体。非替换动作保留原队列并按普通原生规则插入／选择一首。
- M3085:462–481 先检查被点曲目，M308:4540–4699 调 M23.z；M23:428–445
  的在线条件用 M119 的连接状态，映射的 maxPlayBr<=0 为不可播，明确试听位例外。
  这里只用匹配 ID 的公开在线 metadata 预检被点曲目，不能视为实际授权；接受后仍由
  已有普通原生音源 resolver 请求该曲目的授权。替换保留全部展示行的顺序，不把尚未
  点击的曲目授予权限。M308:4465–4479 的下载优先、M23 的离线本地/cache、会员与
  版权备选弹窗未接入；不在普通音源拒绝后凭卡片重试、下载或绕过权限。

单行「下一首播放」
- M556:117–142 的普通歌曲菜单使用 nextPlay；M35.j:35–42 把负的版权状态视为
  禁用。M3085:243–251,309–314,380–399,564–585 对已存在播放列表的单行请求
  只用被点歌曲，发送 `play:false,clear:false`，不读取双击替换设置；空列表转播放，
  但当前节目页的原生 receipt 无法授权空列表。M308:3148–3152 以当前显示次序为
  锚，M59:117–174 筛掉不可播曲目后才插入。这里保留已证普通在线分支，仍不模拟
  下载／本地映射、版权替代和付费弹窗。
- M1384:2628–2669,5273–5298 去除同 resourceId 的旧行，在当前行之后重放新行；
  `play:false` 不设置当前播放。M1384:5366–5377,5695–5725 同时指定随机播放的
  下一项。Cumulus 在展示顺序与原生顺序中都紧接当前条目，重复移已有普通歌曲，保留
  条目 ID；完全相同且已在正确位置时不重复写队列。歌曲与同数字的节目主音轨使用独立
  命名空间，不能通过入队移除正在解码的节目。当前 playId、条目、位置、暂停与解码器
  不变；常规后台预取仍可能做自己的已授权读取。已知不可播、负版权状态或失效 receipt
  在写队列或触发媒体读取之前拒绝。

多选的原生动作
- M106:152–223,291–299 保存选择 Set 的插入顺序。普通左键会在抬起时收回为单项；
  右键点中现有选中项保留整组，点未选中项重新单选。M195:399–411 仅在多于一项时
  按此顺序给动作提供 selectedData。Row.tsx:134–148 和 M19:86–107 另外传触发行；
  M3085:4517–4535,4619–4632,4659–4688 保存并恢复右键触发行和父列表。封面自身的
  click 仍然不带 selectedData，不应消费多选。
- M3085:243–251 让已选组优先于整表。菜单播放／下一首保留当前队列，与双击偏好
  无关；如果双击时确实还持有多选，替换设定才使用该组及清空，追加设定只使用触发
  行（M3085:309–311,380–399,564–585）。触发歌曲是启动／检查目标，而不是组选中
  的第一首（Row.tsx:143–148；M3085:217–218,431,456,462–481）。M556:85–100,
  117–139 用全组选中项是否全部版权受限来决定菜单可用性；M3085 仍检查触发曲目的
  播放资格。之后 M308:3148–3173 与 M59:117–174 过滤后按原序去重并插在当前后。
- 原生 `player_voice_songs_selection(epoch, play_id, receipt, {kind,index,indices}, quality)`
  接受 `menu_play`、`next_play` 或 `double_click`。`indices` 仅为当前已验证卡的
  2–100 个不重复行号，按选择顺序携带且必须包括触发行 `index`；重复歌曲的不同
  展示行允许选择，入队保留第一条合格同 ID 曲目。菜单播放保留旧队列并从触发曲目
  启动；下一首保持当前原生解码器、playId、暂停、进度，并在随机队列中同样固定顺序。
  同批已在正确位置时不重复写队列。容量不足拒绝整批。沿用原子队列／播放版本、
  音频焦点、账号、凭据修订、节目身份与一起听守卫，不另读卡片／选择数据，也不修改
  远端账号资源。显式播放仍走现有媒体授权，常规后台预取也可能发生。
- 此段是原生权限明确的普通在线分支：触发行不可在线播放则拒绝，组里没有正常
  在线资格或已标负版权状态的行不入队（即使它同时携带正码率）；不会猜测备用歌、
  本地文件、已下载资源、免费试听或会员购买跳转，真正播放仍由现有音源 resolver
  授权。双击追加退回原单行检查。桌面 IPC 同名、仅主窗口可调用；不会把这次动作
  登记为稍后可重放的播放器重试。

桌面曲目表与喜欢
- VoiceSongRow/VoiceSongsCard 使用无表头标题列、48px 封面、标题、歌手链接和行内
  喜欢。曲目较多时在已有播放页滚动容器上只渲染可见行及缓冲，不加嵌套滚动。使用
  当前卡的行号而不是歌曲 ID 作为选中身份，因此重复曲目有独立的行。普通单击只
  选择；Ctrl 切换行、Shift 按锚点扩展、Ctrl+Shift 从选中组扣除范围，Ctrl+A 选当前
  卡全部行。双击走替换设置，封面始终单独播放。方向键从选择组边缘继续，Home/End
  用既有外层滚动区域移动焦点，键盘可打开右键菜单。新节目或原生 receipt 重置选择。
- 右键调用共用歌曲菜单。该菜单的播放、下一首、评论、收藏和分享/复制链接都有实际
  入口；切集、换账号或关闭节目页时回收旧入口。M556:76–141 对菜单的播放及下一首
  检查版权标记；已知负版权状态不提供分享或复制；评论和收藏走各自既有流程。
  曲目卡在打开菜单时冻结有序行号；未选中的修饰键右键目标只作为单行处理，不代替
  原生动作所需的组内触发行。这里的多选只覆盖播放和下一首；多项收藏及逐项下载不走
  这条路径。
- TrackTitleCell.tsx:605–631、OperCell.tsx:44–58,132–155 的喜欢使用普通歌曲
  类型及全局喜欢映射，不使用节目点赞，也不依赖在线播放权限。IPC
  player_voice_song_like(epoch, playId, receipt, index, liked) 只接受活跃节目卡的
  行号；Rust 解析歌曲 ID、核对账号与凭据范围后，复用普通歌曲喜欢、结果回读和未决
  写入对账。该动作不会切换播放或修改队列。
- 官方 DownloadButton/index.tsx:137–147 走歌曲下载。M3085:3455–3473,3965–3982
  对非已喜欢且不来自自有／已收藏歌单的普通歌曲，会先要求选择「下载到歌单」；
  取消中止下载。故此卡暂不显示通用下载入口，避免把仅选目录/音质的流程当成官方行为。
  付费购买与本地替代边界见上。
