Cumulus：只接非空普通顺序播放队列与单个可见本地歌曲行。按住标题或行的空白位置，
拖到已展开队列的插入线并松开。可在首尾或两行之间放下；边缘滚动按实际列表边界。
Escape、离开窗口、切换账号/页面/搜索/队列或手势丢失会取消；即使释放回标题上也
不触发播放。原有“下一首播放”菜单仍按当前曲之后插入，使用不同动作。
前端用应用内指针状态持有本地页来源，既不读 DataTransfer，也不接收系统文件、链接、
拖入的元数据或路径作为播放资源。已有文件夹筛选仅匹配索引键。
`player_action/drop_local_into_queue` 要求账号代次、查询/库版本、可见页的本地曲目 ID、
队列版本、当前 play ID 及下一个队列条目 ID（尾部用 null）。核心按索引复核查询/分页，
`queue_track` 复核文件指纹并生成原生资源；以后实际播放仍要经过现有 CUE/NCM/文件
授权。新旧版本不符或不属于当前页/队列时直接拒绝；错误留在队列上，不自动重放。
插入复用原生队列事务和 actor 栅栏；不切换播放源、当前条目、播放 ID、暂停或位置。
重复资源移到落点而不添加第二个条目；若是当前曲则原条目和加载资源完整保留。
超过队列容量时拒绝新条目，不删除远处旧曲。启动恢复中/加载中、随机、FM、心动、
一起听及含隐藏原生条目的队列暂不接受这个入口。其他来源、多选拖放、窗口窄到
同时看不到歌曲与队列时的交互、接续或房间上报仍不在这一单行版本范围内。

验证：client_local 的合成源验证插入首位、重复当前曲移尾、同一个暂停的原生条目、

在真实 WebView 使用合成 WAV/CUE 和 libmpv null 输出；检查插入线、Escape、释放
时兼容点击、外部 drop 无效、实际队列新顺序及同一个暂停 CUE 播放实例。
指针由 WebView 合成注入；不是物理鼠标、声卡或真实房间验证。

Cumulus 用同一插入线、Esc 和非空普通队列规则；按钮等可交互控件保持原动作，只有
普通歌曲行和标题响应拖放。搜歌单时，手势带过滤前的索引；切换来源页、账号、歌单
版本、搜索或目标队列会取消手势。核心只接当前登录账号的歌单 ID、trackIds 版本、
原列表索引、歌曲 ID 和音质偏好，前端不传标题、资源对象、路径或 URL。先读
/api/v6/playlist/detail 核对返回歌单 ID、完整 trackIds 版本及索引对应的非本地歌曲，
再只读该歌曲 /api/v3/song/detail。私有云盘/已标为云盘的歌曲不通过这个入口；没有
曲目详情同样拒绝。由核心投影安全队列资源，真正播放时才使用既有权限和地址解析。
歌曲重复按各类资源身份区分；已有云盘、本地、下载或播客条目不会仅因数字 ID
相同而被合并。当前重复项保持原条目、播放 ID、暂停及位置，只移动队列位置。
读请求失败、版本过期或并发换曲均不写队列，也不自动重放。

本分支覆盖当前已加载的单首普通歌单歌曲。未接批量勾选拖动、搜索结果/日推/专辑/
艺人/榜单等其他来源、私有云盘歌曲、一起听或跨设备拖放。官方在拖放时可用客户端
