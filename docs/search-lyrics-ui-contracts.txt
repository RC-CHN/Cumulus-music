当前界面
- 统一复用 TrackRow 保留歌曲、歌手/专辑入口、喜欢、时长和更多操作；表头与歌曲页一致。
  不把变量高度歌词放入56px固定行高的虚拟列表。每批10项，单条最多512行/64KiB；
  超出时显示“歌词过长，仅显示部分内容”，复制按钮与成功反馈明确显示部分内容。
- 歌词默认前三行；展开/收起保持当前控件焦点；切分类/详情返回保留展开和滚动位置，
  状态只在账号隔离的搜索内存保存。新搜索和换账号不会复用旧关键词的展开记录。
- 少于四行时展开不可用；没有歌词时明确说明，复制不可用；长行可换行，不产生横滚。
  950px以下操作行移至正文前面右对齐，左距40px；展开后操作不会被推至视口外。
  此为Cumulus窄窗适配；28px按钮高度/6px圆角亦非已证明的官方像素值。
  展开/收起文字用160ms透明度/位移动画，图标旋转；尊重减少动态效果。
- 复制通过类型化 copyText → desktop copy_text → 原生剪贴板；复制成功/失败和重试反馈
  在按钮下方，不用浏览器剪贴板权限提示。请求进行中保留焦点、忽略重复点击。
  Tauri官方剪贴板适配说明：https://v2.tauri.app/plugin/clipboard/
  使用与现有Tauri兼容的clipboard-manager 2.3.2；锁文件不升级现有Tauri/WebView依赖。
  正式前端没有读取/清空剪贴板权限；此能力不进入Rust业务core。
- 旧 matchedLyric 字符串/数组仍作为兼容输入；移除em/b标记，其余内容按文字插值。
  优先官方 lyrics/lyric，不再静默截为五行。不存在HTML注入或额外歌词网络请求。

连续加载与可变高度
- M3095:2489–2524、2544–2555 的歌词模式初始和后续按 10 条请求，后续采用
  已返回列表长度作为 offset；M3001:299–301、405–416、477–485、503–515
  追加并按满批继续。M2245.f:195–215 只发送 keyword/scene/limit/offset；
  M15.Wn:2270–2299 读 resources 与 totalCount，明确的 null resources 为空，
  不生成歌词分类纠正。原 formatter、请求包装和 effect 四组合成向量已离线执行，
  覆盖满批/短批/显式 null/空数组与矛盾的总数、hasMore 和纠正字段。
- Cumulus 对歌词仅在返回原始条数等于 limit 时允许继续，保留 totalCount 用于
  展示；不会因 hasMore=false 提前丢失续页，也不会让短批因旧总数继续请求。
  nextOffset 计原始条数，避免畸形条目被过滤后重复请求。列表缺失/格式不合法
  仍是可重试错误；失败时保留本次有效请求词、已加载内容和滚动锚点，只响应显式重试。
  不新增歌词分类响应中的纠正词，已有综合纠正进入歌词时继续生效。
- M352:1136–1171、M225:485–504、536–539 和 M230:75–88、137–156、172–212
  使用共享滚动容器、测量行高、前后各 5 项缓冲与剩余 60px 触发。
  Cumulus 保持同一滚动面板，以测量行高索引可见窗口，保留已聚焦行；滚动停帧时
  有界定时器更新。展开、分类往返及宽度变化按行和行内位置恢复，不按固定行高猜测。
- 同一歌曲的多条歌词命中保持顺序和独立展开状态。每次浏览最多 500 行、
  合计 2 Mi UTF-16 文本单元，达到上限时给出提示；播放采用已加载有界列表和
  确切点击位置，沿用搜索试听上下文。
- search_lyrics_smoke.py --waterfall 在真实 WebView 核对原生合成请求、失败/重试、
  迟到前的等待、变高与还原、窄窗、重复歌曲命中和深处点击后的原生队列。
  同一用例增满批但 hasMore=false 后继续，短批但 hasMore=true 后停止；
  错误的歌词纠正字段不改变原请求词，末尾按钮消失后焦点落在本页结尾。
- `9ef06185` 的 Linux 实际 WebKitGTK 复验共 4 阶段和 4 张截图：在 offset=60
  收到短批 3 条后停在 63 条，仍显示服务报告的总数 99；保持重试游标、重复命中与
  有界节点。深处播放实际进入合成歌曲 58，返回恢复焦点和展开。证据：

点中歌词行的评论菜单
- M352:1149–1174 在搜索场景下把歌词命中交给 M225 的 Track 行菜单；
  M225:350–360、563–601 传递点中行和选区。M15:2270–2289 的格式化先合并
  外层歌词资源，再叠加嵌套 song。M556:144–229 等待行菜单准备；M232:824–842
  发 POST /api/resource/commentInfo/list，resourceType=4，resourceIds 为
  精确歌曲 ID 的单项 JSON 数组。正数用「查看评论(N)」，零或失败保留普通
  文案，特殊歌曲隐藏；动作仍按该行原歌曲打开评论。
- Cumulus 在已登录歌词结果读取时绑定 songCommentMenu 到准确公开歌曲和
  /api/search/resource/lyric。外层明确身份与嵌套 song 不符、私有来源或特殊歌曲
  不发读取回执。Rust 原生调用使用同账号的歌词请求作用域和评论数作用域，
  不借用单曲查询的路径；前端不能提供歌曲 ID 或服务路径。存活时间和 1.5 秒
  降级沿用 search-song-menu-comment-count.txt。
- 即使多条歌词命中同一歌曲，打开菜单也按该命中的原对象、行序号、可见窗口、
  当前搜索及原锚点核验。换分类、关键词、账号或锚点后的旧结果不弹出菜单。
  播放、歌词展开、分享和评论页路由保持各自原流程；组选区按下节处理。
- 隔离 Linux Tauri / WebKitGTK 验收通过九态及九张截图。同一首歌的两个合成
  命中核对了两个不同的原生行回执、原歌词行焦点、两次非缓存读取和准确评论页；
  零或失败保留文案，特殊歌曲不发送评论数请求，离开后的 88 不弹出，新搜索
  中显示 51。原暂停队列、原生播放实例和独立播放器徽标没有变化。
  证据在 .build/ui-proof/phase309-search-lyric-comment-count/lyric-comment-count/。
  原生传输测试同时校验精确歌词路径、超过 JS 安全整数的歌曲 ID、正确和冲突
  的歌词路径凭据。两项证据均使用合成数据；Windows 由对应提交的 CI 验证。
- 同批 Linux 歌词连续加载回归通过四态：63 条短批后停止、保留重复命中，
  真实解码歌曲 58、返回恢复焦点。证据见同目录 lyric-waterfall-r1/first/。

歌词选区及组播放
- M106:152–223、234–299 以有序歌曲 ID 集合记选区；Ctrl 点击按操作顺序切换，
  Shift 替换范围，Ctrl+Shift 从现有选区扣除范围，Ctrl+A 只取已加载项。
  普通右击选区内歌曲保留组合，点选区外歌曲切为单曲；普通主键在已选歌曲上
  到抬起才收为单曲。M225:540–545、590–602 单独处理背景清空和组菜单。
- M3095:247–251、M352:1149–1174 的分类挂载和前缀键未证明返回时恢复选区。
  M3085:215–251、431–481、564–585 有组选曲播放和下一首语义，M556:342–395
  有组下载判断。Cumulus 保留变高虚拟行，选区按有序歌曲 ID 记录，同时保存
  实际点击的行作为 Shift 范围端点和菜单锚点。滚动和续页不清空已加载
  选区，换分类、搜索、账号或已加载前缀则重新建立选区。普通 More 按主键
  抬起后的单曲打开；按住修饰键右击选区外不会借用其它行的组授权。
- 歌词查询只为原生核实的公开歌曲和明确播放权限签发 lyricGroupPlayback。
  同一歌曲的相容命中各有自己的行回执；在同一查询后续页发现冲突权限会撤销
  该歌曲全部旧回执。组动作只接不透明的 anchor、rows 及 operation、quality、
  expected_play_id、expected_queue_revision，前端不提供歌曲 ID 或源路径。
  Rust 核对歌词、账号和音源请求 Cookie 作用域，限定同一查询连续分页，
  提交前校验原账号、队列和播放实例；不能跨用单曲、下载、分享、拖入队列回执。
- 菜单的组播放和「下一首播放」沿用 M3085 的点击锚点、选中顺序和
  trialMode=42。可播放项插到当前项后，不替换已有队列；暂停时点下一首
  保留当前解码实例。若混合组点中版权不可用行，则提示改从组内可播行操作，
  不更改队列。组菜单不读单曲评论数；官方检查顺序有时先读后隐藏。
  官方组收藏、组下载和歌词行拖入队列尚未接入本流程。
- 用离线 Hook 夹具执行原 M106 得到 11 个选区回执；同一歌曲的两个命中共用
  选中状态，追加页不自动选新尾部，删除的 ID 会清理。见
  .build/ui-proof/phase310-lyric-selection-audit/official-selection-vectors.json；
  这是原模块执行证据，没有运行官方桌面宿主。
- Linux Tauri/WebKitGTK 的 `search_lyrics_smoke.py --group-play` 隔离验收
  通过九态和九张截图。按 Ctrl 选择 103、102、101，101 的两个命中均选中；
  版权拒绝保留暂停队列，点击第二个 101 命中时按 103、101 插入，随后从
  该 101 开始实际解码。合成媒体授权用 trialMode=42；另核对加载续页、
  组外修饰键、普通右击及切换分类。截图和请求见
  .build/ui-proof/phase310-lyric-group-play/group-play-r3/。该证据没有真实
  账号请求、实体声卡或 Windows 桌面实测。
