社区实现和验证

core/playback/keep_awake.rs 的纯模型只接恢复的枚举及设置，不推测现有 Rust
状态对应关系；desktop/playback_keep_awake.rs 提供不能跨线程传送或共享的
Windows 适配器，构造不调用平台 API。显式 apply 只调一次，失败返回系统错误；
已成功启用的适配器析构时尽力清除，这是未来宿主的额外安全清理，不称官方等价。
调用者必须使用同一个专用系统线程，不能在共享线程上覆盖其他组件的请求。

本地 Node VM 执行 M/473 的原始效果体及 M/4 的桥接函数，核对十条合成观察、
重复依赖抑制和 macOS 不调用；Rust 冻结同样的状态/请求测试及 Windows 标志测试。
本批未接设置、引导、IPC、生产宿主、实验刷新或 Linux 休眠抑制；没有调用 Windows
原生接口或在物理机上验证休眠。正式接线前仍需验证原始模型信号的完整映射、宿主
线程寿命、设置读写及休眠回归。没有账号读写或外部服务请求。
