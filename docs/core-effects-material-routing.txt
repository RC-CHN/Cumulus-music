2026-10-29；对应 effects/material/{routing,equalization,controls}.rs。

本批范围
实现官方整份材料的分支选择、组件顺序及七类新增参数/开关调用计划。
Rust 可以独立读取 NCAE、选择实际生效的分支、输出类型化调用；不是全效果图的
声音渲染或桌面预设启用。已有 GEQ 和音量均衡播放器接线仍按各自专项文档验收。
没有增加网络接口、账号权限或付费行为；不依赖 Tauri 或归档 Python 进程。
未使用 YesPlayMusic。混响等尚未恢复的内核不能用部分 EQ 链冒充完整官方预设。

分派规则
- 根必须是对象。aev2 只有在值为对象时才整体替代旧分支；空对象也不回退。
- 现代分支顺序固定为 eq、bt、se、rvb、rotate、peq、cmp、limiter、dly、alc、spspatial。
  旧分支只有前五项；顶层 peq/cmp/limiter 等不会因为存在字段就被激活。
- 只有对象形式的组件会进入对应解析器；对象的 on=false 或缺少 on 仍可能产生关闭
  调用，因此不能在分派时按真假过滤。chorus/flanger 在官方现代分支仅记日志，
  没有引擎 API 调用。route_sections 的顺序是配置调用顺序，不是 PCM 的处理顺序。

EQ / BT
- on 只接收布尔，缺少或错类型默认为 false；关时不读取其他参数。
- EQ 开启且 eqs 为数组时，读取前十个元素，短数组补零，非数字元素独立归零。
  空数组提交十个零；eqs 缺失或非数组时不提交增益，但仍提交开启开关。
  先发增益再发开关，不直接用旧值补全短数组。
- BT 开启时 bass 缺少/错类型默认为 +2 dB，treble 为 0 dB；只传这两个增益。
  JSON 中的 bassFreq/bassQ/trebleFreq/trebleQ 不会被这个桥读取，不能擅自套用。
  外层缓存显示值和实际 DSP 的初始化默认值可能不同，不能用日志缓存替代 DSP 参数。

压缩 / 限幅 / 延迟 / 简单开关
- compressor_calls：on 默认 false；开启时 threshold=-18、ratio=4、attack=0.05、
  release=0.1、range=-5、pregain=0、postgain=0。数字字段缺少或错类型沿用对应默认。
- limiter_calls：on 默认 false；开启时 threshold=-18、attack=0.05、release=0.1、
  outputgain=0、ratio=4、infiniteRatio=true。infiniteRatio 仅接受布尔。
  这组显式材料默认值与下述引擎载入默认限幅不同，不得混为一套。
- delay_calls：必须有布尔 on；false 只关闭。true 时 delay、feedback、dry、wet
  必须全部是数字，否则整个组件被跳过，连关闭调用也不发。四个数字字段校验通过后
  才转 f32；缺少一个字段的对象不能被当成使用默认值的延迟或显式关闭请求。
- alc_calls / speaker_spatial_calls：只读取必需的布尔 on；缺失/错类型时不发调用。
- 数字转 f32，布尔不算数字。Rust 额外拒绝转成非有限值的计划，避免交给音频线程。
  调用计划不提前夹取普通数值；内核的合法范围、限幅和状态转换属于后续 DSP 边界。
  本批按“参数在前，开关在后”返回完整 Vec；失败不返回半份配置。

末端前瞻限幅：材料控制与帧协议
以 3.1.42.205594 x64 的 neaudioeffects.dll 为准（上述完整 SHA256）。真实
LookaheadLimiterProcessorImpl 虚表 23F588，构造 63900、初始化 63EB0、旁路 654A0、
参数 654B0、PCM 入口 63B90、动态算法 63F30、状态/容量重置 64F40。图处理
1AA50 先运行其余 DSP，再运行 B0 限幅，最后才输出格式转换（10）。
此处无网络接口，不触发服务端授权。

Rust material_limiter_plan 将两层控制明确分开：
1. 已存在的原生处理器执行 begin 时，处理器 reset 和取消总旁路分别对末端节点
   发送 bypass=false；随后传默认参数 0 dB、f32 5 ms attack、f32 100 ms release、
   0 dB outputgain、infiniteRatio=true、ratio=4 和结构末尾的 true 标志。
2. 现代 aev2.limiter 必须是对象才进入 EFA280。明确 on=true 时先提交组件参数
   （默认 -18 dB、50 ms attack、100 ms release、0 dB、无限比、ratio=4），再开；
   on=false 或对象里缺少/错型的 on 只提交关闭，保留刚提交的默认参数。
   缺少组件、错型组件或旧式顶层 limiter 不派发，保留 begin 默认开启。
3. 本次不把 end 描述成提交或启动 PCM 的动作；前文原生对照未观察到 end 的
   处理器调用。计划记录已发送参数，不把所有值当作实际参数；例如 654B0
   忽略非正 attack，继续用 begin 的 5 ms。非有限参数被 Rust 拒绝，不返回半份计划。

新合成原生证据实际执行 x64 构造、初始化、begin、reset、末端桥、实际限幅
节点及数学代码；只有分配/释放、有界内存操作、锁/安全 cookie 和其他处理器
setter 使用替身。无官方 DLL 全图初始化、Windows 系统运行、声卡或账号验证。
64F40 先以双精度把采样率乘收到的 f32 attack，再乘声道数，向零截断并向下对齐整帧；
6533F–65351 将整帧数减一，同时作为首块扣留和 EOF 补帧预算。63B90 在 EOF
把当前块未用容量补满到剩余预算，未排完时清除本次 EOF；64B55–64BB0 在返回
前扣掉尚未补偿的起始前瞻。例：48 kHz 双声道、每块至多 128 帧、默认 5 ms，
先输入 128 与 71 帧，两次均输出 0；再以两个空 EOF 块排出 89、110 帧，
最后一次才返回 EOF。44.1 kHz 单声道的 256 帧首块输出 37 帧，扣留 219 帧。
显式关闭则原样返回帧数和 EOF。默认双声道的同步峰值 2.0/-1.5 变为 1.0/-0.75，
证明两声道共享增益；不能拆成互不通信的单声道节点。

LimiterFrameFlow 实现初次载入后一个固定格式流的块/EOF 协议，只计算输入补帧、
初始扣留、输出帧数和 EOF，不存储或计算 PCM。复用本机 DSP 格式限制；拒绝超出
容量的块、攻击窗口不足一帧或超出原生缓冲分配的 100 ms 范围。运行中的重载和
旁路切换不在本流程内。公开冻结向量 effects-limiter-pcm-official.json 包含七种
合成输入的真实帧数、EOF 和非零样本，记录 DLL、两个生成器哈希和替身范围。
Rust 测试比较其中的帧数和 EOF，并与 EFA280 的 207 组冻结显式控制调用联合验证；
该批只核对时序；非零样本随后用作下节的 PCM 迁移证据。

限幅 PCM：初次载入的单节点离线渲染
原生 63F30 的公开合成对照新增五例：双声道交错峰值及相交斜率、有限比率加前后增益、
无限比率加前后增益、44.1 kHz 官方默认窗口和八声道向量分支。只执行原生材料 begin、
实际限幅节点、数学和上节列明的有界宿主替身。冻结 effects-limiter-kernel-official.json
的 185 帧中间状态保存原生 f64 位模式：共享峰值、当前输出增益、下一增益和斜率、
待处理峰值数、滑动统计及每声道裁剪后的 f64 样本。五例另有 691 帧、1554 个 f32 PCM
样本和完整输出帧数/EOF；Rust 逐位比较，不把 Python 模型当作业务实现。

- 64080–64187 先把输入 f32 提升为 f64，再乘前置线性增益，以所有声道的绝对值最大值
  检测同一帧。前后增益和阈值的 dB→线性转换沿用 71DE0：f32 除以 20，升为 f64
  执行 pow(10, x)，再舍入 f32。参数化增益和阈值范围在 Rust 外层检查。
- 64187–64447 按阈值/峰值建立目标增益。比较到达未来峰值的下降斜率，必要时替换整队，
  或修改第一处相交旧斜率、丢弃被遮蔽的后续峰值再加入新峰。除法先以环形样本容量为
  分母，再乘声道数，避免改变舍入。
- 64447–64840 取延迟帧、更新窗口峰值统计，先对所有声道使用同一个当前斜率更新后的
  增益，再在到达已安排峰时更新后续斜率。无限比率与有限比率的峰值退出分支分别保留；
  63E10 中有符号的释放候选和上下界按原算式保留。
- 64840–64ACB 处理增益和斜率的接近零边界。已经算出的延迟样本按 ±线性阈值裁剪，
  再乘输出增益。节点 +5C 是独立的阈值归一化标志，材料路径上为 0；+58 才是无限
  比率，不能用无限比率开启归一化。
- LimiterStage 持有跨声道环形样本、峰值队列和 LimiterFrameFlow。EOF 仅按原生预算
  读入静音，保留完整尾音；初始禁用保持输入。MaterialLimiterPlan::pcm_stage 接好已
  验证的默认及显式材料参数；非正 attack/release 不覆盖 begin 默认值，材料未提供
  可调前置增益，保留 0 dB。

可用：effect_dsp_render material-limiter-render INPUT.ncae < REQUEST.json

限幅 PCM：官方外层输入/输出 FIFO
3.1.42.205594 x64 AudioEffectsImpl 虚表 +18 的 67C00 接收输入，+20 的 68120
读取输出。1AA50 是二者之间调用的处理器：从原始数据转换到内部工作缓冲，顺序调用
非空节点，最后限幅 B0，再按其输出帧数调用输出转换 +10。此处只挂接已经恢复的
B0；不能把该入口用于给任意均衡器或播放流自动加限幅。

- 写入参数的长度按每样本字节数及声道数转成帧。正常写入独立输入 FIFO，累计到
  处理量子才调用 1AA50；官方默认量子 2048 帧。一个写入可以触发多个量子，剩余
  不足的帧继续排队。每次处理前清零工作区，只读入实际 FIFO 帧。
- 已初始化流上的零长度写入设置输入结束标记；之后的写入连同时间戳都忽略。
  结束时若输入 FIFO 仍有数据，从该余量开始排空；若已为空，67CE8–67D1C 先推入
  **一帧**静音。它和限幅器内部的前瞻补零不同，可以令总输出比总输入多一帧。
  随后持续调用图，直到图返回 EOF，每次仍按它返回的变帧数量写入输出 FIFO。
- 输出读取最多取调用方请求的整帧及当前可用量，不填补不足。非空读取仅在输入结束
  且读后的输出 FIFO 已空时返回 EOF。零容量读取不改原生 EOF 输出参数，Rust
  表示为 end=null。既未输入结束又没有输出的读取是 0 帧、end=false。
- 可选输入时间戳以整数毫秒替换保存值；未提供时保留保存值，图接收未设置时的 0。
  每个量子调用后，只有保存值正数时，按调用前从输入 FIFO 取得的帧数做
  trunc(clock + frames / sampleRate * 1000)；不使用限幅器修改后的输出帧数。
  时间戳 0 不推进，纯尾部补零量子也不推进。此值不是桌面输出时钟。

新的 x64 Oracle 实际执行 67C00、68120、原生循环 FIFO 的 71C00/719C0/724A0/722E0、
1AA50 图驱动及实际 B0；只用预分配缓冲，合成 f32 输入/输出转换用逐位交错转换
替身，无其他 DSP 节点。锁、分配及 CRT 替身范围仍按前节。六例包含两声道环绕
缓冲、输入恰好整量子、八声道空流 EOF 与跨块 PCM、单声道初始旁路、默认 2048 帧量子。
effects-limiter-stream-official.json 冻结 54 次写读、37 次真实图调用的输入/输出帧、
时钟、EOF 及逐次 PCM 哈希，共 2212 输出帧、4554 个样本。Rust 对照原生哈希，
验证了一帧额外静音、原始输入用时、读空后 EOF 与终止写入忽略。

MaterialLimiterPlan::pcm_stream 在新的孤立节点上提供 push_interleaved /
pull_interleaved。请求和返回均使用交错 f32 整帧；调用方可独立选择读写长度。
原生 FIFO 可扩容，Rust 容量为调用方给定的量子以上、最多 65536 帧；写入前预演
帧协议，任一 FIFO 不足则在接收 PCM、修改时间戳或结束标记之前拒绝，拉取后可重试。
异常时间戳和不完整帧拒绝。没有实现原生无处理器/无 FIFO 的分支、自动扩容、
源重置或转换器内部；默认量子以外的小量子用于原生边界对照。

限幅 PCM：跳转或源不连续时的重置
3.1.42.205594 x64 AudioEffectsImpl 虚表 +28（67F70）在有处理器时调用 6B060。
6B060 先调用图的 +18（1B960），再清除输入 EOF（+78）、将源时间戳（+440）重设
为 -1，并分别用 71AA0 和 72390 清空输入、输出环形 FIFO；保留分配与格式。
1B960 对 B0 的 +20（65490）设置内部历史重置标记（+C4），不重走材料 begin、
不覆盖阈值、增益、前瞻/释放时间、比率或旁路。在下次活动量子前实际清空 B0
环、共享峰值队列和释放状态，并重新开始扣留、EOF 预算。持续旁路的 B0
不需要处理 PCM；原生标记可继续保留。图中的其他节点各走自身重置，+80/+88
还有释放操作，独立 B0 不实现那些分支。

LimiterStream::reset 对调用方保留同样边界：丢弃尚未读取的全部 PCM、未成量子的
输入、源时钟和结束标记，保留已安装材料、格式和容量；新 PCM 重新前瞻。
与原生标记相比，Rust 私有历史提前清零，期间不会对外产生样本。已读出的 PCM
不受影响；调用方需在真正的解码跳转边界先重置，再写入新位置的 PCM，可提交新的
源时间戳。暂停或普通读取不会隐式重置。离线 NCAE 流命令接受 {"op":"reset"}，
可放在任意两次写读之间。

effects-limiter-reset-official.json 来自真实 x64 外层/图/环形 FIFO/B0 重置路径，
其余替身与上一节相同。四条合成场景、42 次操作、5 次重置和 26 次图调用覆盖：
有未成量子输入和未读取输出、有限比率参数的 EOF 后重置、默认 2048 帧量子的重置，
以及八声道旁路重复重置。
每个原生重置后的完整后缀均与一个独立初始化的原生流一致；Rust 核对重置前后
队列、时钟、EOF、所有调用帧数及 2278 帧（4583 个样本）PCM 的逐次哈希。
这里只验证原生显式重置入口，未验证官方界面哪些动作调用它。这里的独立 B0 验证不包含普通播放器的
seek 动作、实际声卡或完整图。另见 core-effects-modern-limiter-oracle.txt：单份
已归档 aev2 预设的 GEQ、现代 BT、PEQ 和显式 B0 已做原版完整原生图与 PCM
分级对照，仍未绑定桌面预设运行时。
