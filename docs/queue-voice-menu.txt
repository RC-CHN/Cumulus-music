普通播放队列：声音行菜单

官方基线：网易云音乐 3.1.42.205594。

- `PlayingTrackTitleCell.tsx:701–705,804–826` 与 M3113:443–459 不把普通歌曲
  的行内来源、喜欢、收藏套在声音行上，但「更多」仍传入队列包装对象、track 菜单
  类型和 `playingList` 场景。M19:59–85 原样发送动作；M3085:4517–4550 选择
  M556 的菜单。M405:225–247、M392:49–68 的右键继承同一播放列表场景。
- M556:81–115、M3085:350–376：当前播放行显示「暂停」，当前暂停行显示
  「播放」；动作调用当前播放切换或选择已有队列项。队列没有「下一首播放」；声音
  不提供歌曲收藏、歌手和专辑项（M556:117–142,233–276,521–539,575–579）。
  这与普通搜索声音的固定「播放」分支不同。
- M556:174–213、M232:824–839、M15:1671–1674：以所选声音的 `resourceId`
  读 `/api/resource/commentInfo/list`，参数 `resourceType=1`，`resourceIds`
  为 ID 字符串数组的 JSON 文本；失败时留「查看评论」。打开评论仍是该声音资源。
- M556:362–377,437–457,664–686,705–750,834–856：下载完成隐藏「下载」，
  提供本机文件目录；分享和复制使用声音资源。来源按入队文本及音频名称确定，
  M265:139–151 将有类型的节目播客链接到 `/audioDetail/<id>`；主播取该条目的
  节目创作者。多选隐藏评论、分享、主播和复制。M556:943–953、M3085:2822–2848
  从本机队列移除当时选中的条目，不改远端歌单。

Cumulus

- 主窗口「更多」、右键和 Shift+F10 共享版本绑定。Rust 从当前普通队列的条目 ID
  解析节目和对应主音轨，核对账号、凭据和队列版本；慢回复不覆盖新菜单。当前行
  的暂停／继续使用已有原生播放实例；播放非当前行使用既有队列选曲和授权。
- 评论数失败使用无数字入口。节目已有合法完成下载时用原生文件管理器打开目录，
  路径不经 IPC 返回给界面。播客和创作者仅使用该队列节目保存且核对的公开 ID；
  缺可信目的地时不猜链接。分享只打开本地分享对话框，复制公开节目链接。单条
  下载进入现有选项确认，旧队列不再允许开始。多选可移除捕获的选组；本批不接
  多选下载。已下载文件资源行、FM、心动和一起听不复用本菜单。
- `cargo test -p cumulus-core --test client_podcast --test client_player --locked`
  核对非当前节目 ID、读取失败／断网、队列变化前后及隐私边界。
- `scripts/ci/search_voice_menu_smoke.py --queue` 在隔离 Linux WebView 验证十态：
  实际 X11 暂停、右键、Escape、移除第二项、继续播放、目录交接；原队列版本仅
  移除时改变，解码实例和暂停位置保留，交互未另取音源。五个菜单画面核验合成像素，
  系统语言保留 `en_US.UTF-8`，数字 locale 为 C。合成服务与 null 输出，无真实
  音乐请求或账号写入；未验证 Windows、实体声卡或分享／下载提交。
