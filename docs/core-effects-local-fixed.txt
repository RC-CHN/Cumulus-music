Fixed local old-schema stereo material — standalone native scope
========================================================

Scope and status
----------------
LocalFixedStereoMaterial is an explicit Rust/C component, also selected by the
native-only held ColdStereoSource. It does not replace the LocalStereoSubgraph
API, install a normal player setting, change a default, expose an effect UI or
grant source/material rights. Its only accepted plan
is the existing LocalStereoMaterialPlan: ten flat GEQ bands with eq.on=false,
bass=treble=0 and bt.on=false, rvb.on=false, integer presence[-10,10] /
stereoizer[0,10], sshaper=true, and the official local schema's ambience=1.
RVB-on, GEQ/BT-on, normalization, rotation, other optional SDK modules and
remote/downloaded preset material are not accepted as this implementation.

This candidate admits exactly stereo 44.1/48/96 kHz, capacity512 or2048. These
are evidence bounds, not the original SDK's complete format capability.
Unsupported formats reject before state/arena allocation. The caller still
must establish actual decoded format, local material origin, account/source
identity, isOpen, native actor authority, and the whole graph's other gates.
No automatic source/engine switch is made by the new component.

Central Linux x86_64 integration has now built and executed this component.
The scoped267-test batch and full2412-test workspace pass, including all1204
original full-graph blocks through the actual Rust B0. Twelve standalone CLI
flows also match every valid PCM output byte. The manual C evidence below is
separate from those later Rust checks; neither installs a production effect.
Windows x64 vector tests are enabled. GNU cross-Clippy passed, including the
new FFI and test code, but actual Windows/MSVC execution remains a CI check.

Fresh off is bank0; switching off does not reset the material
-----------------------------------------------------------
1BBA0:1C02C–1C03C explicitly sets SE parameters(0,0,true,ambience=0), then
leaves SE bypassed. The fixed old local JSON includes ambience1, but
cloudmusic.dll EFF390 reads on atEFF42A–EFF455, tests it atEFF51D–EFF523,
and on=false jumps directly toEFF92B. Presence/stereoizer/sshaper/ambience
are read/applied only by the on=true branch. Therefore a fresh all-off graph
processes its first off edge with SE bank0. After an explicit SE1 enable,
a later on=false keeps bank1 and applied controls. The new candidate keeps
these distinct states; it does not derive active bank from a static JSON
field while off. Master1C590(false) and SE1DD00(false) remain distinct calls.

The original node Reset methods clear sample histories and set wrapper
previous=target. GEQ A3680, BT A2DB0, PEQ A3E90, SE A8510 and RVB A8DE0
are not an empty processing call. New GraphicEq/BassTreble/ParametricEq
reset methods expose that exact boundary; PEQ AE180 preserves current gain,
dirty/configuration fields. A failed Rust stage remains quarantined after
reset. LocalFixedStereoMaterial::reset also discards B0 lookahead as original
1B960 does; it preserves bank and applied gains. Existing standalone SE0's
public valid_frames=0 rejection and the raw multiband zero behavior remain
unchanged; any required zero-frame handling is local to this new internal
parent with complete initialized capacity storage.

GEQ peak trigonometry correction
-------------------------------
The GEQ type1 branch in B54D0 uses CRT cosf14E8D0 / sinf14EFD0. The frozen
original static CPU-dispatch path reaches14E580 /14EB80. Its finite positive
phase<=0.9*pi domain uses separate double operations, exact reduction
constants and sine/cosine polynomials before one final f32 rounding. Calling
host sinf/cosf produced a one-ULP difference at44.1k and contaminated the
later SE1 environment history. filter_peak_trig.h restores this bounded
original static-SSE computation, not the different133340 paired-sine PEQ
helper and not a generic libm substitute. Out-of-domain/nonfinite phase
rejects before an integer conversion. No AVX/FMA dispatch or large-angle
math-library behavior is claimed.

The manual freeze_geq_peak_trig.py executes only the two reviewed original
small-domain functions from the hash-pinned image. No DLL startup, text patch,
import/OS/CRT adapter or DSP hook is used. 10,135 synthetic phases include
small/subnormal inputs, polynomial and quadrant boundaries, a fixed-seed
sample and actual band phases. Every original sine/cosine f32 bit matches
the new C translation. The previous648 public coefficient vectors also
match bitwise when exercised directly through the new C coefficient function.

Local executable
----------------
cargo run -p cumulus-core --example effects_local_fixed --locked -- \
  44100 2048 local-plan.json synthetic-stereo.f32le rendered.f32le

The explicit CLI reads bounded raw interleaved f32le stereo, validates the
strict plan and real format constraints, drains actual EOF, and creates a new
output file. It does not play through a sound device or create credentials.
No output overwrite is allowed. The actual built CLI ran12 synthetic cases:
three rates ×two capacities ×fresh off/on. Its output was split at the original
block boundaries and every valid-byte SHA matched the original complete SDK;
all repeated output paths were refused without changing the file. Evidence:
.build/ui-proof/phase61-local-fixed/fixed-cli-r1.json, binary source310b93fb.
