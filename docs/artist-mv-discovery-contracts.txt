列表、续页与操作
- M/3088:2953–3019 → M/2999:313–359 → M/15:3700–3717：无缓存 POST
  /api/mlog/artist/video {artistId:"…",tab:1,order:0,page:"{\"size\":20,\"cursor\":0}"}。
  page 是 JSON 字符串，cursor 在其中是未经浮点转换的十进制数字；data.page.more 决定
  续页，回传 data.page.cursor。官方 M/2999:154–176 把返回放到 cursor-size 开始的
  位置并清理缺项；Rust 校验边界、回退/停滞，Vue 按稀疏位置合并并保留续页失败的前缀。
- M/2019:129–167 与 M/3088:3011–3018：12 跨距、span=4 的三列虚拟瀑布，滚到近底
  请求后续；尚有下一页时保留不完整尾行。本客户端保留可键盘操作的「加载更多」和
  重试。若合法页无卡片但仍有续页，提供手动继续，避免空页自动连续请求。
