细分音量与显示整数
------------------
官方 VolumeVertical.tsx 的 percentInt 把真实非零、未到最大值的音量显示为
1–99%，0% 和 100% 仅用于真实端点。社区版主/迷你播放条共享此显示逻辑；
写入和静音记忆仍保留原生小数值，不用显示整数覆盖它。滑块操作仍按 1%；
滚轮按 3 个百分点调整，保留起点的小数。合成桌面回归核对 0.2% 显示 1%、
静音再取消后精确回到 0.2%、滚轮升至 3.2% 和 99.9% 显示 99%。
同一实窗探针也检查主窗口浮层开合时发生在正文的滚轮：打开时单次原生音量
由 3% 变成 6%，滑块保留焦点；关闭后不再阻止同一事件、不发新原生命令。
Linux WebKitGTK 使用 f9fb92d1 的固定原生探针与本批生产前端，在无默认路由、
独立 XDG、en_US.UTF-8 与 libmpv null 下通过首次 40 态、重开 3 态。新增两态
原图确认浮层位置、6% 及关闭后返回图标的焦点；同一暂停实例保持 9.99 秒。
这是合成滚轮事件经过真实界面与原生音量的验收，不是物理输入或 Windows 实测。
